# Training Set Audit P0 产品收敛实施基线

## 状态

- 日期：2026-07-18。
- 基线：`training-set-audit-product-reset-v2.md`。
- 目的：完成最终 UX 签核前的默认状态、证据层级和行动闭环收敛。
- 范围：本轮不增加相分类、磁性或局域环境算法。

## 一、默认体验

Audit 打开后先执行数据盘点和既有确定性检查并显示基础结果，结构证据随后按设置决定是否自动在后台补算。用户无需配置即可回答：

1. 当前检查哪些结构。
2. 数据由哪些精确组成、原子数和 `config_type` 构成。
3. 是否存在明确 blocker 和需要人工处理的 review group。
4. 哪些组成最集中、纯端元各有多少。
5. 因为目标和独立模型证据尚未定义，当前不能判断什么。

默认组成图只显示精确组成计数。相结构和磁序属于“结构证据”，基础结果显示后默认自动在后台计算，用户可在设置中关闭。后台或进阶证据入口启动的计算不能擅自切换主图；如果用户直接在组分地图点击“分析相结构与磁序”，完成后切到“按结构相着色的样本数量”，作为该显式动作的结果反馈。

## 二、目标状态契约

目标有三种显式状态：

- **未设置**：不运行比较，不显示 `Thin`、`Quantity rule met` 或补样动作。
- **已设置但未启用数量规则**：只判断“有精确样本”“无精确样本”“无法判断”。
- **已设置并启用数量规则**：才显示“达到你设置的数量规则”或“低于你设置的数量规则”。

关键组成点留空时，只展示范围内已有精确分数点，不把它们自动解释为目标点，也不产生偏薄结论。

目标可选关注 `config_type`。比较时必须区分：

- 有匹配样本。
- 没有精确组成样本。
- 有精确组成，但没有匹配结构家族。
- 部分或全部结构缺少 `config_type`，因此无法完整判断。

目标比较结果进入 core 的统一结果模型，GUI、HTML 和测试不得各自重新发明状态语义。

## 三、概览行动

概览保留主要组成点和纯端元，但改为键盘可达的行动行：

```text
37.5 at.% Ni    28,746    51.35%    [查看 28,746 个结构]
纯 Ni              943     1.68%    [查看来源与结构类型]
```

当前判断拆成四块：数据质量、采样事实、人工复核、当前无法判断。首页不再显示低频信号数量，不固定推荐相结构分析。

## 四、数据地图层级

组成表默认列：

| 精确组成 | 结构数 | 占比 | 原子数 | `config_type` |
| --- | ---: | ---: | --- | --- |

相结构、磁序和证据完整度不占默认列。结构证据完成后，组分图提供“样本数量 / 按结构相着色 / 按磁序着色”三个显式视图；柱高始终表示该浓度的样本数量，柱内彩色分段表示各结构相或磁序的相对占比，色块可回选结构。

二元体系显示精确组成图。三元及以上在任何一维元素投影中都明确标记“投影后聚合”，并显示该投影点包含多少个不同精确组成。

## 五、复核队列

复核队列只消费 canonical Finding 中的 `blocker` 和 `review`。普通 evidence 留在数据地图。

状态必须按工作项类型提供：

- blocker：未处理 / 已处理并复验。
- 重复几何：待确认 / 有意保留 / 隔离候选 / 待重算。
- 标签冲突：待确认 / 已确定可信来源 / 待重算。
- 高力、高能尾部：待复核 / 物理上合理 / 需要检查几何。

重复几何按组展开，每组拥有独立结构索引、标签一致性和状态。临时状态使用 `(dataset fingerprint, finding ID, subgroup ID)` 命名空间；载入其他数据指纹时不得复用。

## 六、模型证据边界

默认空状态为：

> 尚未接入独立模型证据。当前没有通过结构映射和单位校验的独立参考值与预测值。Show NEP 对当前训练数据的预测可以用于误差浏览，但不会自动视为独立模型验收证据。

接入模型证据前，不显示模型误差结论。

## 七、验收测试

1. `set_result()` 后目标表为空，页面显示“尚未设置目标”。
2. 未启用数量规则时不会出现 `Thin` 或 `Quantity rule met`。
3. 启用数量规则后才出现对应数量状态，且文案包含用户设置的阈值。
4. Audit 默认先显示基础诊断，再在下一轮事件循环中自动后台启动相结构和磁序分析；用户可在设置中关闭自动分析。
5. 默认组成图始终是精确组成计数，默认列优先显示原子数和 `config_type`。
6. 从组分地图显式启动结构证据时，当前页显示进度，完成后自动切到按结构相着色的样本数量；自动后台分析不改变用户当前图表。
6. 三元投影点明确报告包含的精确组成数。
7. Review queue 中没有普通 composition/local chemistry/pair-contact evidence。
8. 重复几何可以逐组选择、查看和记录状态。
9. 更换 dataset fingerprint 后旧状态不可见。
10. 首页主要组成与纯端元按钮发出对应真实结构索引。
11. 缺失 `config_type` 时目标结果为“无法完整判断”，不是“无样本”。
12. 模型空状态明确区分训练数据误差浏览和独立模型验收。

## 八、实施顺序

1. 目标状态与 core 比较契约。
2. 复核工作项与重复组模型。
3. 概览直接行动与默认数据地图。
4. 按需结构证据。
5. canonical Finding、报告、中文翻译和文档收敛。
6. 定向测试、全量测试和真实数据任务验证。
