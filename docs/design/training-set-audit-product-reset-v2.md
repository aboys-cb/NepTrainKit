# 训练集评估产品重置草案 V2

## 状态

- 状态：已确认，作为当前 Audit 产品与 UI 的实现基线。
- 日期：2026-07-14。
- 目的：重新定义 Training Set Audit 相对 `NEP Dataset Display` 的职责、首屏结果和实施顺序。
- 本文记录用户可见产品效果；`training-set-readiness.md` 只保留核心契约、算法边界和性能证据，不再另行定义页面信息架构。
- 2026-07-18 的默认状态、复核队列和目标比较收敛以 `training-set-audit-p0-convergence.md` 为最新补充验收基线。

## 一、这次为什么必须停下来

当前实现已经完成不少基础工作，但没有形成用户能消费的产品结果。

已落地的主要是：

- 明确活动范围、数据和模型指纹。
- 数据格式、标签、晶胞、短距离、重复与标签冲突检查。
- 将高能量、高力从错误降级为复核集合。
- canonical Finding、GUI/HTML 共用结果。
- Distribution Explorer 迁入统一页面。
- 局域化学和元素对统计，以及大数据性能优化。

仍然缺失的核心体验是：

- 用户不能一眼知道纯元素、主要组成、结构类型分别有多少。
- 用户不能一眼知道数据集中在哪些组成、结构来源或轨迹。
- 没有目标比较，无法把“较少”升级为“需要补”。
- 没有模型误差切片，无法定位真正的模型薄弱区。
- Finding 的主要动作仍然只是“查看结构”，没有形成复核、隔离、补样和复验的工作队列。
- 首页仍按 Composition、Label、Local chemistry、Pair contacts 等算法模块组织，而不是按用户决策组织。

因此，当前产品本质仍是“检查器与分布图集合”，不是“查缺补漏助手”。

现有 `training-set-readiness.md` 中 Phase 0/1 的“完成”，只能理解为底层数据契约和检查基础完成，不能再理解为用户产品完成。

## 二、Audit 与 Show NEP 的职责边界

### Show NEP

Show NEP 是结构浏览与数据操作台，擅长：

- 看单个结构和散点。
- 搜索、圈选和按范围选择。
- 查看误差最大的结构。
- 标记 reject、删除、撤销和导出。
- 运行 FPS 等具体数据操作。

它回答的是：

> 我想看或处理哪些结构？

### Training Set Audit

Audit 不应复制 Show NEP 的图和工具栏。它应把整个数据集压缩成少量可以行动的结论，回答：

> 我现在有什么？哪里值得检查？相对目标缺什么？下一步先做什么？

Audit 负责诊断、归因和排序；Show NEP 负责查看和执行。两者通过结构索引、筛选预设和动作深链连接。

## 三、一句话产品定义

训练集评估把当前数据、可选目标和可选模型证据整理成一份可追溯的工作清单，帮助用户决定：先修数据、先确认采样偏重、补哪类结构，还是进入模型复验。

这不是一个自动给训练集打总分的页面，也不是通用分布画图工具。

## 四、设计假设：用户经常无法先说清完整目标

Pro 方案中“先选择快速体检、目标覆盖或模型验收”方向是正确的，但不应原样实现成长向导或强制模式选择。

真实用户经常只能先说：

- 我在做 Fe-Ni 合金。
- 我想查缺补漏。
- 我不确定这批数据是否合理。
- 我还不能完整描述温压、相、缺陷和物性边界。

如果页面要求先填完整目标画像，用户会在得到任何价值之前卡住。因此采用渐进式工作流：

1. 无需配置，先给出可信的数据盘点和内部问题。
2. 用户看到数据地图后，再用很小的表单声明关注范围。
3. 有目标结构、轨迹或模型证据时，页面自然升级结论。

“目标未知”是合法状态，不是空页面。

## 五、最终信息架构

页面不再以三个互斥模式开场，而使用一个连续工作流。

### 1. 概览

默认首屏，不需要任何配置。必须回答：

- 当前检查的是哪个范围。
- 数据集中有什么。
- 是否存在明确数据阻塞。
- 最显著的采样集中或薄弱事实是什么。
- 当前最值得做的三件事是什么。

### 2. 数据地图

按物理用户能理解的对象组织：

- 组成盘点。
- 结构家族与 `config_type`。
- 原子数、晶胞、来源和轨迹。
- 标签覆盖和范围。
- 局域环境支持。

Local chemistry、Pair contacts 和通用分布图进入这里的证据层，不再占据产品首页。

### 3. 复核队列

集中展示需要人处理的结构组：

- 数据阻塞。
- 标签冲突。
- 疑似重复与泄漏。
- 固定分位尾部复核集合。
- 用户从数据地图中加入的关注组。

每组支持查看、接受、隔离、标记待重算和导出。第一阶段复用 Show NEP 的 selection/reject/export，不自动删除。

### 4. 目标与模型

这是渐进增强区域，不是使用 Audit 的前置条件。

- 没有目标时显示“尚未定义目标，因此不能判断缺口”。
- 添加简单目标后，数据地图叠加目标范围并产生目标相关 Finding。
- 添加目标数据或轨迹后，比较真实结构与局域环境。
- 存在参考/预测数据后，显示模型误差切片和薄弱区域。

### 5. 高级证据

保留 Distribution Explorer、详细直方图、局域配位和元素对统计，供用户追溯结论，不作为默认阅读顺序。

- 一个虚构的综合分数。

## 七、组成盘点是第一个必须重做的证据模块

当前逐元素宽分箱会隐藏纯端元和精确采样峰。新版组成数据模型必须：

- 按归一化原子分数聚合，而不是按原始化学式或超胞原子数分组。
- `Ni6Fe10` 和 `Ni12Fe20` 都归入 37.5 at.% Ni。
- 纯元素端元始终单独展示。
- 同时保留原子数、`config_type`、来源和标签覆盖作为下钻维度。
- 输出主要组成点、Top-N 占比和组成点数量。
- 每个组成点都能选择回 Show NEP。

图形规则：

- 二元体系：精确组成棒棒糖图或柱图，横轴为原子百分比；默认不分宽 bin。
- 三元体系：三元组成图加可排序表格。
- 四元及以上：组成表格和可选择的二维投影，不强行显示不可读的高维图。

“数据集中在某些组成”与“结构内部元素偏聚”必须分开：

- 前者是训练集采样分布，组成盘点即可回答。
- 后者是相同全局组成下的局部化学有序，需要按组成和结构类型分层的短程有序分析；不能用原始元素对接触数冒充。

## 八、Finding 与下一步动作

Finding 不再等同于首页的一行告警。首页只消费排过优先级的工作项。

优先顺序：

1. 数据契约阻塞。
2. 标签冲突、切分泄漏和来源不一致。
3. 与用户目标直接相关的缺口。
4. 有独立证据支持的模型薄弱区。
5. 需要用户确认的采样集中、稀疏和冗余事实。
6. 缺少输入导致的“下一步先提供什么”。

每个工作项必须包含：

- 一句话事实。
- 为什么现在值得看。
- 结论成立需要什么条件。
- 受影响结构数。
- 一个主动作。
- 一个查看证据入口。

没有目标时，允许建议“确认是否符合预期”或“设置目标”，但不能直接建议补数据。

## 九、最小目标定义

第一版不实现完整的温压、相、缺陷、物性长表单。先支持用户最容易表达的三类目标：

- 组成范围或离散组成点。
- 关注的 `config_type`/结构家族。
- 可选目标数据集或轨迹。

示例：

```text
我关注：Ni 0–40 at.%
重点组成：0%、12.5%、25%、37.5%
结构类型：bulk、vacancy、surface
```

只有这些目标已声明后，页面才可以把数据内部事实解释为：目标内有支持、目标内偏薄或目标点没有样本。

温度、压力、应变、磁态和性质模板在真实 metadata/协议出现后逐步增加，不先建设空表单。

## 十、模型证据如何进入同一工作流

模型验收不另起一套页面语言。参考值和预测值存在时，在同一数据地图上增加：

- 总体 E/F/V 误差。
- 按组成、`config_type`、元素和标签大小分层的误差。
- 误差最大的结构组，而不是只有最大单点。
- 与目标范围交叉后的误差。

模型误差 Finding 与数据分布 Finding 使用同一个复核队列和 Show NEP 深链。

没有独立参考时明确显示“未评估”，不把标签尾部或模型 cutoff 统计称为模型风险。

## 十二、重新排序后的实施路线

### 新 P0：让用户看懂自己有什么

1. 实现可复用的 `DatasetInventory`，输出组成、端元、结构大小、`config_type`、来源和标签盘点。
2. 重做组成模块，按精确归一化组成聚合。
3. 重做 Audit 首屏，显示数据概况、当前判断和三个下一步。
4. 将 Composition/Local chemistry 的低频信号移出首页工作项。
5. 所有概况和工作项深链到 Show NEP 的结构选择。

### 新 P1：形成复核工作队列和简单目标比较

1. 复核、接受、隔离、待重算状态。
2. 组成范围、离散组成点和 `config_type` 目标。
3. 目标内支持/偏薄/无样本比较。
4. HTML 与 GUI 使用同一工作项和状态。

### 新 P2：接入真实模型薄弱区

1. 复用现有 reference/prediction/error 数据。
2. 按组成、结构家族和元素切片。
3. 将高误差结构组加入同一复核队列。

### 新 P3：目标轨迹和局域环境缺口

1. 独立脚本验证 descriptor novelty。
2. 比较训练集和目标结构/轨迹。
3. 选择最值得补算的代表结构。

Distribution 深链、旧 Dialog 清理和更多高级图不再排在新 P0 之前。

## 十三、验收标准

使用一个 FeNi-like fixture，首次进入页面且不做任何交互时，用户必须能够回答：

- 当前检查的是多少结构。
- 纯 Fe 和纯 Ni 各有多少。
- 数据主要集中在哪三个组成。
- 前三个组成占多少。
- 是否存在训练阻塞。
- 现在建议先做哪三件事。

两次点击内必须能够：

- 在 Show NEP 中查看全部纯 Ni 结构。
- 查看占比最高的组成结构。
- 查看任一 blocker/review 工作项对应结构。

没有目标时，页面不得声称“缺少某组成”；设置目标后，必须清楚区分：

- 目标内有样本支持。
- 目标内样本较薄。
- 目标点没有样本。

## 十四、已确认的产品决定

2026-07-14 已确认：

1. Audit 采用一个渐进式工作流，而不是要求用户先选择三个模式。
2. 新 P0 优先完成“数据盘点 + 下一步”，暂停继续完善高级分布图。
3. 没有目标时只报告内部事实；目标可以从最小的组成范围和结构类型开始，而不是完整物理画像。

## 十五、2026-07-14 实施结果

当前 Qt 页面已经按本文落成四个一级页面：

1. **概览**：显示活动范围、结构数、精确组分点、元素、E/F/V 标签可用率、Top 组成、纯元素端点、当前判断和三个下一步。
2. **数据地图**：默认显示精确组分棒棒糖图与表格；支持元素切换、线性/对数坐标、按组成点回到 Dataset Display。原有局域化学、元素对、标签尾部和通用数值分布保留在“进阶证据/数据分布”。
3. **复核队列**：集中展示 blocker、重复几何、标签尾部和低频证据；每项保留事实、解释、限制和结构深链，并支持本次会话记录处理状态。
4. **目标与模型**：支持按元素输入范围、离散组分点和最低结构数，输出“数量规则已满足 / 数量偏少 / 没有精确样本 / 无法判断”。模型证据不存在时明确显示未评估。

多元体系的一维元素分数图按所选元素分数聚合：例如多个不同 Co/Ni 配比但 `V=0%` 的精确组分在图上合并为一个 V 分数点，表格仍保留全部精确组分用于下钻，避免同一横坐标重复绘制和标签遮挡。

关键组分点不是必填项。只设置范围时，页面列出范围内已有的元素分数点并检查其数量规则，同时明确说明这种模式不能判断已有点之间是否缺样本；填写关键组分点后，才检查明确目标点的支持、偏薄或无精确样本。

核心数据由 `build_audit(context) -> AuditRun` 返回的 `DatasetInventory` 提供，Qt 页面不重新计算组分。相同原子分数、不同超胞大小会合并成一个组分点，同时保留原子数、化学式/`config_type` 和原始结构索引用于下钻。

真实 FeNi 验证结果：

- 55,985 个结构，33 个精确组分点，16/32 原子结构。
- 纯 Fe 596，纯 Ni 943。
- 37.5%、18.75%、12.5% Ni 分别为 28,746、11,960、5,148 个结构，合计 81.9%。
- 无 blocker；42 个结构属于 14 组重复几何，作为 review set，不自动删除。

仍未完成的边界：

- 复核状态尚未写入可复用快照或报告。
- `config_type` 目标筛选尚未接入目标比较。
- 模型误差切片、目标轨迹和真正的局域偏聚/短程有序分析尚未实现。
- 当前“数量规则已满足”只表示显式结构数阈值达到，不代表局域环境或物理空间已经覆盖。

## 十六、2026-07-17 磁序与空间布局调整

数据含逐原子 `spin:R:3` 时，数据地图增加结构级磁序、结构相 × 磁序、逐元素局部自旋模式及异元素近邻耦合。逐元素结果使用“对齐（类铁磁）”“补偿（类反铁磁）”等单帧自旋子晶格表述，不把 Fe、Ni 等元素单独声明成热力学磁相。所有离散分组均保存真实结构索引并可回到 Dataset Display。

页面空间按任务重新分配：

1. 完整的数据集名称、运行标识、重新检查和报告导出只放在“概览”，不再占用四个一级页面的共同高度。
2. “组分地图”主体改为可拖动的左右分栏。左侧是当前结构相/磁序结论与主图，右侧是精确组分表、相/磁序交叉筛选和结构下钻。
3. 右侧表格默认展示精确组分、结构数、占比、结构相/磁序和证据覆盖五个判断字段；原子数和构型类型保留在组分单元格提示及 HTML 报告中，不再挤压主判断列。
4. 在 1192×716 的桌面窗口与完整 V–Co–Ni 数据上，默认分栏约为 514/632 px，精确组分表获得约 455 px 高度，左侧磁序图约 220 px；左右比例可由用户拖动调整。

## 十七、2026-07-18 P0 产品收敛

本轮不增加新算法，只修正默认状态、证据层级和行动闭环：

1. 目标默认是“未设置”，不再自动应用 1,000 个/点；最低支持量规则默认关闭，只有用户主动启用后才出现“达到/低于数量规则”。
2. 目标比较支持精确 `config_type` 结构家族，并区分“无匹配样本”和“元数据不足，无法完整判断”。
3. 默认组成图始终展示原始精确组成计数；表格默认展示精确组成、结构数、占比、原子数和 `config_type`。相结构与磁序按需计算，完成后可显式切换到按结构相或磁序着色的样本数量：柱高仍是样本数，柱内彩色分段表示相对占比。只有用户从组分地图直接发起分析时，完成后才自动切到结构相着色视图；后台结果不会擅自改图。
4. 复核队列只保留 blocker 和 review。重复几何按组展开，每组独立记录“有意保留 / 隔离候选 / 需要重算”等状态；状态以数据快照和工作项共同命名空间隔离。
5. 首页主要组成点和纯元素端点提供直接结构动作；首页不再显示低频信号数量，也不再把相结构检查固定为默认下一步。
6. 模型空状态明确要求通过结构映射与单位校验的独立参考值和预测值；Show NEP 对当前训练数据的预测只用于误差浏览，不自动视为独立验收证据。

这次调整遵循“概览负责身份和结论、数据地图负责比较和下钻”的边界。后续不应再向数据地图顶部增加全局状态卡；新的次要元数据优先进入单元格提示、选中行详情或报告。

## 十八、2026-07-20 磁类型与占比视图收敛

结构级磁分类收敛为 FM、AFM、FiM、PM-like、其他非共线、未识别、低／零磁矩和无 `spin`。不再把有限 q 峰直接命名为螺旋磁序；证据不足时进入“未识别”。AFM 在结构级判定之后再检查周期层序，并把 `↑↓` 和 `↑↑↓↓` 分别显示为逐层 AFM 和双层 AFM。周期方向出现一个完整层序单元即可确认，周期边界负责后续重复。

磁类型进阶证据固定提供三张按结构帧数归一化的可点击 100% 堆叠图：结构相到磁类型、磁类型到结构相，以及整个训练集的磁类型占比。混合局域结构、未识别、低／零磁矩和无 `spin` 保持独立颜色段。`Config_type` 只作为来源元数据展示，不参与结构相或磁类型判断。
