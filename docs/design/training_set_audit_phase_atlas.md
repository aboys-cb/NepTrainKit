# Training Set Audit：相与组分地图设计

## 1. 用户最终要得到什么

Training Set Audit 不应只展示抽象指标，而应直接回答下面几个问题：

1. 训练集中主要有哪些结构相和化学有序类型？
2. 每个组分区间分别以什么相为主，混入了哪些少数相？
3. 哪些结构无法可靠归类，可能是缺陷、液态、界面、未知有序或坏数据？
4. 目标组分附近是否缺相、缺少数环境或分布严重失衡？
5. 下一批数据最值得补什么？

页面中的“相与组分地图”应以可行动结论为中心，而不是把用户留在一组需要自行解释的图和指标前。

## 2. 建议的产品形态

### 2.1 数据集总览

总览只展示四类信息：结构数与原子数、元素与组分范围、标签完整性、相图结论。相图结论使用自然语言，例如：

> Ni 富集区主要是 FCC/A1；50 at.% 附近同时出现 FCC/L1₀ 与未知有序环境；低 Ni 区样本明显不足。

### 2.2 相与组分地图

横轴为关键组分，纵向不再堆叠难懂指标，而是展示：

- 每个组分箱中的结构数；
- 主相及其比例；
- 次要相及其比例；
- 未知或低置信结构比例；
- 点击后可进入对应结构列表。

关键组分不应成为必填项。默认自动选择变化范围最大、对分层最有信息量的元素；用户只有在需要研究特定组分时才手动切换。

### 2.3 相识别结果的表达

结果必须区分三个层次：

- 几何骨架：FCC、BCC、HCP、SC、diamond、unknown；
- 化学装饰：A1/A2、L1₀、L1₂、B2、pure、unknown ordering；
- 置信状态：已知、低置信、参考库外。

“未知”不是失败，而是 Audit 最有价值的信号之一。系统不得为了让图好看而把参考库外结构强行归入最近的已知相。

## 3. PhaseSketch 原型

PhaseSketch 是一个与 UI 解耦的研究原型。它将局域信息拆成两条互不混淆的路径：

1. **几何指纹**：归一化近邻距离、壳层间隙、旋转不变键序特征、局域拓扑条码和角度分布；
2. **化学指纹**：中心原子与邻居的同类相关、径向加权的组分集中度、熵和有效物种数。

化学指纹对元素编号重标记不敏感，并使用连续径向窗口，避免固定截取前 4、6、8 个邻居时切断简并配位壳层。几何分类与化学有序分类分别完成，再通过原型云距离进行开放集拒识。

A1/A2 参考不是固定的二元 50:50 模板，而是覆盖二元、三元、四元及多种组分的随机占位族。否则三元随机固溶体会因为物种数和总体组分不同而被错误地标成未知有序。

这一设计的特色不是再造一个 PTM，而是把“晶格骨架”和“谁占据了什么局域环境”分开。这样既能识别常见相，也能明确指出“几何仍是 FCC，但化学排序不属于已知 A1/L1₀/L1₂”。

## 4. 与 OVITO PTM 的首轮对比

### 4.1 数据集

首轮基准包含 80 个参考帧、65 个独立测试帧和 8,190 个测试原子。测试覆盖：

- FCC pure/A1/L1₀/L1₂；
- BCC pure/A2/B2；
- HCP、SC、diamond；
- 热扰动、强扰动、空位和非正交晶胞；
- 参考库外 A15、非晶结构和 FCC/L1₁ 化学有序。

训练与测试使用不同随机种子，测试扰动未直接进入参考帧。

### 4.2 结果

| 指标 | PhaseSketch C++/OpenMP | OVITO PTM |
|---|---:|---:|
| 几何相准确率 | 100.0% | 64.6% |
| 完整相标签准确率 | 100.0% | 56.9% |
| 完整相标签 macro-F1 | 100.0% | 58.8% |
| 未知几何召回率 | 100.0% | 100.0% |
| 未知化学有序召回率 | 100.0% | 0.0% |
| 吞吐（8 OpenMP 线程） | 29,129 atoms/s | 36,659 atoms/s |

PTM 将未收录的 L1₁ 测试结构识别为 FCC/A1；PhaseSketch 保留 FCC 几何判断，同时将化学有序标为 unknown。强扰动下 PhaseSketch 的优势主要来自学习到的容差范围和开放集分类，并不代表所有强扰动结构都具有物理上明确的晶相。

Python 参考路径为 2,114 atoms/s。单精度 C++/OpenMP 特征核与混合近邻后端达到 29,129 atoms/s，提升 13.8 倍。线程扩展实验中，1、4、8 线程吞吐约为 8,264、21,301、28,237 atoms/s；最终混合近邻策略在 8 线程下进一步达到 29,129 atoms/s。小结构使用单精度 OpenMP 近邻核，大结构回退到 cKDTree，避免原型中的平方复杂度路径扩大。

### 4.3 不能从这轮结果推出什么

这是一套合成、同相族留出基准，不能据此宣称在真实 MD、缺陷、界面和多相训练集上全面优于 PTM。PTM 使用默认 RMSD 阈值；部分强扰动样本也可能已不应被视为理想晶相。产品集成前仍需真实数据盲测，并以人工/OVITO 联合标注作为验收依据。

### 4.4 V–Co–Ni 真实数据盲测

在 `/Users/superbing/Desktop/f_VCoNi.xyz` 上完成了第一轮只读抽样。数据集包含 10,602 个结构、339,264 个原子和 66 个精确组分点；每个组分点使用固定种子的 reservoir 抽取 10 个结构，共检查 660 个结构。

没有真实相标签，因此这里只能报告方法一致性，不能报告准确率：

| 几何判断 | PhaseSketch | PTM |
|---|---:|---:|
| FCC | 551 | 369 |
| BCC | 101 | 81 |
| unknown | 8 | 210 |

两种方法的几何标签一致率为 66.8%。共同识别出 360 个 FCC 和 81 个 BCC；PhaseSketch 额外将 PTM 的 191 个 unknown 判为 FCC、19 个判为 BCC。这个结果可能说明 PhaseSketch 对畸变更宽容，也可能包含过度归类，必须抽查这些分歧结构后才能决定。

数据盘点同时给出了一个直接可用的答案：纯 Ni 结构共有 **161 个**。在其中固定抽取的 10 个结构里，PhaseSketch 判断 9 个 FCC、1 个 BCC；PTM 判断 6 个 FCC、1 个 BCC、3 个 unknown。这个 BCC 纯 Ni 样本和双方分歧样本应成为下一轮人工复核的首批对象。

真实数据还证明产品不能只显示一个全局“主相”：相比例随 Ni 含量明显变化，并且部分组分箱的 `unknown ordering` 较高。评估工具已经输出按精确组分、按单元素浓度聚合的相比例，以及可下钻的结构索引；这些字段可以直接成为未来“相与组分地图”的数据契约草案。

### 4.5 L1₂ 与 Laves 候选相复核

这轮复核使用 AFLOW 的 C14 MgZn₂、C15 MgCu₂、C36 MgNi₂ 标准原型，而不是自行猜测晶格。三种超胞分别包含 216、162、432 个原子。首先按 Laves 相的已知局域化学配位做独立校验：A 位 Z16 应有 4A+12B，B 位 Z12 应有 6A+6B。三个原型的配位错误均为 **0**，第一、第二壳层的最小间隙比分别为 1.398、1.477、1.397。

候选专用检查在随机应变、剪切和最高约 8% 最近邻距离的位移噪声下，正确配位比例仍为：

| 原型 | 无扰动 | 中等扰动 | 最强扰动 |
|---|---:|---:|---:|
| C14 | 100.0% | 100.0% | 91.2% |
| C15 | 100.0% | 100.0% | 92.6% |
| C36 | 100.0% | 100.0% | 94.4% |

作为反例，将 FCC、BCC、HCP 和 diamond 全部随机装饰成相同 AB₂ 化学计量后重复测试，最高配位匹配率只有 **18.1%**。这说明“AB₂ + Z12/Z16 化学配位”适合作为 Laves 候选门控，但还不能替代完整的 Frank–Kasper 拓扑检查。

在 B 位的 6 个同类最近邻上计算归一化 centrosymmetry parameter 后，理想及受扰动样本的 B2 位比例稳定在：C14 约 0.75、C15 约 0、C36 约 0.375。这与 LaCA 用 B1/B2 局域环境区分 C14/C15 的物理思路一致。这里必须保留一个边界：**C36 的全局 B2 比例也可由 C14/C15 混合得到**。因此当前证据只支持“理想整块 C36-like”提示，不能支持逐原子 C36 缺陷识别，也不能把 C14/C15 层错混合强行标成 C36。C36 的正式判定必须再检查跨多个四层单元的堆垛序列。

通用 PhaseSketch 不能直接承担这项工作：未加入 Laves 参考时，它在低、中扰动下会拒识 Laves，但在最强扰动下会将三种 Laves 都误报为 FCC/A1。OVITO 标准 PTM 在低扰动下则会把 Laves 的大量 Z12 环境显示为 ICO，较强扰动后转为 unknown。结论是不能简单地把 `C14/C15/C36` 三个名字塞进现有平面分类器，必须使用候选专用的分层验证。

L1₂ 的结果更明确：在同一组四档应变/噪声下，PhaseSketch 四档均保持 FCC/L1₂；PTM 在最强扰动档转为 unknown。引入反位缺陷后，PhaseSketch 在 1.9% 原子交换时仍判为 L1₂，在 5.6% 和 11.1% 时保留 FCC 骨架但将化学有序标为 unknown，在 24.1% 以上转为 A1。这个行为比把部分有序结构硬分成 L1₂/A1 更诚实，但产品不能只显示离散标签，还应显示反位比例或连续有序度。

候选细化实现的反例复查推翻了一个最初假设：只检查 FCC 第一配位壳和 12 个最近邻的 AB₃ 占位时，AFLOW 的 D0₂₂ Al₃Ti 和 D0₂₃ Al₃Zr 都会被 100% 错判为 L1₂。两者是与 L1₂ 很接近的四方 A₃B 有序竞争相，常见 FCC/BCC/HCP 反例无法暴露这个错误。实现现已增加第二配位壳约束：L1₂ 的 A 位要求第一壳 0A+12B、第二壳 6A；B 位要求第一壳 4A+8B、第二壳 0A+6B。修正后 D0₂₂、D0₂₃ 均不再被确认为 L1₂。

复核过程中还发现并修复了 Python 非正交周期近邻的边界缺陷：已经包回主晶胞的位置被二次包裹时，浮点负零可能把中心原子移动到相邻像，导致零距离 self-neighbor 混入。修复后 C14/C15/C36 三个原型的配位错误从 0/33/4 统一降为 0，并增加了非正交边界原子的 Python/C++ 双路径回归测试。

## 5. 性能实现边界

- C++ 核内部使用 `float` 计算近邻向量、局域形状、化学配位和 B1/B2 CSP；
- 支持正交与可逆非正交晶胞；
- OpenMP 是可选能力，没有 OpenMP 时保持串行正确性；
- Python 实现保留为数值 oracle 和不支持平台的回退；
- 所有尺寸统一使用原生 Cartesian cell list：先将周期位置包回主胞，按倒易晶格界限生成必要周期像，再在笛卡尔网格的相邻桶中恢复精确最近邻；请求近邻不足或第 K 邻居逼近搜索边界时自动扩大半径；
- SciPy cKDTree 不再承担安装扩展后的生产路径，只作为无扩展环境的回退和独立数值 oracle；
- `refine_l12()` 与 `refine_laves()` 的逐原子形状匹配、第一/第二壳化学检查、CSP 和结构级聚合均已下沉到 OpenMP 核；Python 只保留元素角色解析、保守标签门控和无扩展环境的参考回退；
- 局域细化核下沉后的上一轮中位耗时为 1.19/5.79/2.64/13.00 ms；cell-list 接入后，8 OpenMP 线程、热缓存、31 次取中位分别降至：108 原子 L1₂ 0.18 ms、216 原子 C14 0.30 ms、162 原子 C15 0.27 ms、432 原子 C36-like 0.56 ms，本轮再提升 6.5–23.4 倍；相对最初 Python 局域细化版本，结构级总耗时累计下降约 43–99 倍；
- C36 当前近邻阶段约 0.32 ms、局域细化约 0.19 ms，二者均已进入亚毫秒区间，不再存在值得继续微调的 Python 逐原子热点。

## 6. 产品集成门槛

只有同时满足以下条件，PhaseSketch 才进入 Training Set Audit：

1. 在至少三套真实合金训练集上，与 PTM 和人工抽查对比；
2. 分别报告常见相准确率、未知拒识、少数相召回和混淆矩阵；
3. 非正交晶胞、原子顺序、元素编号重标记和周期平移测试通过；
4. 对 5k、50k 结构给出端到端耗时和内存上限；
5. UI 能从相图直接进入结构列表，并始终展示置信状态和方法边界；
6. 不把结构级主相推断包装成逐原子相分数。

## 7. 候选细化的正式设计

候选相由用户按研究背景选择，但关键元素或关键组分点不应成为必填项。系统先根据整体化学计量和局域占位自动推断元素角色，明确展示“当前按哪些元素归为 A/B 位”；只有多组元共占位、偏离 AB₂ 很远或自动推断不唯一时，才要求用户确认分组。

识别流程采用分层门控：

1. **L1₂**：先通过 FCC 几何门，再同时检查第一、第二配位壳的化学子晶格关系；输出 `L1₂`、`L1₂ partial`、`not L1₂` 或 `unknown`，而不是只给一个硬标签。`confirmed=true` 只用于完整门控通过的 L1₂。
2. **Laves**：先通过 AB₂/元素角色检查，再验证 Z12/Z16 Frank–Kasper 配位多面体的归一化三维形状和 4A+12B、6A+6B 化学配位；未过门控直接保持 `unknown`。
3. **C14/C15**：只在 Laves 门控通过后，用 B1/B2 centrosymmetry 和邻居类型关系统计区分。
4. **C36**：必须增加跨层堆垛序列证据；在这之前只显示 `C36-like / C14-C15 mixed`，不得给确定 C36 标签。
5. **缺陷**：将不符合主体模板的原子比例作为结果本身，供 Audit 显示空位邻域、反位、层错或未知局域环境，而不是用多数投票掩盖。

UI 中每个相结论至少同时展示：主体相、匹配比例、低置信/未知比例、自动元素角色和“查看这些结构”。用户选择细化候选后再运行对应检查，避免默认对所有复杂相做昂贵且难解释的穷举。

当前 falsification 集包含：64 个随机 AB₂ 的 FCC/BCC/HCP/diamond/SC/A15/sigma/fluorite 反例，3 个保持真实有序占位的 fluorite/rutile/C11b AB₂ 反例，48 个随机 AB₃ 的 FCC/BCC/HCP/A15 反例，以及 D0₂₂、D0₂₃ 两个最接近的有序 A₃B 竞争相。现有集合中没有出现错误确认；强扰动超出包络时返回 `unknown`。这只是进入真实数据盲测的 correctness gate，不等于已经覆盖所有 TCP 相和实际有限温度轨迹。

在完整 V–Co–Ni 数据集的 10,602 个结构上又执行了一次候选误报扫描。共有 1,204 个二元结构满足自动 AB₂ 角色推断条件，Laves 细化将它们全部保留为 `unknown`，错误确认数为 0；该数据集没有满足自动 AB₃ 推断条件的结构，因此这次真实扫描不能验证 L1₂。候选扫描本身耗时 3.35 s。由于数据集没有真相标签，这个结果只能证明“未出现大规模意外 Laves 误报”，不能证明未知结构中一定不存在 Laves。
