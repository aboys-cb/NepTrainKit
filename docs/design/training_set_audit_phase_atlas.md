# Training Set Audit：相与组分地图设计

## 1. 用户最终要得到什么

Training Set Audit 不应只展示抽象指标，而应直接回答下面几个问题：

1. 训练集中主要有哪些结构相和化学有序类型？
2. 每个组分区间分别以什么相为主，混入了哪些少数相？
3. 哪些结构无法可靠归类，可能是缺陷、液态、界面、未知有序或坏数据？
4. 目标组分附近是否缺相、缺少数环境或分布严重失衡？
5. 下一批数据最值得补什么？

页面中的“相与组分地图”应以可行动结论为中心，而不是把用户留在一组需要自行解释的图和指标前。

## 2. 建议的产品形态

### 2.1 数据集总览

总览只展示四类信息：结构数与原子数、元素与组分范围、标签完整性、相图结论。相图结论使用自然语言，例如：

> Ni 富集区主要是 FCC/A1；50 at.% 附近同时出现 FCC/L1₀ 与未知有序环境；低 Ni 区样本明显不足。

### 2.2 相与组分地图

横轴为关键组分，纵向不再堆叠难懂指标，而是展示：

- 每个组分箱中的结构数；
- 主相及其比例；
- 次要相及其比例；
- 未知或低置信结构比例；
- 点击后可进入对应结构列表。

关键组分不应成为必填项。默认自动选择变化范围最大、对分层最有信息量的元素；用户只有在需要研究特定组分时才手动切换。

### 2.3 相识别结果的表达

结果必须区分三个层次：

- 几何骨架：FCC、BCC、HCP、SC、diamond、unknown；
- 化学装饰：A1/A2、L1₀、L1₂、B2、pure、unknown ordering；
- 置信状态：已知、低置信、参考库外、长程无序。

“未知”不是失败，而是 Audit 最有价值的信号之一。系统不得为了让图好看而把参考库外结构强行归入最近的已知相。

## 3. PhaseSketch 原型

PhaseSketch 是一个与 UI 解耦的研究原型。它将局域信息拆成两条互不混淆的路径：

1. **几何指纹**：归一化近邻距离、壳层间隙、旋转不变键序特征、局域拓扑条码和角度分布；
2. **化学指纹**：中心原子与邻居的同类相关、径向加权的组分集中度、熵和有效物种数。

化学指纹对元素编号重标记不敏感，并使用连续径向窗口，避免固定截取前 4、6、8 个邻居时切断简并配位壳层。几何分类与化学有序分类分别完成，再通过原型云距离进行开放集拒识。

局域指纹之外增加一条独立的长程平移有序门：在晶胞倒空间的 13 组低指数方向上扫描有限谐波，取归一化 Bragg 强度最大值，并与随原子数和扫描波矢数变化的随机位置上限比较。它不负责判断 FCC/BCC，只负责阻止“液体的瞬时局域环境像 FCC”被包装成确定晶相。计算基于分数坐标，因此正交与非正交晶胞使用同一公式；部分周期或非周期结构不执行这一门控。

FCC/HCP/BCC 另有一条轻量的局域拓扑证据：计算标准自适应 CNA 的 421/422 以及 BCC 444/666 键型。它不替代 PhaseSketch 的强畸变分类，而是专门回答结构内部有多少 FCC-like、HCP-like、BCC-like 和其他/未解析环境，从而显式暴露层错、相界面及 BCC 局域区域。该核同样使用已有邻居数组并在 C++/OpenMP 中执行。

A1/A2 参考不是固定的二元 50:50 模板，而是覆盖二元、三元、四元及多种组分的随机占位族。否则三元随机固溶体会因为物种数和总体组分不同而被错误地标成未知有序。

这一设计的特色不是再造一个 PTM，而是把“晶格骨架”和“谁占据了什么局域环境”分开。这样既能识别常见相，也能明确指出“几何仍是 FCC，但化学排序不属于已知 A1/L1₀/L1₂”。

## 4. 与 OVITO PTM 的首轮对比

### 4.1 数据集

首轮基准包含 80 个参考帧、65 个独立测试帧和 8,190 个测试原子。测试覆盖：

- FCC pure/A1/L1₀/L1₂；
- BCC pure/A2/B2；
- HCP、SC、diamond；
- 热扰动、强扰动、空位和非正交晶胞；
- 参考库外 A15、非晶结构和 FCC/L1₁ 化学有序。

训练与测试使用不同随机种子，测试扰动未直接进入参考帧。

### 4.2 结果

| 指标 | PhaseSketch C++/OpenMP | OVITO PTM |
|---|---:|---:|
| 几何相准确率 | 100.0% | 64.6% |
| 完整相标签准确率 | 100.0% | 56.9% |
| 完整相标签 macro-F1 | 100.0% | 58.8% |
| 未知几何召回率 | 100.0% | 100.0% |
| 未知化学有序召回率 | 100.0% | 0.0% |
| 吞吐（8 OpenMP 线程） | 46,293 atoms/s | 35,939 atoms/s |

PTM 将未收录的 L1₁ 测试结构识别为 FCC/A1；PhaseSketch 保留 FCC 几何判断，同时将化学有序标为 unknown。强扰动下 PhaseSketch 的优势主要来自学习到的容差范围和开放集分类，并不代表所有强扰动结构都具有物理上明确的晶相。

Python 参考路径为 2,114 atoms/s。第一版单精度 C++/OpenMP 特征核达到 29,129 atoms/s；统一 cell-list、批处理和选择性置信复核完成后，不计算逐原子 CNA 比例时达到约 49,170 atoms/s。加入独立 C++ FCC/HCP/BCC CNA 后的 15 次中位为 46,293 atoms/s，同轮 PTM 为 35,939 atoms/s；不同轮次存在约 7% 的整机波动，因此以 PhaseSketch/PTM 吞吐比判断，加入 BCC 前后分别为 1.289 和 1.288，没有测到可分辨的新增成本。长程平移有序与局域比例加入后仍保持 100% 合成几何准确率和 100% 未知召回率。

### 4.3 不能从这轮结果推出什么

这是一套合成、同相族留出基准，不能据此宣称在真实 MD、缺陷、界面和多相训练集上全面优于 PTM。PTM 使用默认 RMSD 阈值；部分强扰动样本也可能已不应被视为理想晶相。产品集成前仍需真实数据盲测，并以人工/OVITO 联合标注作为验收依据。

### 4.4 V–Co–Ni 真实数据盲测

在 `/Users/superbing/Desktop/f_VCoNi.xyz` 上完成了第一轮只读抽样。数据集包含 10,602 个结构、339,264 个原子和 66 个精确组分点；每个组分点使用固定种子的 reservoir 抽取 10 个结构，共检查 660 个结构。

没有真实相标签，因此这里只能报告方法一致性，不能报告准确率。加入结构级开放集和局域支持率双重门控后，结果分为“最终标签”和“候选标签”：

| 几何判断 | PhaseSketch 最终标签 | PhaseSketch 候选 | PTM 0.10 | Adaptive CNA |
|---|---:|---:|---:|---:|
| FCC | 553 | 556 | 369 | 493 |
| BCC | 101 | 104 | 81 | 89 |
| unknown | 6 | 0 | 210 | 78 |

PhaseSketch 最终标签与默认 PTM 的几何一致率为 68.9%。其中有 72 个结构被 PhaseSketch 接受为已知相，但默认 PTM 和 Adaptive CNA 都返回 unknown。仅凭这一点不能把 72 个结构都当成 PhaseSketch 误判：将 PTM RMSD 门槛从 0.10 放宽到 0.12、0.15、0.20 后，分别有 59、68、69 个结构回到 PhaseSketch 的同一候选相。到 0.20 时只有 3 个结构转为相反晶相。

这轮复核暴露的真正问题不是“PhaseSketch 普遍过度归类”，而是结构级统计会掩盖少量局域证据冲突。新增二级门控只对结构森林概率低于 0.80 的样本计算逐原子原型证据；候选相的局域支持率低于 0.40 时，最终标签改为 unknown，并保留候选相供复核。V–Co–Ni 样本中该门控标出 4 个结构：`5173`、`5066`、`4859`、`6994`。其中后三个正是宽松 PTM 转为相反晶相的全部冲突样本；`5173` 是一个被保守拒绝、但宽松 PTM 仍支持 FCC 的强畸变样本。

结构级参考包络最初拒绝了 10 个结构，其中 8 个被 PTM 和 CNA 同时识别为 FCC。新增局域拓扑复核后，这 8 个结构以 `matched_local` 恢复为 FCC，只剩 2 个证据不足的 BCC 候选保持 `outside_reference`。这也证明结构摘要的包络不能凌驾于一致的局域拓扑证据，但局域复核必须明确标记来源，不能伪装成结构级模型本身更确定。

数据盘点同时给出了一个直接可用的答案：纯 Ni 结构共有 **161 个**。在其中固定抽取的 10 个结构里，PhaseSketch 判断 9 个 FCC、1 个 BCC；PTM 判断 6 个 FCC、1 个 BCC、3 个 unknown。BCC 样本 `5234` 同时得到 PTM 和 CNA 的 BCC 支持，不应因为“纯 Ni 通常是 FCC”而被先验删掉。FCC 样本 `2127` 在默认 PTM/CNA 下为 unknown，但 PTM 放宽到 0.12 后恢复 FCC，更像强畸变而不是明确错相。

真实数据还证明产品不能只显示一个全局“主相”：相比例随 Ni 含量明显变化，并且部分组分箱的 `unknown ordering` 较高。评估工具已经输出按精确组分、按单元素浓度聚合的相比例，以及可下钻的结构索引；这些字段可以直接成为未来“相与组分地图”的数据契约草案。

### 4.5 逐结构置信度契约草案

评估工具现在为每个抽样结构输出以下字段：

- `label`：通过全部门控后可展示的几何相；证据不足时为 `unknown`；
- `candidate`：结构模型给出的候选几何相，用于解释和复核，不直接当成确定结论；
- `confidence_state`：`matched`、`matched_local`、`mixed_local`、`low_local_support`、`outside_reference` 或 `diffuse_structure`；
- `structure_distance_ratio`：结构摘要到相应参考包络的归一化距离，`1.0` 是当前包络边界；
- `forest_probability`：结构分类器对候选相的内部投票比例；
- `translational_order_score` / `translational_order_limit`：长程平移有序强度及相同扫描规模下的有限尺寸随机位置上限；
- `cna_phase_fractions`：结构内 FCC-like、HCP-like、BCC-like 与 `other_or_unresolved` 的原子比例；
- `local`：只在结构级结果不够明确时计算，包含候选相局域支持率、局域 unknown 比例、原型距离和类间 margin。

这些状态的产品含义必须固定：`matched` 只表示“与当前参考库一致”；`matched_local` 表示结构摘要超出包络、但局域拓扑高度一致；`mixed_local` 表示同一结构内存在显著的 FCC/HCP 混合；`low_local_support` 表示候选相与局域证据冲突；`outside_reference` 表示结构有序但超出当前参考范围；`diffuse_structure` 表示长程平移有序不足。任何一种都不等于真实相标签。完整 PhaseSketch 分类器仍属于评估路径；Audit 首个生产契约没有在运行时拟合合成参考库，而是只发布已经独立验证的 Adaptive CNA 局域比例和 L1₂/C14/C15 保守细化。

### 4.6 Audit 生产契约与页面落地

Audit core 现已增加不可变 `PhaseInventory`，正式版本字段为：

- `schema_version = phase-inventory-v2`；
- `method_id = adaptive-cna-ordering-v1`；
- `reference_bank_id = aflow-l12-laves-v1`；
- `analysis_strategy = all-structures-v1`。

每个精确组分保存来源结构数、实际分析结构数、实际分析原子数、FCC/HCP/BCC/未解析局域比例、结构级主相比例、强/混合/未解析置信计数以及已确认的 L1₂/C14/C15 候选数。生产 Audit 不再按组分抽样或外推：当前 scope 内的每一个结构都进入相识别，精确组分、浓度聚合和相别筛选均由同一批完整结果生成。

结果跟随 `StructureData` 的不可变几何缓存保存，缓存键同时包含 scope 索引、方法版本、参考库版本和全量分析策略。相算法、缓存和 UI 之间只有这个结果契约，页面不直接调用 CNA 或候选细化内部函数。基础 Audit 先在工作线程中返回可用页面，相识别随后在独立工作线程中全量执行并报告精确进度；完成后以不可变结果替换缓存，重复进入页面直接命中 dataset 缓存。

组分地图的主图直接使用堆叠柱回答“这个元素浓度下有多少结构、分别是什么局域相”：柱高是完整结构数，颜色段是结构级相标签，点击颜色段只下钻该浓度与该相对应的真实结构索引。图下方表格保留精确组分、主要局域相、相证据、原子数和完整构型类型；超过四种构型时明确显示剩余数量，并在提示中列全，不再静默截断。主相不足 50% 时明确显示“混合”，不以相对多数冒充多数相。

精确组分行提供结构级相别筛选，“查看结构”始终把全量结果中的真实来源索引交给现有 Show NEP。进阶证据新增“相与局域结构”维度，以结构级相标签和证据强度两张可点击分布图展示完整 10,602 个结构；选择任一类别都可直接回到对应结构。页面始终说明这是训练集中的局域结构分类，不是热力学稳定相预测，也不把“未解析”强行归入已知相。

HTML 报告只允许在全量相分析完成后导出，并以纯 HTML/CSS 为每个元素生成“浓度—相标签”堆叠图。图中的柱宽与颜色分别代表该浓度下的完整结构数和结构级相标签，精确组分长表继续保留用于追溯；报告不再把相随浓度变化重新藏回表格。

在 `/Users/superbing/Desktop/f_VCoNi.xyz`、10 个物理核心、`OMP_NUM_THREADS=8` 上，基础 Audit 五轮中位为 0.880 s，页面此时已经可用；随后全量分析 10,602 个结构、339,264 个原子的相证据，三轮中位为 1.697 s。首次完整证据约在 2.62 s 后就绪，但不阻塞用户先看总览、标签和复核队列；同一 dataset 再次请求相证据耗时 0.555 ms。

完整性门逐项校验了 66 个精确组分的来源结构数与分析结构数相等，全体来源索引集合与当前 scope 完全一致，原子总数为 339,264，所有相别筛选均来自实际结构标签而非估算。旧的“每个组分最多 10 个结构 + 用户再点完整扫描”生产策略已经移除；抽样只保留在离线基准和参考模型评估工具中，并明确标为评估结果。

液体反例在加入长程门控前会被硬报为 FCC；现在最终标签为 unknown。钙钛矿具有很强 Bragg 有序，但仍被几何参考包络拒识，说明该门只排除长程无序，不会把“任意晶体”提升成已知相。有限尺寸上限来自随机位置零假设的保守近似，不应显示成严格统计显著性；它还需要更多熔体、非晶、界面和小晶胞反例校准。

### 4.8 FCC/HCP 界面与层错

使用解析 close-packed 堆垛构造了四组未进入训练参考的结构，并逐层与 OVITO PTM 对照：

| 结构 | PhaseSketch 局域比例 | PTM 局域比例 | 结构级状态 |
|---|---:|---:|---|
| 24 层 ABC 纯 FCC | FCC 100% | FCC 100% | FCC / matched |
| 24 层 AB 纯 HCP | HCP 100% | HCP 100% | HCP / matched_local |
| 12 层 FCC + 12 层 HCP 相界面 | FCC 50%，HCP 50% | FCC 50%，HCP 50% | FCC candidate / mixed_local |
| 含一处本征层错的 23 层 FCC | FCC 91.3%，HCP 8.7% | FCC 91.3%，HCP 8.7% | FCC / matched |

这组反例证明单个“主相”标签不够：50/50 界面若只显示 FCC，会直接丢掉用户最关心的一半信息；层错结构虽然仍可显示 FCC 主体，也必须同时显示 8.7% HCP-like 局域环境。评估工具因此同时输出结构级标签和原子加权的 `cna_local_fractions`，并在按元素浓度聚合时使用估算原子数加权，而不是把一个大界面结构和一个小 bulk 结构等权。

同一套自适应 CNA 已扩展 BCC 444/666 拓扑。在 15 个 clean、热扰动、强扰动、空位和非正交形变 BCC 样本上，本实现与 OVITO PTM 的平均 BCC 原子比例分别为 57.77% 和 57.75%；逐条件差异主要发生在强扰动样本上。A15、diamond 和 simple cubic 反例均未被误报为 BCC。这里的逐原子结果仍不是通用全相空间分类器：TCP、钙钛矿和液体原子进入 `other_or_unresolved`。

### 4.9 L1₂ 与 Laves 候选相复核

这轮复核使用 AFLOW 的 C14 MgZn₂、C15 MgCu₂、C36 MgNi₂ 标准原型，而不是自行猜测晶格。三种超胞分别包含 216、162、432 个原子。首先按 Laves 相的已知局域化学配位做独立校验：A 位 Z16 应有 4A+12B，B 位 Z12 应有 6A+6B。三个原型的配位错误均为 **0**，第一、第二壳层的最小间隙比分别为 1.398、1.477、1.397。

候选专用检查在随机应变、剪切和最高约 8% 最近邻距离的位移噪声下，正确配位比例仍为：

| 原型 | 无扰动 | 中等扰动 | 最强扰动 |
|---|---:|---:|---:|
| C14 | 100.0% | 100.0% | 91.2% |
| C15 | 100.0% | 100.0% | 92.6% |
| C36 | 100.0% | 100.0% | 94.4% |

作为反例，将 FCC、BCC、HCP 和 diamond 全部随机装饰成相同 AB₂ 化学计量后重复测试，最高配位匹配率只有 **18.1%**。这说明“AB₂ + Z12/Z16 化学配位”适合作为 Laves 候选门控，但还不能替代完整的 Frank–Kasper 拓扑检查。

在 B 位的 6 个同类最近邻上计算归一化 centrosymmetry parameter 后，理想及受扰动样本的 B2 位比例稳定在：C14 约 0.75、C15 约 0、C36 约 0.375。这与 LaCA 用 B1/B2 局域环境区分 C14/C15 的物理思路一致。这里必须保留一个边界：**C36 的全局 B2 比例也可由 C14/C15 混合得到**。因此当前证据只支持“理想整块 C36-like”提示，不能支持逐原子 C36 缺陷识别，也不能把 C14/C15 层错混合强行标成 C36。C36 的正式判定必须再检查跨多个四层单元的堆垛序列。

通用 PhaseSketch 不能直接承担这项工作：未加入 Laves 参考时，它在低、中扰动下会拒识 Laves，但在最强扰动下会将三种 Laves 都误报为 FCC/A1。OVITO 标准 PTM 在低扰动下则会把 Laves 的大量 Z12 环境显示为 ICO，较强扰动后转为 unknown。结论是不能简单地把 `C14/C15/C36` 三个名字塞进现有平面分类器，必须使用候选专用的分层验证。

L1₂ 的结果更明确：在同一组四档应变/噪声下，PhaseSketch 四档均保持 FCC/L1₂；PTM 在最强扰动档转为 unknown。引入反位缺陷后，PhaseSketch 在 1.9% 原子交换时仍判为 L1₂，在 5.6% 和 11.1% 时保留 FCC 骨架但将化学有序标为 unknown，在 24.1% 以上转为 A1。这个行为比把部分有序结构硬分成 L1₂/A1 更诚实，但产品不能只显示离散标签，还应显示反位比例或连续有序度。

候选细化实现的反例复查推翻了一个最初假设：只检查 FCC 第一配位壳和 12 个最近邻的 AB₃ 占位时，AFLOW 的 D0₂₂ Al₃Ti 和 D0₂₃ Al₃Zr 都会被 100% 错判为 L1₂。两者是与 L1₂ 很接近的四方 A₃B 有序竞争相，常见 FCC/BCC/HCP 反例无法暴露这个错误。实现现已增加第二配位壳约束：L1₂ 的 A 位要求第一壳 0A+12B、第二壳 6A；B 位要求第一壳 4A+8B、第二壳 0A+6B。修正后 D0₂₂、D0₂₃ 均不再被确认为 L1₂。

复核过程中还发现并修复了 Python 非正交周期近邻的边界缺陷：已经包回主晶胞的位置被二次包裹时，浮点负零可能把中心原子移动到相邻像，导致零距离 self-neighbor 混入。修复后 C14/C15/C36 三个原型的配位错误从 0/33/4 统一降为 0，并增加了非正交边界原子的 Python/C++ 双路径回归测试。

评估数据契约现在把两类候选相的逐原子匹配率真正聚合到精确组分和单元素浓度：`candidate_local_phases` 记录当前组分中满足 AB₃/AB₂ 角色门控的结构数、确认数、标签分布、合格原子数和 `local_match_fraction`；`candidate_local_phase_estimates` 在浓度层按合格原子数加权。L1₂ 的局域匹配表示 FCC 几何与第一、第二壳化学子晶格同时通过；Laves 的局域匹配只表示 Z12/Z16 与 AB₂ 配位同时通过，C14/C15/C36 仍由结构级堆垛证据决定，不能把一个原子单独硬标成某种 Laves 多型。

在完整 V–Co–Ni 数据集的 660 个相图采样结构上，原子数加权估计为 FCC-like 56.16%、BCC-like 14.39%、HCP-like 0.06%、其他/未解析 29.39%。例如纯 Ni 组分为 FCC-like 71.56%、BCC-like 8.75%、其他/未解析 19.69%；50 at.% Ni 为 FCC-like 64.43%、BCC-like 1.92%、HCP-like 0.11%、其他/未解析 33.55%。这些是对每个精确组分固定抽样后外推到该组分结构数的估计，不是真值标签。

### 4.10 独立公开结构与有限温度压力测试

新增 `tools/validate_phase_blind_set.py`，从未参与模板生成的公开数据库下载结构并生成可复现 JSON 报告。正例使用 Materials Project `mp-2593` 和 OQMD `4065738` 的 DFT 弛豫 Ni₃Al、COD `5910078` 的实验 MgZn₂ C14、COD `1524810` 的实验 MgCu₂ C15；关键竞争相使用 COD `1527746` 的实验 D0₂₃-Al₃Zr。原始结构结果如下：

| 外部结构 | 本实现 | PTM | 结论 |
|---|---|---|---|
| MP `mp-2593` Ni₃Al | L1₂ / confirmed | FCC/L1₂ | 正确 |
| OQMD `4065738` Ni₃Al | L1₂ / confirmed | FCC/L1₂ | 正确 |
| COD `1527746` D0₂₃-Al₃Zr | L1₂ partial / not confirmed | FCC/L1₂ | 第二壳门控阻止近邻竞争相假确认 |
| COD `5910078` MgZn₂ | C14 / confirmed | ICO | 正确识别 Laves 多型 |
| COD `1524810` MgCu₂ | C15 / confirmed | ICO | 正确识别 Laves 多型 |

每个结构另做 8 个固定随机种子的应变、剪切和位移压力测试。低扰动下两个 L1₂ 与两个 Laves 正例均为 16/16 确认；中等扰动下 L1₂ 为 12/16 确认、4/16 降为 partial，C14/C15 为 16/16 正确。D0₂₃ 在 clean、低、中三档合计 17 个结构中始终 0 次确认，而 PTM 在 clean/低档全部报 FCC/L1₂。高扰动时 C14 为 4/8、C15 为 6/8，其余保守转 unknown；极端扰动全部转 unknown。随机扰动只用于测量算法边界，不能当成有限温度真值。

两份独立 Ni₃Al 弛豫结构还分别执行了固定晶胞、1 fs 步长、1 ps 的 ASE EMT Langevin NVT。目标温度 300、600、900、1200 K 下，两份结构均保持 L1₂ confirmed，局域联合匹配率最低 89.8%；目标 1500 K 下均降为 L1₂ partial，联合匹配率分别为 82.4% 和 77.8%，而 PTM 仍报 FCC/L1₂。这里保留 partial 是有意的：精确第一/第二壳化学关系已经低于确认门槛，不能仅凭整体 FCC 骨架继续给确定有序相。EMT 固定晶胞轨迹是独立的热扰动压力测试，不是 Ni₃Al 相图或熔点证据。

## 5. 性能实现边界

- C++ 核内部使用 `float` 计算近邻向量、局域形状、化学配位和 B1/B2 CSP；
- 支持正交与可逆非正交晶胞；
- OpenMP 是可选能力，没有 OpenMP 时保持串行正确性；
- Python 实现保留为数值 oracle 和不支持平台的回退；
- Audit 的 `PhaseInventory` 生产路径只使用已编译原生核；原生模块缺失时明确显示相证据不可用，不在用户等待界面静默运行慢速 Python 回退；
- 所有尺寸统一使用原生 Cartesian cell list：先将周期位置包回主胞，按倒易晶格界限生成必要周期像，再在笛卡尔网格的相邻桶中恢复精确最近邻；请求近邻不足或第 K 邻居逼近搜索边界时自动扩大半径；
- SciPy cKDTree 不再承担安装扩展后的生产路径，只作为无扩展环境的回退和独立数值 oracle；
- `refine_l12()` 与 `refine_laves()` 的逐原子形状匹配、第一/第二壳化学检查、CSP 和结构级聚合均已下沉到 OpenMP 核；Python 只保留元素角色解析、保守标签门控和无扩展环境的参考回退；
- 局域细化核下沉后的上一轮中位耗时为 1.19/5.79/2.64/13.00 ms；cell-list 接入后，8 OpenMP 线程、热缓存、31 次取中位分别降至：108 原子 L1₂ 0.18 ms、216 原子 C14 0.30 ms、162 原子 C15 0.27 ms、432 原子 C36-like 0.56 ms，本轮再提升 6.5–23.4 倍；相对最初 Python 局域细化版本，结构级总耗时累计下降约 43–99 倍；
- C36 当前近邻阶段约 0.32 ms、局域细化约 0.19 ms，二者均已进入亚毫秒区间，不再存在值得继续微调的 Python 逐原子热点；
- 置信门控的第一版对所有结构重复做逐原子原型分类，吞吐由 54.3k 降到 31.8k atoms/s，已经撤回。保留版只对结构森林概率低于 0.80 的样本触发原型复核；
- CNA 的融合核只有约 41.5k atoms/s，已经撤回。保留版使用独立位图核；微基准显示 32/108 原子结构启动 8 线程分别比串行慢约 4.2/1.5 倍，因此只在 256 原子以上启用 OpenMP。加入 BCC 444/666 后 15 次中位为 46.3k atoms/s，同轮 PTM 为 35.9k atoms/s；两者吞吐比为 1.288，与加入 BCC 前的 1.289 相同，因此没有测得可区分于机器波动的新增成本。相对完全不计算局域比例的历史 49.2k atoms/s，保守按约 6–12% 的总成本预算。

## 6. 产品集成门槛

只有同时满足以下条件，PhaseSketch 才进入 Training Set Audit：

1. 在至少三套真实合金训练集上，与 PTM 和人工抽查对比；
2. 分别报告常见相准确率、未知拒识、少数相召回和混淆矩阵；
3. 非正交晶胞、原子顺序、元素编号重标记和周期平移测试通过；
4. 对 5k、50k 结构给出端到端耗时和内存上限；
5. UI 能从相图直接进入结构列表，并始终展示置信状态和方法边界；
6. 不把结构级主相推断摊分成逐原子相分数；逐原子比例必须来自独立局域拓扑证据。

## 7. 候选细化的正式设计

候选相由用户按研究背景选择，但关键元素或关键组分点不应成为必填项。系统先根据整体化学计量和局域占位自动推断元素角色，明确展示“当前按哪些元素归为 A/B 位”；只有多组元共占位、偏离 AB₂ 很远或自动推断不唯一时，才要求用户确认分组。

识别流程采用分层门控：

1. **L1₂**：先通过 FCC 几何门，再同时检查第一、第二配位壳的化学子晶格关系；输出 `L1₂`、`L1₂ partial`、`not L1₂` 或 `unknown`，而不是只给一个硬标签。`confirmed=true` 只用于完整门控通过的 L1₂。
2. **Laves**：先通过 AB₂/元素角色检查，再验证 Z12/Z16 Frank–Kasper 配位多面体的归一化三维形状和 4A+12B、6A+6B 化学配位；未过门控直接保持 `unknown`。
3. **C14/C15**：只在 Laves 门控通过后，用 B1/B2 centrosymmetry 和邻居类型关系统计区分。
4. **C36**：必须增加跨层堆垛序列证据；在这之前只显示 `C36-like / C14-C15 mixed`，不得给确定 C36 标签。
5. **缺陷**：将不符合主体模板的原子比例作为结果本身，供 Audit 显示空位邻域、反位、层错或未知局域环境，而不是用多数投票掩盖。

UI 中每个相结论至少同时展示：主体相、匹配比例、低置信/未知比例、自动元素角色和“查看这些结构”。用户选择细化候选后再运行对应检查，避免默认对所有复杂相做昂贵且难解释的穷举。

当前 falsification 集包含：64 个随机 AB₂ 的 FCC/BCC/HCP/diamond/SC/A15/sigma/fluorite 反例，3 个保持真实有序占位的 fluorite/rutile/C11b AB₂ 反例，48 个随机 AB₃ 的 FCC/BCC/HCP/A15 反例，以及 D0₂₂、D0₂₃ 两个最接近的有序 A₃B 竞争相。现有集合中没有出现错误确认；强扰动超出包络时返回 `unknown`。这只是进入真实数据盲测的 correctness gate，不等于已经覆盖所有 TCP 相和实际有限温度轨迹。

在完整 V–Co–Ni 数据集的 10,602 个结构上又执行了一次候选误报扫描。共有 1,204 个二元结构满足自动 AB₂ 角色推断条件，Laves 细化将它们全部保留为 `unknown`，错误确认数为 0；该数据集没有满足自动 AB₃ 推断条件的结构，因此这次真实扫描不能验证 L1₂。候选扫描本身耗时 3.35 s。由于数据集没有真相标签，这个结果只能证明“未出现大规模意外 Laves 误报”，不能证明未知结构中一定不存在 Laves。
