# 从整体组成到数值分布

拿到陌生训练集时，先回答两个问题：数据由哪些元素组合构成、关键物理量是否存在覆盖空缺或异常长尾。主工具栏中的 `Training set check` 负责整体组成和证据概览，`Explore distributions` 负责展开具体数值字段。

## 先看训练集整体

加载数据后，点击主工具栏中的 `Training set check`。概览页会直接展示结构数、原子数、元素数和标签可用性，并用元素共现矩阵呈现训练集中一元、二元及多元组合的整体覆盖。

```{image} ../_static/image/generated/training_set_audit_overview.png
:alt: 训练集评估概览
:class: docs-screenshot
```

共现矩阵中的非对角单元格表示两个元素在同一结构中出现的频率；对角线表示单元素结构。点击一个元素后，左侧会聚焦显示与它相关的组合，便于查看它与哪些元素共同出现、哪些组合稀少或完全缺失。元素集合表保留精确的组合与占比，适合进一步核对。

这个页面取代了旧的 `Dataset summary` 弹窗。整体统计、元素组合和后续证据现在都在同一处查看，不再需要从保存菜单进入独立摘要。

## 再看力等关键字段

回到数据展示页，打开 `Explore distributions`，选择数据字段、统计范围和分组方式。本例查看 `force`，按元素分组，并用力的模长作横坐标：

```{image} ../_static/image/generated/tutorials/force_distribution.png
:alt: 按元素统计的原子力分布
:class: docs-screenshot
```

分布图可以比较不同元素或标签的覆盖范围，也可以切换参考值、预测值或误差，用同样方法检查能量、应力和磁力等字段。

概览负责发现“哪些组合存在或缺失”，数值分布负责发现“标签覆盖是否均衡”。发现孤立尖峰、异常长尾或某个组明显偏移后，再回到主界面选中对应结构，结合几何和原始计算结果复核。
