# Bain 路径（Bain Path）

**分类：** 晶格

## 功能说明

沿晶格 `a`、`b` 或 `c` 构造一条四方形变路径。默认扫描相对 `c/a = 0.95、1.00、1.05`，因此每个输入会得到 3 个不同形状的结构，而不是只复制原结构。

卡片提供三种路径：

- **恒体积**：改变四方形状，同时保持晶胞体积。
- **形状 × 体积网格**：每个形状点再组合一组相对体积。
- **自由四方轴**：只改变所选晶格矢量，另外两条保持不变。

:::{important}
输入晶胞应提前按目标四方轴定向。这里的 `a / b / c` 是三条晶格矢量，不是笛卡尔 `x / y / z`；程序不会自动重定向或把任意原胞转换成标准 Bain 晶胞。
:::

## 工作原理

### 以相对 c/a 为路径坐标

设 $q$ 是输出轴向／横向比例相对输入晶胞的倍数。`q=1` 保留输入比例，`q=1.05` 表示比例提高 5%。

恒体积模式对选中轴和两条横向晶格矢量分别使用

$$
f_{\parallel}=q^{2/3},\qquad
f_{\perp}=q^{-1/3}.
$$

因此 $f_{\parallel}/f_{\perp}=q$ 且 $f_{\parallel}f_{\perp}^2=1$：界面中的相对 `c/a` 就是真实比例变化，体积保持不变。

形状 × 体积模式再把三条晶格矢量统一乘以 $v^{1/3}$，所以

$$
\frac{V'}{V_0}=v.
$$

自由四方轴模式使用 $f_{\parallel}=q$、$f_{\perp}=1$，此时体积也随 $q$ 改变。

### 输出数量

普通路径的输出数为

$$
N_{\mathrm{out}}=N_{\mathrm{input}}N_q.
$$

形状 × 体积网格的输出数为

$$
N_{\mathrm{out}}=N_{\mathrm{input}}N_qN_v.
$$

界面会实时显示路径点数、体积点数和总输出数。

## 操作示例

### 近平衡三点路径

1. 输入已经按目标四方轴定向的结构。
2. 选择四方轴，例如晶格 `c`。
3. 保持路径坐标为“相对 c/a”、模式为“恒体积”。
4. 使用默认范围 `0.95 → 1.05，步长 0.05`。
5. 保持“原子随晶胞移动”开启。

若载入 8 个结构，界面会显示 `8 × 3 = 24` 个输出。每个输入生成压缩、原始和拉伸三个形状点。

需要同时覆盖体积响应时，选择“形状 × 体积网格”。例如 3 个形状点和 `0.95、1.00、1.05` 三个体积点，会为每个输入生成 `3 × 3 = 9` 个输出。

## 参数说明

### 路径定义

#### 四方轴（axis）

默认晶格 `c`。选择第一、第二或第三条晶格矢量作为四方轴；保存值继续使用 `x / y / z` 以兼容已有工作流。

#### 路径坐标（coordinate_mode）

默认 `relative_ca`，表示真实的相对轴向／横向比例。`axis_scale` 是旧工作流使用的轴向直接缩放因子：恒体积时选中轴乘 $s$，横向各乘 $s^{-1/2}$，实际相对 `c/a` 为 $s^{3/2}$。

旧 JSON 没有该字段时会自动按 `axis_scale` 恢复，保证原有几何行为不变；新建卡片使用 `relative_ca`。

#### 相对 c/a 扫描（ca_range）

默认 `(0.95, 1.05, 0.05)`，依次填写起点、终点和正步长。终点小于起点时会自动交换；所有路径值必须大于 0。

#### 路径模式（mode）

- `constant_volume`：恒体积四方路径。
- `scale_volume`：形状与体积的笛卡尔积。
- `free_c`：只改变所选晶格矢量。

#### 相对体积扫描（volume_scale_range）

默认 `(1, 1, 1)`，仅在 `scale_volume` 中显示并生效。`1.0` 表示输入体积，`0.95` 表示输入体积的 95%。

### 原子坐标

#### 原子随晶胞移动（scale_atoms）

默认开启：保持分数坐标，原子随晶胞仿射变形。关闭后保持笛卡尔坐标，只改变周期晶胞；这可能改变跨边界近邻关系，应有明确物理目的再使用。

## 常见问题

**为什么相对 c/a 填 1.2 后，所选晶格矢量不是直接变成 1.2 倍？**

恒体积路径需要同时补偿横向晶格。轴向乘 $1.2^{2/3}$、横向乘 $1.2^{-1/3}$，二者的相对比例正好改变 1.2 倍。

**为什么没有显示体积扫描？**

它只参与“形状 × 体积网格”。恒体积和自由四方轴模式各自已经确定体积变化规则。

**为什么旧工作流显示“轴向缩放（旧版）”？**

旧版本把 `ca_range` 当作直接轴向缩放因子。卡片会保留该计算语义，避免载入旧 JSON 后静默改变结构。

## 输出

新语义标签为 `Bain(ax={axis},ca={ca},V={V/V0},mode={mode})`；旧轴向缩放语义使用 `s={s}`。该操作无随机性，同一输入和参数会得到相同输出。
