# 晶格随机扰动（Lattice Perturb）

**分类：** 晶格

## 功能说明

围绕每个输入晶胞随机改变三条晶格矢量的长度，并可同时改变三个晶格角。它适合补充近平衡晶格附近的随机样本；若需要指定方向和固定步长的系统扫描，应使用“晶格应变”。

## 原理与公式

设最大相对变化为 $m$。程序为三条晶格长度分别抽取独立因子：

$$
f_a,f_b,f_c\in[1-m,1+m],\qquad
a'=f_a a,\ b'=f_b b,\ c'=f_c c.
$$

开启“同时扰动晶格角”后，还会独立抽取：

$$
g_\alpha,g_\beta,g_\gamma\in[1-m,1+m],\qquad
\alpha'=g_\alpha\alpha,\ \beta'=g_\beta\beta,\ \gamma'=g_\gamma\gamma.
$$

因此界面中的 `4%` 表示每条长度，以及启用时的每个角度，分别最多相对变化 ±4%；它不表示体积变化 ±4%。

关闭角度扰动且输入为正交晶胞时：

$$
\frac{V'}{V}=f_af_bf_c.
$$

例如 $m=0.04$ 时，理论体积边界约为 $0.96^3V=0.8847V$ 到 $1.04^3V=1.1249V$。开启角度扰动后，体积还取决于三个新角度，不能只由长度因子相乘得到。

原子分数坐标保持不变，Cartesian 坐标随晶胞变形。输入晶胞的全局取向会保留，不会因角度重建而额外整体旋转。

## 输出数量

“每个输入的输出数”为精确数量。若输入结构数为 $N_\mathrm{in}$，每个输入生成 $N_\mathrm{per}$ 个结构，则：

$$
N_\mathrm{out}=N_\mathrm{in}N_\mathrm{per}.
$$

例如 2 个输入、每个输入 50 个输出，会生成 100 个结构。若某组长度或角度会形成奇异晶胞，卡片会明确失败并提示减小扰动范围，不会返回零体积结构。

## 参数说明

### 采样序列（engine_type）

默认 `1`。`0` 为 Sobol，`1` 为 Uniform。

- Uniform：各输出独立均匀随机采样。
- Sobol：低差异序列，小样本时通常分布更均匀；输出数取 4、8、16、32、64 等 2 的幂时平衡性最好。

两种方式使用相同的参数范围，且都严格生成指定数量。

### 最大相对变化（max_scaling）

默认 `0.04`，序列化时保存为比例；界面显示为 `4%`。每条长度的乘法因子范围为 $[1-m,1+m]$，开启角度扰动后每个角度使用同一相对范围。

界面允许 `0%`～`20%`。建议先小范围生成并检查体积、晶格角和最近邻距离，再决定是否扩大。

### 每个输入的输出数（max_num）

默认 `50`，范围 `1`～`10000`。它控制覆盖密度，不改变扰动范围。

### 同时扰动晶格角（perturb_angle）

默认开启。开启后同时改变 $\alpha$、$\beta$、$\gamma$；关闭后只改变三条晶格长度，原始晶格角保持不变。

例如原始角为 $90^\circ$、最大相对变化为 `4%`，该角的采样范围是 $86.4^\circ$～$93.6^\circ$。

### 保持识别出的分子刚性（identify_organic）

默认关闭。开启后，程序在晶胞变形之后恢复检测到的分子团簇内部几何，减少晶格缩放直接拉伸分子内键的情况。分子识别结果应结合具体体系抽查，尤其是周期网络和 MOF。

### 使用随机种子（use_seed）

默认关闭。开启后显示随机种子输入，并使相同输入、参数和 seed 可复现。

### 随机种子（seed）

默认 `0`，仅在 `use_seed=true` 时生效。seed 会结合单帧结构内容派生，因此数据集重新排序不改变该结构的结果。

## 操作示例

### 补充近平衡晶格邻域

一个弛豫结构附近缺少晶格变化样本时，可先使用：

- 采样序列：Sobol
- 最大相对变化：`2%`
- 同时扰动晶格角：关闭
- 每个输入的输出数：`32`
- 使用随机种子：开启

这会为每个输入生成 32 个长度随机变化、晶格角不变的结构。生成后先查看体积分布和最近邻距离，再决定是否加入标注与训练流程。

```json
{
  "class": "CellScalingCard",
  "check_state": true,
  "params": {
    "engine_type": 0,
    "max_scaling": 0.02,
    "max_num": 32,
    "perturb_angle": false,
    "identify_organic": false,
    "use_seed": true,
    "seed": 42
  }
}
```

## 输出标签

`LSc(max={max_scaling},{U|S})`：`U` 表示 Uniform，`S` 表示 Sobol。

## 常见问题

**为什么设置 4% 后，体积变化会超过 4%？** 三条晶格长度分别独立变化；正交晶胞关闭角度扰动时，体积比是三个长度因子的乘积，而不是单个因子。

**为什么提示晶胞无效？** 当前长度与角度组合形成了奇异晶胞。减小最大相对变化，或关闭晶格角扰动后重新生成。
