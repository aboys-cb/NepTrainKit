# 晶格应变（Lattice Strain）

**分类：** 晶格

## 功能说明

沿输入晶胞的晶格矢量 $\mathbf a$、$\mathbf b$、$\mathbf c$ 扫描法向工程应变。可生成三条单轴路径、三组双轴网格、一个三轴网格、各向同性路径，或只组合用户指定的晶格轴。

这里的 `a / b / c` 是晶格矢量，不是 Cartesian `X / Y / Z`。对于旋转或非正交晶胞，两者不能混用。

## 原理与公式

给定百分数 $s_a,s_b,s_c$，工程应变为

$$
\epsilon_i=\frac{s_i}{100},\qquad i\in\{a,b,c\}.
$$

程序分别缩放晶胞矩阵的三条行向量：

$$
\mathbf a'=(1+\epsilon_a)\mathbf a,\quad
\mathbf b'=(1+\epsilon_b)\mathbf b,\quad
\mathbf c'=(1+\epsilon_c)\mathbf c.
$$

原子分数坐标保持不变，因此 Cartesian 坐标随晶胞作仿射变换。应变必须大于 `-100%`，否则对应晶格矢量会坍缩或反向。

## 模式与输出数量

设三组范围分别含 $N_a$、$N_b$、$N_c$ 个点：

| 模式 | 实际生成内容 | 去重前数量 |
| --- | --- | ---: |
| 单轴路径 | 分别扫描 $a$、$b$、$c$ | $N_a+N_b+N_c$ |
| 双轴网格 | 合并 $ab$、$ac$、$bc$ 三个网格 | $N_aN_b+N_aN_c+N_bN_c$ |
| 三轴网格 | 联合组合 $a$、$b$、$c$ | $N_aN_bN_c$ |
| 各向同性路径 | 使用第一组范围，令 $s_a=s_b=s_c$ | $N_a$ |
| 指定晶格轴 | 只组合选中的轴 | 所选范围点数的乘积 |

不同路径可能得到相同的应变向量。例如单轴扫描的三条路径都包含 `0%`，对应的都是原始结构。程序会按照 $(s_a,s_b,s_c)$ 去重，只输出一次完全相同的应变状态。

默认三组范围均为 `-5%～5%`、步长 `1%`，每组 11 个点。去重后的默认数量为：

- 单轴路径：31 个；
- 双轴网格：331 个；
- 三轴网格：1331 个；
- 各向同性路径：11 个。

若输入结构数为 $N_\mathrm{in}$，每个输入的去重后数量为 $N_\mathrm{per}$，则总输出为 $N_\mathrm{in}N_\mathrm{per}$。界面摘要会随模式和范围实时显示该数量。

## 参数说明

### 扫描模式（axes）

默认 `uniaxial`。可选值及含义：

- `uniaxial`：晶格 $a$、$b$、$c$ 三条单轴路径；
- `biaxial`：$ab$、$ac$、$bc$ 三组双轴网格；
- `triaxial`：$abc$ 三轴联合网格；
- `isotropic`：三轴使用同一个应变值；
- 自定义轴：序列化为 `X`、`XY`、`XZ` 等旧格式，界面显示为 `a`、`ab`、`ac`。

自定义轴不能重复，例如 `aa` 无效。

### 晶格 a 范围（x_range）

默认 `(-5, 5, 1)`，依次为最小值、最大值、步长，单位 `%`。控制晶格矢量 $\mathbf a$；各向同性模式也只读取这一组范围作为三轴共同应变。

### 晶格 b 范围（y_range）

默认 `(-5, 5, 1)`，控制晶格矢量 $\mathbf b$。各向同性模式下不生效，因此界面会隐藏。

### 晶格 c 范围（z_range）

默认 `(-5, 5, 1)`，控制晶格矢量 $\mathbf c$。各向同性模式下不生效，因此界面会隐藏。

三组范围都允许反向填写最小值和最大值，程序会按升序生成；步长必须为正数。

### 保持识别出的分子刚性（identify_organic）

默认关闭。开启后，程序先施加晶胞仿射应变，再恢复检测到的分子团簇内部几何。周期网络和 MOF 的识别结果应结合实际结构抽查。

## 操作示例

### 生成三条近平衡单轴路径

若训练集缺少晶格法向应变附近的结构，可设置：

- 扫描模式：单轴路径（a、b、c）；
- 三组范围：`-2%～2%`，步长 `1%`；
- 保持识别出的分子刚性：关闭。

每组有 5 个点，三条路径去重前为 15 个；三个 `0%` 状态合并后，每个输入生成 13 个独特结构。生成后应检查体积、最近邻距离及所需应力分量，再决定是否进入标注流程。

```json
{
  "class": "CellStrainCard",
  "check_state": true,
  "params": {
    "axes": "uniaxial",
    "x_range": [-2.0, 2.0, 1.0],
    "y_range": [-2.0, 2.0, 1.0],
    "z_range": [-2.0, 2.0, 1.0],
    "identify_organic": false
  }
}
```

## 常见问题

**为什么单轴模式不是只沿一个方向？** “单轴路径”会枚举 $a$、$b$、$c$ 三条路径。若只需要一条，选择“指定晶格轴”并输入 `a`、`b` 或 `c`。

**为什么输出数少于三个网格点数之和？** 不同路径重叠得到的相同应变向量只输出一次，最常见的是 `(0%,0%,0%)` 原始结构。

**为什么各向同性模式只显示一组范围？** 三条晶格矢量使用同一个应变值，因此只需要共同范围。

## 输出标签

`Str(a={sa}%,b={sb}%,c={sc}%)`，记录每条晶格矢量的工程应变。

## 可复现性

无随机性。相同输入和参数会产生相同的去重后应变结构。
