# 成分梯度（Composition Gradient）

**分类：** 合金与组分

## 功能说明

沿晶格 $a$、$b$ 或 $c$ 的分数坐标排列候选位点，再逐组改变元素配比。卡片只替换元素种类，不移动原子，也不改变晶胞。

这里的“组”是**等原子数组**：程序把排序后的候选位点分成原子数尽量相等的组，而不是沿空间切出等厚层。

## 原理与公式

设实际得到 $G$ 个非空组。第 $g$ 组的位置参数为：

$$
t_g=\frac{g}{G-1},\qquad g=0,1,\ldots,G-1.
$$

组内目标成分由起止配比线性插值：

$$
\mathbf c_g=(1-t_g)\mathbf c_{\mathrm{start}}+t_g\mathbf c_{\mathrm{end}}.
$$

若一组有 $N_g$ 个候选位点，程序先计算连续计数 $N_gc_{g,e}$，向下取整，再按小数余数从大到小补齐剩余位点。因此每组元素总数严格等于 $N_g$，但有限原子数下的实际配比只能取离散值。

例如每组有 4 个候选位点，单个元素只能表达 0%、25%、50%、75% 和 100%。增加组数会让空间变化更细，却会降低每组的成分分辨率。

请求组数必须至少为 2。若请求组数超过候选位点数，实际组数为：

$$
G=\min(N_{\mathrm{requested}},N_{\mathrm{sites}}).
$$

每个输入的输出数只由随机样本数决定：

$$
N_{\mathrm{out}}=N_{\mathrm{in}}N_{\mathrm{samples}}.
$$

随机样本保持各组的整数配比不变，只改变元素落在组内哪些位点上。组很小时排列自由度有限，不同样本可能完全相同。

## 操作示例

对沿晶格 $a$ 方向扩展的 Ni–Co 超胞设置：

```text
起始比例：Ni=1, Co=0
终止比例：Ni=0, Co=1
梯度方向：晶格 a
请求等原子数组：8
作用位点：仅列出的已有元素 Ni,Co
每个输入的随机样本：3
```

程序按分数坐标 $a$ 从低到高排序 Ni/Co 位点，分成最多 8 个等原子数组，再生成 3 个组内随机排列。

若晶格 $a$ 开启周期性，高坐标端会重新连接低坐标端。起止成分不同时，周期边界会形成第二个突变界面。

## 参数说明

### 元素（elements）

默认 `Ni,Co`。表格每行对应一种输出元素；程序只会在这些元素之间分配候选位点。

### 起始比例（start_composition）

默认 `Ni:1,Co:0`，定义低分数坐标端的相对配比。数值会自动归一化，不要求填写后的总和为 1。

### 终止比例（end_composition）

默认 `Ni:0,Co:1`，定义高分数坐标端的相对配比。中间各组在起止比例之间线性插值。

### 梯度方向（axis）

默认 `a`，可选 `a`、`b` 或 `c`。它们表示晶格分数坐标方向，不是笛卡尔 X/Y/Z。旧配置中的 `x/y/z` 仍分别按 `a/b/c` 读取。

### 请求等原子数组（bins）

默认 8，最小为 2。实际组数不会超过候选位点数；界面加载输入结构后会显示候选位点、实际组数和每组原子数范围。

### 作用位点（target_mode）

`target_mode="all"` 表示替换全部原子；`target_mode="listed"` 表示只替换列出的已有元素。

### 要替换的已有元素（target_elements）

在 `target_mode="listed"` 时生效。填写输入结构中允许被替换的元素符号，以逗号分隔。

例如输入包含 Ni、Co、Al，只希望修改 Ni/Co 子晶格时，应选择“仅列出的已有元素”并填写 `Ni,Co`，这样 Al 会保持不变。

### 每个输入的随机样本（samples）

默认 1，最小为 1。输出数等于输入数乘以该值。多个样本可能重复，尤其是每组只有一个位点，或整数配比只有一种排列时。

### 使用随机种子（use_seed）

默认 `false`。开启后，层内随机排列可以由相同输入、参数和种子复现；关闭时每次运行可能不同。

### 随机种子（seed）

默认 0，仅在 `use_seed=true` 时生效。界面中的种子输入框也只在启用后显示。

## 配置示例

```json
{
  "class": "CompositionGradientCard",

  "params": {
    "elements": "Ni,Co",
    "start_composition": "Ni:1,Co:0",
    "end_composition": "Ni:0,Co:1",
    "axis": "a",
    "bins": 8,
    "target_mode": "listed",
    "target_elements": "Ni,Co",
    "samples": 3,
    "use_seed": true,
    "seed": 42
  }
}
```

## 常见问题

**为什么实际组数少于请求值？** 候选位点少于请求组数时，每个位点最多单独形成一组，空组会被去除。

**为什么层内配比不是目标小数？** 原子数必须是整数。增大梯度方向的超胞，或减少组数，可以提高每组的成分分辨率。

**为什么随机样本重复？** 随机性只来自组内位点排列。每组位点太少时，可用排列数可能小于请求样本数。

**磁矩会随新元素自动更新吗？** 不会。`spin:R:3` 和 ASE `initial_magmoms` 会原样复制；替换磁性元素后，应按需要再使用磁矩设置或磁序卡片。

## 输出标签

`CompGrad(ax={a|b|c},b={实际组数},s={派生种子})`

未启用随机种子时不写 `s`。标签中的 `b` 是实际非空组数，不一定等于请求值。
