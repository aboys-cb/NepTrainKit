# FPS 代表性采样（FPS Sampling）

**分类：** 筛选与采样

## 功能说明

从候选池中选择描述符空间里的代表结构，输出数量不超过设定上限。它通常接在 `Geometry Filter` 后面：前者删除明确的几何异常，FPS 再减少相似结构，控制进入 DFT 或训练的数据量。

“代表性”取决于所选 NEP 模型。模型改变后，描述符距离和入选结构也可能改变。

当你选择“元素集合—晶相—磁序平衡”时，卡片先保证元素集合和晶相覆盖，再在每个物理分层内部做 FPS。模型若被识别为 spin 模型，磁序也会进入分层；此时不会把具有相同晶格、不同 spin 排列的构型当成同一种输入。

## 原理与公式

全局和元素集合策略先把一个结构中 $N_i$ 个原子的 NEP 描述符取平均：

$$
\mathbf d_i=\frac{1}{N_i}\sum_{a=1}^{N_i}\mathbf d_{ia}^{\mathrm{NEP}}.
$$

FPS 每一步选择离当前已覆盖集合最远的候选：

$$
i_t=\arg\max_j\min_{i\in S_{t-1}}\lVert\mathbf d_j-\mathbf d_i\rVert_2.
$$

物理平衡策略使用更完整的结构级表示：原子描述符的均值、标准差和最大局域偏离，加上每原子体积、晶胞形状、夹角和周期性。对 spin 模型还加入净磁矩、共线度、共面度、近邻关联和 `q_peak/q-vector` 等连续磁性证据。每个特征块先独立稳健归一化，再按有效维数平衡，避免高维模型描述符仅凭列数压过晶格或磁性证据。元素集合、晶相和磁序作为硬分层；不同浓度留在同一物理层内，由局域环境描述符区分。

若选择“基于已有训练集补选”，已有训练集的同定义特征会成为初始覆盖集合 $S_0$。FPS 在此基础上挑选离已有覆盖最远的新候选；已有训练集本身不进入本次输出。距离阈值大于 0 时，最远候选仍达不到阈值就提前停止，因此实际输出可能少于上限。

## 操作示例

### 场景：FeNi 模型只在 BCC Fe 的 TC 模拟中暴露失效

FeNi 训练集在某个浓度堆积了大量构型，纯 Fe 很少；当前 TC 只证明 BCC 覆盖不足，FCC 还没有独立验证。只在全数据上做一次 Global FPS，仍可能让主浓度吞掉大部分预算，也不能保证 FCC 与 BCC 都被保留。

- **输入：** 同时含 BCC、FCC 和多种 spin 排列的 FeNi `train.xyz`
- **目标：** 在压缩冗余的同时，保留每个元素集合、晶相、磁序和不同局域环境的代表构型
- **参数设置：** 使用实际训练得到的 spin `nep_best.txt`，`strategy="physics"`，`n_samples=25000`，`min_distance=0`
- **输出：** 每个已观察到的元素集合—晶相—磁序分层至少保留一帧，其余预算根据层内局域描述符覆盖缺口分配
- **怎么验证训练集质量改善：** 先对比抽样前后的元素集合、浓度分布、BCC/FCC 和磁序计数；浓度是诊断项而非硬分层。重训后分别在独立 BCC 与 FCC 验证集上检查能量、力、磁力和 TC。TC 改善只说明对应测试路径通过，不能替代另一晶相的验证。

## 参数说明

### 描述符 NEP 模型（nep_path）

`str`，默认使用内置 `nep89.txt`。描述符距离由该模型决定；模型文件存在不等于一定覆盖候选元素，正式采样前应确认模型的化学体系。

### 最大输出（n_samples）

`int`，默认 `100`。本次最多保留的候选结构数。输入更少或距离阈值提前停止时，实际输出更少。

### 距离阈值（min_distance）

`float`，默认 `0`。无物理单位，尺度依赖 NEP 模型。`0` 表示只按数量停止；大于 `0` 时用于提前停止近重复选择。

### 采样计划（strategy）

`str`，默认 `"global"`：

| 值 | 界面名称 | 行为 |
|---|---|---|
| `global` | 全局预算 | 全部候选共享一个预算；没有已有训练集时从输入第 1 帧开始 |
| `element_set` | 按元素集合均衡 | 每组先计划一个名额，其余按组大小平方根分配；组内从描述符中心开始 |
| `physics` | 元素集合—晶相—磁序平衡 | 先按元素集合和晶相分层；检测到 spin 模型后继续按磁序分层，最后在每个分层内部做 FPS |

`physics` 会使用与 Training Set Audit 相同的保守晶相和磁序识别；混合或无法确认的结构进入单独的 `mixed/unresolved` 分层，不会被强行猜成 BCC 或 FCC。最大输出若小于实际物理分层数，卡片会明确报错，因为此时无法兑现“每个已观察分层至少保留一帧”。计划名额仍会受到已有覆盖和距离阈值影响。

### 已有训练集（existing_dataset_path）

`str`，默认空。选择一个 `.xyz` 或 `.extxyz` 训练集作为补选起点。全局模式从全部已有结构的覆盖范围继续选；元素集合模式只匹配相同元素集合；物理平衡模式只匹配相同元素集合、晶相和磁序。输出只包含本轮新选中的候选，不重复包含已有训练集。

spin 模型要求候选集和已有训练集都提供规范的 `spin:R:3`。`mforce` 或 `force_mag` 是监督标签，不会被当成 spin 输入替代。

### 计算后端（backend）

`str`，默认 `"auto"`。由全局 NEP 计算设置管理，卡片界面不单独暴露；旧 JSON 中的值仍会恢复。

### 单批最大原子数（chunk_max_atoms）

`int`，默认 `100000`。描述符计算的内存分块参数，由全局设置管理，不改变 FPS 选择规则。

## 推荐预设

这组参数适合先重平衡已经带有 BCC/FCC 与 spin 数据的合金训练集；把模型路径和数量换成你的实际值：

```json
{
  "class": "FPSFilterDataCard",
  "params": {
    "nep_path": "/path/to/nep_best.txt",
    "n_samples": 25000,
    "min_distance": 0.0,
    "backend": "auto",
    "chunk_max_atoms": 100000,
    "strategy": "physics",
    "existing_dataset_path": ""
  }
}
```

已有平衡训练集、只想从新候选池补结构时，保留相同策略并填写 `existing_dataset_path`。新候选只会与相同物理分层的已有覆盖比较，避免用 FCC/FM 构型替代 BCC/AFM 缺口。

## 推荐组合

- 生成或扰动卡 → `Geometry Filter` → `FPS Filter`
- 多分支汇总 → `FPS Filter` → 导出 DFT
- `Training Set Audit` → 检查成分/晶相/磁序缺口 → `FPS Filter (physics)` → 分别验证 BCC 与 FCC

## 常见问题

**为什么输出少于最大值？** 输入数量不足，或距离阈值让选择提前停止。查看预览中的阈值状态和运行后的实际输出。

**为什么均衡模式某组输出为 0？** 计划名额不是强制输出。已有训练集已经覆盖该组、同时启用距离阈值时，组内候选可能全部被判为过近。

**为什么 spin 模型在运行前就报缺少 spin？** 物理平衡策略只接受规范的逐原子 `spin:R:3` 作为磁状态。仅有 `mforce` 或 `force_mag` 不能说明输入磁序；请修复数据字段，而不是切回结构-only 抽样掩盖问题。

**为什么明明写着 BCC/FCC，结果里还有 unresolved？** 晶相判断依据当前坐标而不是 `Config_type` 名称。热扰动、强应变或混相结构可能没有足够证据确认单一晶相；它们会被保守地单独保留。

**为什么换模型后结果不同？** FPS 距离定义在模型产生的描述符空间中。不同模型对结构差异的表达不同。

## 输出标签

输出保留原有 `Config_type`。全局模式按 FPS 选择顺序输出；元素集合和物理平衡模式保持入选帧在输入中的相对顺序。

## 可复现性

本卡没有随机性。同一输入、模型和参数会得到相同结果；改变输入顺序可能改变全局模式的起点和选择顺序。
