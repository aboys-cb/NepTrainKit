# FPS 代表性采样（FPS Sampling）

**分类：** 筛选与采样

## 功能说明

从候选池中选择描述符空间里的代表结构，输出数量不超过设定上限。它通常接在 `Geometry Filter` 后面：前者删除明确的几何异常，FPS 再减少相似结构，控制进入 DFT 的数量。

“代表性”取决于所选 NEP 模型。模型改变后，描述符距离和入选结构也可能改变。

## 原理与公式

先把一个结构中 $N_i$ 个原子的 NEP 描述符取平均：

$$
\mathbf d_i=\frac{1}{N_i}\sum_{a=1}^{N_i}\mathbf d_{ia}^{\mathrm{NEP}}.
$$

FPS 每一步选择离当前已覆盖集合最远的候选：

$$
i_t=\arg\max_j\min_{i\in S_{t-1}}\lVert\mathbf d_j-\mathbf d_i\rVert_2.
$$

若选择“基于已有训练集补选”，已有训练集的描述符会成为初始覆盖集合 $S_0$。FPS 在此基础上挑选离已有覆盖最远的新候选；已有训练集本身不进入本次输出。距离阈值大于 0 时，最远候选仍达不到阈值就提前停止，因此实际输出可能少于上限。

## 操作示例

候选池包含 80 个 Si、20 个 Ge 和 40 个 Si–Ge 结构，希望最多选择 30 帧：

1. 先用 `Geometry Filter` 删除短键等异常帧。
2. NEP 模型选择覆盖 Si 和 Ge 的模型。
3. 选择“按元素集合均衡”，把最大输出设为 `30`。
4. 预览会显示 Si、Ge、Ge+Si 三组的计划名额；元素集合只看出现了哪些元素，不区分 SiGe 与 Si₂Ge 的化学计量。
5. 运行后检查实际输出数和元素集合覆盖。已有训练集或距离阈值可能使某组实际输出为 0，所以计划名额不是结果保证。

用同一独立测试集比较 FPS 子集和等规模随机子集；如果关键结构类型本来不在候选池中，应回到上游补充，而不是继续调整 FPS。

## 参数说明

### 描述符 NEP 模型（nep_path）

`str`，默认使用内置 `nep89.txt`。描述符距离由该模型决定；模型文件存在不等于一定覆盖候选元素，正式采样前应确认模型的化学体系。

### 最大输出（n_samples）

`int`，默认 `100`。本次最多保留的候选结构数。输入更少或距离阈值提前停止时，实际输出更少。

### 距离阈值（min_distance）

`float`，默认 `0`。无物理单位，尺度依赖 NEP 模型。`0` 表示只按数量停止；大于 `0` 时用于提前停止近重复选择。

### 采样计划（strategy）

`str`，默认 `"global"`：

| 值 | 界面名称 | 行为 |
|---|---|---|
| `global` | 全局预算 | 全部候选共享一个预算；没有已有训练集时从输入第 1 帧开始 |
| `element_set` | 按元素集合均衡 | 每组先计划一个名额，其余按组大小平方根分配；组内从描述符中心开始 |

当最大输出小于元素集合数时，均衡模式会明确报错。计划名额仍会受到已有覆盖和距离阈值影响。

### 已有训练集（existing_dataset_path）

`str`，默认空。选择一个 `.xyz` 或 `.extxyz` 训练集作为补选起点。全局模式从全部已有结构的覆盖范围继续选；均衡模式只以元素集合相同的已有结构为起点。输出只包含本轮新选中的候选，不重复包含已有训练集。

### 计算后端（backend）

`str`，默认 `"auto"`。由全局 NEP 计算设置管理，卡片界面不单独暴露；旧 JSON 中的值仍会恢复。

### 单批最大原子数（chunk_max_atoms）

`int`，默认 `100000`。描述符计算的内存分块参数，由全局设置管理，不改变 FPS 选择规则。

## 推荐组合

- 生成或扰动卡 → `Geometry Filter` → `FPS Filter`
- 多分支汇总 → `FPS Filter` → 导出 DFT

## 常见问题

**为什么输出少于最大值？** 输入数量不足，或距离阈值让选择提前停止。查看预览中的阈值状态和运行后的实际输出。

**为什么均衡模式某组输出为 0？** 计划名额不是强制输出。已有训练集已经覆盖该组、同时启用距离阈值时，组内候选可能全部被判为过近。

**为什么换模型后结果不同？** FPS 距离定义在模型产生的描述符空间中。不同模型对结构差异的表达不同。

## 输出标签

输出保留原有 `Config_type`。全局模式按 FPS 选择顺序输出；按元素集合均衡模式保持入选帧在输入中的相对顺序。

## 可复现性

本卡没有随机性。同一输入、模型和参数会得到相同结果；改变输入顺序可能改变全局模式的起点和选择顺序。
