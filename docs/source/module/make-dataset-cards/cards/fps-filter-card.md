# FPS 代表性采样（FPS Sampling）

**分类：** 筛选与采样

## 功能说明

从候选池中选择描述符空间里的代表结构，输出数量不超过设定上限。它通常接在 `几何健全性过滤` 后面：前者删除明确的几何异常，FPS 再减少相似结构，控制进入 DFT 或训练的数据量。

“代表性”取决于所选 NEP 模型。模型改变后，描述符距离和入选结构也可能改变。

“结构与局域环境覆盖”适用于普通 NEP 和 spin 模型。卡片先保护元素集合与晶相代表，再根据结构和真实原子环境的覆盖缺口分配预算。只有 spin 模型才加入磁序和磁性特征；普通模型不需要磁矩数据。

## 原理与公式

全局和元素集合策略先把一个结构中 $N_i$ 个原子的 NEP 描述符取平均：

$$
\mathbf d_i=\frac{1}{N_i}\sum_{a=1}^{N_i}\mathbf d_{ia}^{\mathrm{NEP}}.
$$

FPS 每一步选择离当前已覆盖集合最远的候选：

$$
i_t=\arg\max_j\min_{i\in S_{t-1}}\lVert\mathbf d_j-\mathbf d_i\rVert_2.
$$

此策略与主界面的固定数量采样共用后端和选择序列，同时检查结构平均描述符、周期性与密度、元素比例，以及真实逐原子描述符；spin 模型另加磁性特征。结构特征块之间取最大距离，原子只匹配相同中心元素；选中一帧就加入其全部原子环境。因此一个特征的高覆盖不能抵消另一项的缺口，也不会仅凭相同结构均值认定原子环境相同。

采样不依赖 DFT 标签，也不使用 `Config_type` 或目录名分配名额。除模型描述符外，还按元素保留近邻距离分布；spin 模型另保留磁矩大小、相对排列和相对键方向。输入中识别出的路径、联合网格和有限状态会转成范围、连续性和联合单元见证，每个已观察的物理分层也是一个见证；先用最少的帧满足见证，不锁定具体帧，剩余名额再按覆盖缺口补足。名额不随帧密度或重复帧变化。没有自旋的普通模型使用相同流程中的几何输入。

见证仍受总预算限制。达到上限时检查未覆盖数量；不能把输入覆盖当作未知能量或力的精度保证。验证抽样效果时，固定样本数和训练设置，并在同一份独立验证集上检查关键状态区间。

尺度在完整可比较池上固定，去掉完全重复行的频数影响。描述符使用整块均方根尺度，保留原始距离比例；辅助结构特征才按各维单位缩放。晶相和可选磁序用于保护代表，不单独分配固定配额。手动模式在细尺度恢复精确原子距离，不会被自动覆盖分辨率提前截断。详情见[主界面采样说明](../../nep-main-tool-sparse-samples.md)。

若选择“基于已有训练集补选”，已有训练集的同定义特征会成为初始覆盖集合 $S_0$。FPS 在此基础上挑选离已有覆盖最远的新候选；已有训练集本身不进入本次输出。距离阈值大于 0 时，最远候选仍达不到阈值就提前停止，因此实际输出可能少于上限。

## 操作示例

### 场景：普通 NEP 的缺陷构型覆盖不足

模型在完整晶体上的力误差较小，在含空位或较大应变的独立验证集上误差较大。候选池中大量相似的完整晶体可能掩盖数量较少的局域环境。

- **输入：** 混有完整晶体、应变和空位构型的普通 NEP 数据，不要求 spin 字段
- **目标：** 压缩重复帧，同时保留晶相代表和不同原子环境
- **参数设置：** 使用适合该化学体系的 `nep.txt`，选择“结构与局域环境覆盖”，设置最大输出和距离阈值
- **输出：** 所有已选结构的原子共同提供环境覆盖，其余预算持续补足最大缺口
- **验证：** 检查报告中的未覆盖数量、结构与局域距离的 P95/最大值；重训后分别比较完整晶体、应变和空位验证集的能量与力误差，不能只看总体 RMSE 或散点是否均匀

## 参数说明

### 描述符 NEP 模型（nep_path）

`str`，默认使用内置 `nep89.txt`。描述符距离由该模型决定；模型文件存在不等于一定覆盖候选元素，正式采样前应确认模型的化学体系。

### 最大输出（n_samples）

`int`，默认 `100`。本次最多保留的候选结构数。输入更少或距离阈值提前停止时，实际输出更少。

### 距离阈值（min_distance）

`float`，默认 `0`。无物理单位，尺度依赖 NEP 模型。`0` 表示不启用距离阈值；物理模式仍会在所有不同几何候选耗尽时停止；大于 `0` 时用于提前停止近重复选择。

### 采样计划（strategy）

`str`，默认 `"global"`：

| 值 | 界面名称 | 行为 |
|---|---|---|
| `global` | 全局预算 | 全部候选共享一个预算；没有已有训练集时从输入第 1 帧开始 |
| `element_set` | 按元素集合均衡 | 每组先计划一个名额，其余按组大小平方根分配；组内从描述符中心开始 |
| `physics` | 结构与局域环境覆盖 | 先按元素集合和晶相分层；检测到 spin 模型后继续按磁序分层，保护类别代表后共享几何覆盖和总预算 |

`physics` 会使用与训练集评估相同的保守晶相和磁序识别；混合或无法确认的结构进入单独的 `mixed/unresolved` 分层，不会被强行猜成 BCC 或 FCC。最大输出若小于尚无已有训练集代表的物理类别数，卡片会明确报错，因为此时无法兑现“每个已观察分层至少保留一帧”。类别代表先受保护，其余预算按几何缺口分配。达到上限不代表覆盖完成；运行结果会报告停止原因、未覆盖结构数和归一化分辨率。

### 已有训练集（existing_dataset_path）

`str`，默认空。选择一个 `.xyz` 或 `.extxyz` 训练集作为补选起点。全局模式从全部已有结构的覆盖范围继续选；元素集合模式只匹配相同元素集合；物理模式在相同元素集合内共享结构覆盖、在相同中心元素间共享原子覆盖，同时保护尚无已有代表的物理类别。输出只包含本轮新选中的候选，不重复包含已有训练集。

spin 模型要求候选集和已有训练集都提供规范的 `spin:R:3`。`mforce` 或 `force_mag` 是监督标签，不会被当成 spin 输入替代。

### 计算后端（backend）

`str`，默认 `"auto"`。由全局 NEP 计算设置管理，卡片界面不单独暴露；旧 JSON 中的值仍会恢复。

### 单批最大原子数（chunk_max_atoms）

`int`，默认 `100000`。描述符计算的内存分块参数，由全局设置管理，不改变 FPS 选择规则。

## 推荐预设

这组参数适用于普通或磁性 NEP 的代表性采样；按实际模型和候选池规模调整路径与数量：

```json
{
  "class": "FPSFilterDataCard",
  "params": {
    "nep_path": "/path/to/nep_best.txt",
    "n_samples": 25000,
    "min_distance": 0.0,
    "backend": "auto",
    "chunk_max_atoms": 100000,
    "strategy": "physics",
    "existing_dataset_path": ""
  }
}
```

已有平衡训练集、只想从新候选池补结构时，保留相同策略并填写 `existing_dataset_path`。已有代表参与共享几何覆盖，但每个尚无代表的物理类别仍需从候选中保留一帧。

## 推荐组合

- 生成或扰动卡 → `几何健全性过滤` → `FPS 代表性采样`
- 多分支汇总 → `FPS 代表性采样` → 导出 DFT
- `训练集评估` → 检查成分/晶相/磁序缺口 → `FPS 代表性采样 (physics)` → 分别验证 BCC 与 FCC

## 常见问题

**为什么输出少于最大值？** 输入数量不足，或距离阈值让选择提前停止。查看预览中的阈值状态和运行后的实际输出。

**为什么均衡模式某组输出为 0？** 计划名额不是强制输出。已有训练集已提供类别代表，且其他结构共享的几何覆盖足够时，该类别可能不需要新增结构。

**为什么 spin 模型在运行前就报缺少 spin？** 物理平衡策略只接受规范的逐原子 `spin:R:3` 作为磁状态。仅有 `mforce` 或 `force_mag` 不能说明输入磁序；请修复数据字段，而不是切回结构-only 抽样掩盖问题。

**为什么明明写着 BCC/FCC，结果里还有 unresolved？** 晶相判断依据当前坐标而不是 `Config_type` 名称。热扰动、强应变或混相结构可能没有足够证据确认单一晶相；它们会被保守地单独保留。

**为什么换模型后结果不同？** FPS 距离定义在模型产生的描述符空间中。不同模型对结构差异的表达不同。

## 输出标签

输出保留原有 `Config_type`。全局模式按 FPS 选择顺序输出；元素集合和物理平衡模式保持入选帧在输入中的相对顺序。

## 可复现性

本卡没有随机性。同一输入、模型和参数会得到相同结果；改变输入顺序可能改变全局模式的起点和选择顺序。

## 算法迁移

已有 JSON 参数无需修改。`global/element_set` 保持原规则；`physics` 改为共享多视角覆盖，固定数量且无已有训练集、距离阈值为 0 时先满足区域见证，因此旧工作流的入选结构可能改变。归一化距离的新定义使旧物理模式的非零距离阈值需要重新核对。
