# 界面层互混（Interface Layer Mixing）

**分类：** 合金与组成

这张卡从一个双层或界面结构中选定一处界面，默认在两侧选区内随机抽取位置并交换**异种元素**。原子坐标、晶胞、PBC 和总元素数保持不变，输出可用于补充界面互混的未弛豫候选构型。两侧层数用于限定互混区域的宽度，不要求每层交换相同数量。

## 功能说明

当模型在理想界面上表现正常，但在界面互扩散、元素错位或局部混合构型上误差较大时，可用本卡补充不同互混程度的结构。输入应至少包含两种元素，并且界面能沿某个晶格分数坐标 `a`、`b` 或 `c` 切分。

它与相邻卡片的边界很清楚：

- **随机占位**：在选定位点上重新分配组成；
- **条件替换**：把满足空间条件的目标元素替换成指定元素；
- **界面层互混**：只在选定界面两侧成对交换异种元素，因此总组成不变。

## 原理与公式

### 1. 选定界面

程序按分数坐标 `a`、`b` 或 `c` 分层。这里的 `a/b/c` 是晶格分数坐标，不是笛卡尔 `X/Y/Z`；等分数坐标平面的法向对应倒易晶格方向。

自动模式比较三个方向上切分前后的元素组成差异，选择对比最大的方向和位置。手动模式则使用用户给出的方向与分数位置：低坐标一侧记为 L，高坐标一侧记为 R。

自动判断依据是元素组成，不识别晶相、化学键或界面能。元素子晶格的排布也可能产生很强的组成对比，导致自动模式选中横向切面；相同成分的不同晶相也不能靠这个规则区分。复杂体系可将 `axis` 设为已知的 `a`、`b` 或 `c`，关闭 `auto_position`，再用预览中的位置和两侧元素式核对选区。

只要目标界面能沿一个晶格分数坐标平面分开，就可以使用这张卡，包括非正交晶胞中的平面界面。多层结构需要逐次选定要处理的那一处界面，并核对两侧层是否属于目标材料；曲面或明显起伏的界面，不能直接把一个固定分数位置切面当作真实界面。

### 2. 识别原子层

沿所选方向把相邻原子的等分数坐标平面间距换算为真实垂直距离。距离不大于 `layer_tolerance` 的原子归入同一层，然后从界面向两侧分别选取 `left_layers` 和 `right_layers` 层。

层识别按相邻原子的法向间距逐个归并。若层内起伏或跨层原子使相邻层之间没有清晰间隙，它们可能被并为一层；应核对预览中的可用层数，并结合实际结构设置 `layer_tolerance`。

### 3. 只交换异种元素

设选中区域共有 $n=n_L+n_R$ 个原子，实际交换 $k$ 对原子。每一对必须来自界面两侧且元素不同，因此真正改变元素的原子数为 $2k$，实现浓度为

$$
c_{\mathrm{eff}}=\frac{2k}{n_L+n_R}.
$$

目标浓度 $c_{\mathrm{target}}$ 先换算为离散交换对数

$$
k=\operatorname{round}\left(\frac{c_{\mathrm{target}}(n_L+n_R)}{2}\right).
$$

有限原子数会使 $c_{\mathrm{eff}}$ 与目标值略有不同。界面预览会显示“目标 → 实现”，`Config_type` 记录实现浓度；若两侧元素分布不足以形成所需数量的异种配对，运行会在随机采样前报错。

### 4. 选择交换元素与分层配额

默认在整个两侧选区中随机选择交换位点。你也可以只允许指定的元素对：例如 `Si-P` 仅交换 L 侧 Si 与 R 侧 P，R 侧 Ga 保持原元素；`Si-Ga,Si-P` 同时允许两种交换。元素对按 **L 侧元素在前、R 侧元素在后** 输入。

对于 Si/GaP 这种允许的跨侧元素都能互相配对的选区，程序在各侧候选位点中均匀、不放回地抽样。Ga、P 的交换数随抽到的原子自然波动；当两者候选数相同时，平均交换数接近各半，每个构型不必恰好各半。若任意指定的元素对形成更复杂的限制，程序逐对进行随机的可行选择，保证剩余候选仍足以完成目标数量，但不承诺所有最终可行构型等概率。

`pair_distribution=random` 允许各元素对的数量波动；`equal` 要求每种元素对的交换数量严格相等。因此，“允许两种交换”并不自动代表“各半”。等量分配时，总交换对数必须能被允许的元素对种数整除；有逐层配额时，每一层的配额也必须能整除。程序会明确报错，不会悄悄取整或降低交换数。

逐层配额是可选的受控对照：只有需要不同构型保持相同的层间交换数量时，才勾选“设置逐层配额（可选）”并填写 `layer_pair_counts`。第 1 个数对应距离界面最近的一对 L/R 层，后续数字向外展开。两侧层数必须相等，数字个数必须与层数一致；交换仅发生在相同序号的配对层之间。此时由配额之和决定总交换数，固定浓度输入停止生效，梯度模式不可用。各层内的位置仍然随机；不勾选或留空时，按浓度在整个选区内抽样。

整个选区随机和逐层配额描述的是两种不同的构型分布，不能把逐层配额当作更真实的互扩散规律。本卡构造静态化学占位；实际扩散路径和弛豫后的输运性质需要后续计算判断。

无论是否选择元素，浓度的分母始终是两侧选中层中的全部位点，包含未参与交换的元素。例如 Si/GaP 两侧各 960 个位点，交换 192 对得到 20% 互混；仅交换 P 时，这也是 R 侧全部位点的 20%，同时是该侧 480 个 P 位点的 40%。

### 5. 输出与标签

每个输入严格生成 `num_structures` 个输出。固定模式使用同一个目标浓度生成不同随机排布；梯度模式在起始值与终止值之间线性取 `num_structures` 个目标值。

改变元素后，原有能量、力、应力、virial、计算磁矩、原子电荷和 BEC 不再对应新结构，因此会被删除。`spin` 与 `initial_magmoms` 随交换的元素一起移动；`group`、`sublattice` 等位点标签留在原位。

输出标签示例：

```text
IfaceMix(L=2,R=2,c=0.375,target=0.333,s=42)
```

其中 `c` 是实现浓度；只有发生离散取整时才附加 `target`。

导出只生成 XYZ。第二行保留 `Lattice`、`Properties`、`pbc` 等结构信息，互混卡片只新增简短的 `Config_type` 标签。标签记录两侧层数、实际浓度；启用固定随机种子时还记录派生种子 `s`，选择元素或逐层配额时再附上元素对、分配方式和配额。未启用固定种子时不写 `s`，该随机结果不承诺可复现。

逐对交换的原子编号和长 JSON 明细不再写入 XYZ，也不另存 CSV 或 JSON。新输出会清除输入中遗留的 `interface_mix_audit` 字段；磁矩、质量和几何分组等原子属性仍按上述规则保留。已有 XYZ 文件不会自动改写。

显式保存的原子质量随元素一起交换，包含已有的同位素质量；未显式保存质量时，ASE 根据新元素自动提供质量。几何分组和原子排列保持不变。

## 参数说明

### 分层方向（axis）

默认 `auto`。可选 `auto`、`a`、`b`、`c`。手动选择时表示按对应晶格分数坐标分层。

### 自动定位界面（auto_position）

默认 `true`。开启时沿已选方向自动寻找成分差异最大的层间隙；关闭时使用 `interface_position`。

### 界面位置（interface_position）

默认 `0.5`，范围 `(0, 1)`。仅在手动定位时生效。低于该分数坐标的原子属于 L 侧，其余原子属于 R 侧。

### 层容差（layer_tolerance）

默认 `0.25 Å`，必须大于 0。控制轻微弛豫或层内起伏多大时仍视为同一原子层。容差过小会把一层拆开，过大会合并相邻层。

### L 侧层数（left_layers）

默认 `2`，范围 1–100。从界面向较低分数坐标方向选取的层数。

### R 侧层数（right_layers）

默认 `2`，范围 1–100。从界面向较高分数坐标方向选取的层数。

### 交换元素选择（pair_selection）

`str`，默认 `all`。`all` 允许所有跨界面的异种元素对；`selected` 仅允许 `exchange_pairs` 中列出的 L/R 元素对。对 Si/GaP 这样的多元素界面，选 `selected` 可把与 Ga、与 P 的交换分开比较。

### 允许的元素对（exchange_pairs）

默认空列表。每项包含一个 L 侧元素和一个 R 侧元素，例如 `[["Si", "P"]]` 或 `[["Si", "Ga"], ["Si", "P"]]`。界面支持从周期表选择，也可输入 `Si-P,Si-Ga`。元素对必须由不同元素组成，不能重复；两侧候选不足时会在采样前报错。

生效条件：`pair_selection=selected`。至少填写一对；在 `all` 模式下保留填写内容，运行仍允许所有异种元素对。

### 元素对分配（pair_distribution）

`str`，默认 `random`。`random` 按候选原子随机抽取交换位置，各元素对数量允许波动；`equal` 使每种元素对的交换数严格相等，位置仍随机。在 `all` 模式下，等量分配针对选区中可形成的全部异种元素对。

若两种交换都要严格占 50%，选 `equal`，并保证总交换对数为偶数。这个 50% 描述交换对象的比例，互混浓度仍单独由交换总数与选区位点数决定。

### 逐层交换对数（layer_pair_counts）

默认空列表，表示按浓度在整个选区内随机配对。界面默认不勾选“设置逐层配额（可选）”，配额输入框也隐藏。需要固定层间分布时才启用，并填写从近到远的非负整数配额，例如 `[40, 38, 38, 38, 38]`；这会在最近 5 对原子层中分别随机交换 40、38、38、38、38 对，共 192 对。

生效条件：仅支持 `mode=fixed`，并要求 `left_layers=right_layers=配额个数`。配额覆盖 `concentration` 的作用；若任一配对层容量不足，或等量分配时配额不能整除元素对种数，运行会在随机采样前报错。

### 互混模式（mode）

默认 `fixed`。`fixed` 对所有输出使用同一目标比例；`gradient` 在起始与终止比例之间线性扫描。

### 目标变化比例（concentration）

默认 `0.5`，范围 0–1，仅在 `fixed` 模式生效。它表示选中层中希望改变元素的原子比例，不是单侧原子的换出比例。

填写逐层交换对数后，此值不再决定交换数量；预览根据实际配额显示实现比例。

### 起始比例（gradient_start）

默认 `0.0`，范围 0–1，仅在 `gradient` 模式生效。

### 终止比例（gradient_end）

默认 `1.0`，范围 0–1，仅在 `gradient` 模式生效。

### 每个输入的输出数（num_structures）

默认 `1`，范围 1–10000。总输出数为“输入结构数 × 每个输入的输出数”，界面会给出该预览。

### 使用固定随机种子（use_seed）

默认 `false`。开启后，相同输入、参数和种子可复现同一批交换结果。

### 随机种子（seed）

默认 `0`，仅在 `use_seed=true` 时显示并生效。每个输入和输出帧会派生独立种子。

## 操作示例

例如模型对 Si/GaP 界面错位元素的力预测不可靠，而训练集中主要是理想界面，可以先补充整个选区随机互混的候选：两侧各选 5 层，目标浓度 20%，生成 4 个独立化学构型。

```json
{
  "class": "InterfaceLayerMixCard",
  "check_state": true,
  "params": {
    "axis": "c",
    "auto_position": true,
    "interface_position": 0.5,
    "layer_tolerance": 0.25,
    "left_layers": 5,
    "right_layers": 5,
    "pair_selection": "selected",
    "exchange_pairs": [["Si", "Ga"], ["Si", "P"]],
    "pair_distribution": "random",
    "layer_pair_counts": [],
    "mode": "fixed",
    "concentration": 0.2,
    "gradient_start": 0.0,
    "gradient_end": 1.0,
    "num_structures": 4,
    "use_seed": true,
    "seed": 42
  }
}
```

导出前先检查界面位置、两侧元素式和实际浓度。两侧各 960 个位点时，每个构型交换 192 对；随机模式下 Ga/P 对数与各层数量可以波动。通过互混前后的元素变化核对交换位点，再为代表性候选计算参考能量和力，加入训练后用独立互混构型检验误差是否降低。若要严格 96/96，只把分配改为 `equal`，逐层配额仍可留空。

### 场景：模型对 Si/GaP 选择性互混的局部环境覆盖不足

如果模型在未互混界面上误差较小，但对 Si 进入 Ga 或 P 位点的结构预测不可靠，训练集可能缺少这些局部化学环境。你可以用同一未互混底板构造三组受控候选，分别补充参考计算，并按交换类型比较测试集的能量和力误差。

如果还需要排除各层交换数量波动对比较的影响，可以启用逐层配额。输入应具有 Si 侧 5 层、GaP 侧 5 层，每层 192 个原子，且 GaP 每层各含 96 个 Ga 和 P。先确认 L 为 Si、R 为 GaP，再使用以下受控配置生成两种交换各半的 4 个独立化学构型：

```json
{
  "class": "InterfaceLayerMixCard",
  "check_state": true,
  "params": {
    "axis": "c",
    "auto_position": false,
    "interface_position": 0.5,
    "layer_tolerance": 0.25,
    "left_layers": 5,
    "right_layers": 5,
    "pair_selection": "selected",
    "exchange_pairs": [["Si", "Ga"], ["Si", "P"]],
    "pair_distribution": "equal",
    "layer_pair_counts": [40, 38, 38, 38, 38],
    "mode": "fixed",
    "concentration": 0.2,
    "gradient_start": 0.0,
    "gradient_end": 1.0,
    "num_structures": 4,
    "use_seed": true,
    "seed": 42
  }
}
```

每个输出严格交换 96 对 Si↔Ga 和 96 对 Si↔P，1920 个选区位点中有 384 个改变元素，实现互混浓度为 20%。最近一对层交换 20+20 对，其余每对层交换 19+19 对；每层比例略有不同，5 层平均为 20%。

仅生成 P_only 时把 `exchange_pairs` 改为 `[["Si", "P"]]`；仅生成 Ga_only 时改为 `[["Si", "Ga"]]`，其余配额保持相同。每组均为 192 个交换对，而不是把单一元素组的交换总量减半。

生成后逐层核对改变位点与元素组成，并在弛豫前后检查代表性局部环境的参考能量和力。重训后，用未加入训练的选择性互混构型评估误差是否降低；互混引起热导升降仍需后续模拟检验。

### 场景：GaP/BN 多元素界面的交换通道

如果训练集缺少 GaP/BN 界面元素交换后的环境，可以在同一底板上比较不同交换通道。先手动选定一处平面界面并确认 L 为 GaP、R 为 BN，核对选区同时含有所需的元素。若选择 `pair_selection=all`，允许的通道为 `Ga-B`、`Ga-N`、`P-B` 和 `P-N`；这里交换的是单个原子的元素占位，不是整体搬动 GaP 或 BN 化学式单元。

只比较两种指定交换时，选择 `pair_selection=selected`，例如填写 `exchange_pairs=[["Ga", "B"], ["P", "N"]]`；只交换 Ga 与 B 时填 `[["Ga", "B"]]`。如果两种材料的 L/R 顺序反过来，元素对也要反向填写，例如 `B-Ga`。

`pair_distribution=equal` 只让各允许通道的交换总数严格相等。四通道时总交换对数须能被 4 整除，两通道时须能被 2 整除；单通道没有额外的等分要求，但仍受候选数量限制。关闭逐层配额后，`random` 和 `equal` 都在整个选区内随机选择位置，不要求每一层均匀。

层数应按实际晶体取向和每层组成设置。若 Ga/P 或 B/N 沿法向交替形成单元素层，选取 5 层可能得到 3:2 的局部组成；5 层也不等于 5 个化学式单元。整体配对可行并不代表逐层配对可行：某对纯元素层缺少其他通道的元素时，逐层严格等量分配可能没有容量。先检查两侧元素式和交换容量，不要直接套用上面每层同时含 Ga/P 的 Si/GaP 示例。

生成后按元素交换类型检查改变的位点、选区浓度和局部环境，再用参考计算检验能量和力并补入训练集。允许指定通道和严格等量配对不代表程序会保持材料的局部化学计量、子晶格占位或化学价态，也不能据此判断构型能量是否合理。

## 推荐组合

- **界面层互混 → 原子扰动**：补充相同化学构型附近的离平衡局部环境，参考计算后检查力误差。
- **界面层互混 → 晶格应变**：补充互混界面在应变下的环境，按应变与交换类型分别检查验证集误差。

## 可复现性

旧配置缺少新增参数时，仍使用所有异种元素、随机分配和按浓度配对。本次修正了随机分配优先耗尽某个元素池的偏差，因此旧版本相同种子生成的具体位置不保证与修正后相同。修正后，固定种子可复现相同输入与参数的输出；不同输出帧重新抽取化学交换位置。三种选择性互混使用同一个种子并不保证所有交换坐标完全相同，应通过输入与输出的元素变化核对位点后再进行配对统计。

## 周期边界

若所选方向启用 PBC，结构通常还有一个跨周期边界的第二界面。本卡按盒内的分数坐标切分选区，一次处理一处界面，选层不会自动跨过 0/1 边界。

处理跨边界界面前，先沿相应晶格方向平移输入结构，并重新进行周期包裹，使那处界面位于盒内部；然后手动选择方向和界面位置，再核对两侧材料及层数。仅把 `interface_position` 改为 0 或 1 不可行，因为它必须严格位于 0 和 1 之间。平移后 L/R 顺序可能改变，指定的元素对也需按新的两侧顺序填写。

## 常见问题

**预览显示的实现比例与输入值不同。** 交换必须落到整数原子对上。以预览中的实现比例为准；增大选中层数可获得更细的比例分辨率。

**自动检测选错界面。** 改为手动方向和手动位置，并根据两侧元素式确认选区。

**提示交换容量不足。** 两侧可形成的异种元素对少于目标值所需数量。可降低目标比例、增加选中层数，或检查界面两侧是否确有不同元素。

**选择元素后提示数量不能等分。** `equal` 要求总交换对数能整除元素对种数；有逐层配额时每层都要满足。两种交换配额 39 无法各半，可明确改为 38 或 40，并核对预览中的最终互混浓度。

**逐层配额与浓度不一致。** 有配额时以配额之和为准。清空逐层配额可恢复浓度输入；使用梯度扫描前也需清空配额。

**随机互混是否必须逐层？** 不必。两侧层数只限定选区；保持逐层配额关闭即可在整个选区随机抽样。严格各半也不要求逐层，只需把元素对分配设为 `equal`。
