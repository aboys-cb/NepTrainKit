# 表面薄层扫描（Surface Slab Scan）

**分类：** 表面

## 功能说明

从三维周期体相结构按明确的 Miller 晶面列表切出 slab，并扫描法向重复数与单侧真空厚度。它是确定性枚举：相同输入和参数会得到相同顺序的输出。

Miller 指数 $(h,k,l)$ 使用**输入晶胞的倒易基矢**解释。若你希望 `(100)`、`(110)`、`(111)` 具有常规晶体学含义，请输入对应的常规晶胞。

## 原理与公式

界面中的每一行表示一个晶面。程序先用

$$
g=\gcd(|h|,|k|,|l|),\qquad (h,k,l)\rightarrow(h/g,k/g,l/g)
$$

约简比例相同的指数，再按约简结果去重；例如 `(002)` 会并入 `(001)`，但 `(00-1)` 保留为另一取向。

对每个晶面、法向重复数 $r$ 和单侧真空 $v$ 调用 ASE `surface`。若输入有 $N$ 个原子，该组合得到 $Nr$ 个原子。真空会同时加在 slab 上下两侧，因此总真空间隔增加 $2v$。

输出会重新定向，使表面法向沿笛卡尔 $z$，第一条面内晶格矢量沿 $x$，第二条位于 $xy$ 平面。每组参数只生成一种由输入晶胞原点决定的 termination；若需要比较不同 termination，应准备具有不同原点/切分位置的体相输入。

范围 `[start, stop, step]` 只取不超过 `stop` 的点，点数为

$$
n=1+\left\lfloor\frac{stop-start}{step}\right\rfloor.
$$

设约简去重后有 $n_h$ 个晶面、$n_r$ 个重复数和 $n_v$ 个真空值，则每个输入精确产生

$$
N_{out}=n_hn_rn_v,
$$

总生成原子数为

$$
N_{atoms}=N\,n_hn_v\sum_r r.
$$

界面预览和运行前预算校验使用同一套公式，不会为了计数提前构造 slab。

## 操作示例

### 场景：模型对低指数表面的力误差明显高于体相

训练集主要是体相结构，表面低配位环境覆盖不足。

**输入：** 8 原子的常规 Si 晶胞，三方向均为周期边界。

**目标：** 覆盖 `(100)`、`(110)`、`(111)`，法向重复数 3–6，单侧真空 10 Å。

**参数设置：** `hkl_list=[[1,0,0],[1,1,0],[1,1,1]]`，`layer_range=[3,6,1]`，`vacuum_range=[10,10,1]`。

**输出：** 每个输入 12 个 slab，单个输出含 24–48 个原子，总计 432 个生成原子。

**怎么验证训练集质量改善：** 先检查输出的晶面、cell 和上下真空是否符合预期；标注并重训后，对独立的 `(100)/(110)/(111)` 表面验证集分别比较能量和力误差。

## 参数说明

### 晶面列表（hkl_list）

嵌套整数列表，默认 `[[1,0,0],[1,1,0],[1,1,1]]`。每行直接填写一个 `(h,k,l)`；可用低指数预设起步，再增删行。

指数相对输入晶胞的倒易基矢。程序自动约简并去重比例相同的行，`(0,0,0)` 会明确报错。

### 法向等价重复范围（layer_range）

三个整数，默认 `[3,6,1]`，依次为起点、终点、步长。这里的 `r` 是 ASE 将定向后的体相单元沿表面法向重复的次数，因此输出原子数是 $Nr$；它不保证等于肉眼数出的原子平面数。

增加 `r` 会让 slab 更厚，也会线性增加单个输出的原子数。可用表面能或中心层局域环境随 `r` 的收敛情况选择范围。

### 单侧真空范围（vacuum_range）

三个浮点数，默认 `[10,10,1]`，单位 Å。每个值分别加在 slab 上、下两侧，总真空间隔增加两倍。

需要放置较高吸附物时可增大真空；是否足够应由体系尺寸和后续计算的真空收敛结果判断。

### 法向周期边界（normal_pbc）

布尔值，默认 `true`。开启时输出三个方向均周期；关闭时只有面内周期，表面法向为非周期。

关闭时单侧真空必须大于 0，否则法向 cell 无法形成有效尺寸。

### 每输入最大输出数（max_outputs）

正整数，默认 200。若 $n_hn_rn_v$ 超过该值，运行会在构造第一个 slab 前停止并提示缩小扫描或主动提高上限。

### 每输入生成原子预算（max_generated_atoms）

正整数，默认 200000。它限制所有输出的原子数总和 $Nn_hn_v\sum_r r$，用于避免一个大输入或宽扫描意外占满内存。

## 推荐预设

### 单个 `(111)` 收敛扫描

用于只比较 slab 厚度是否收敛，共 6 个输出。

```json
{
  "class": "RandomSlabCard",
  "check_state": true,
  "params": {
    "hkl_list": [[1, 1, 1]],
    "layer_range": [3, 8, 1],
    "vacuum_range": [12.0, 12.0, 1.0],
    "normal_pbc": true,
    "max_outputs": 50,
    "max_generated_atoms": 100000
  }
}
```

### 三个低指数面覆盖

用于同时补充 `(100)`、`(110)`、`(111)`，并比较 10 Å 与 15 Å 单侧真空，共 24 个输出。

```json
{
  "class": "RandomSlabCard",
  "check_state": true,
  "params": {
    "hkl_list": [[1, 0, 0], [1, 1, 0], [1, 1, 1]],
    "layer_range": [3, 6, 1],
    "vacuum_range": [10.0, 15.0, 5.0],
    "normal_pbc": true,
    "max_outputs": 100,
    "max_generated_atoms": 200000
  }
}
```

## 推荐组合

- `Surface Slab Scan → Insert Defect`：先切出目标晶面，再生成表面吸附候选。
- `Surface Slab Scan → Atomic Perturb`：在已确认正确的 slab 上加入小幅热扰动环境。
- 已有 slab 只需沿当前法向复制时，用 `Layer Stack`；需要从体相按 Miller 面重新定向时用本卡片。

## 常见问题

**`(002)` 为什么没有单独输出？** 它与 `(001)` 比例相同，约简后自动去重。相反方向 `(00-1)` 不会合并。

**重复数为什么不等于看到的原子层数？** 它重复的是 ASE 定向后的体相单元。用输出的实际原子平面与目标性质收敛情况判断 slab 厚度，不要把 `r` 当作固定的原子平面计数。

**为什么运行前就提示超限？** 精确输出数或总生成原子数超过安全参数。预览会给出当前数量；缩小晶面/范围，或在确认资源足够后提高对应上限。

## 输出标签

`Slab(hkl=(h,k,l),R=重复数,vac=单侧真空,pz=0|1)`。`pz` 表示表面法向是否周期。

## 旧配置迁移

旧版 `h_range/k_range/l_range` 会在加载时按旧范围展开，再约简、去重并显示成晶面表格。界面会给出迁移提示，请在运行前核对可见列表；范围步长不再产生超过终点的额外值。

## 可复现性

无随机性。输出顺序固定为：晶面表格行 → 法向重复数 → 真空值。
