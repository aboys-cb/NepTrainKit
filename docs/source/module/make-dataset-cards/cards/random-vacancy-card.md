# 定向空位（Targeted Vacancy）

**分类：** 缺陷

## 功能说明

按“元素 + 可选 group + 删除数量”规则选择候选原子，再随机删除具体位点。适合只生成某种元素、某些原子层或已有区域标签内的空位。

- **定向空位：** 每条规则有自己的元素、group 和数量范围。
- **全局空位：** 所有原子共同采样，按整体数量或比例删除。
- **随机占位：** 改变位点上的元素，不删除原子。

输出保留剩余原子的坐标、晶胞、PBC、逐原子数组和结构信息。

## 原理与公式

第 $r$ 条规则先得到候选集合

$$
\mathcal I_r=\{i\mid Z_i=Z_r\ \text{且}\ g_i\in G_r\},
$$

其中 group 条件 $G_r$ 可留空。固定数量直接使用 $n_r$；随机范围先在整数闭区间 $[n_{r,\min},n_{r,\max}]$ 中抽取 $n_r$。随后从当前仍可用的候选集合中无放回抽取位点。

单条固定规则最多有

$$
\binom{|\mathcal I_r|}{n_r}
$$

种删除组合。多条规则按界面顺序执行；若候选池重叠，后面的规则只能使用前面尚未删除的原子，因此预览显示的是组合数上限，实际唯一输出可能更少。所有结果按删除位点集合去重，并保证至少留下一个原子。

## 操作示例

### 只生成表面氧空位

输入结构含 `group=surface/bulk`。设置一条规则：

```text
元素：O
已有 group：surface
数量模式：随机范围
数量：1–3
```

将“每个输入最大输出数”设为 20。首帧预览会显示匹配的表面 O 数量、删除范围和输出上限；运行后每个结果删除 1–3 个表面 O，并追加 `Vac(n=...)` 标签。

若要同时删除 1 个 Li，可再添加一条 Li 规则。两条规则若使用同一候选池，界面会提示实际输出可能低于组合数上限。

## 参数说明

### 空位规则（rules）

`list[dict]`，默认空列表。每条规则包含：

| 字段 | 说明 |
|---|---|
| `element` | 要删除的元素，如 `O` |
| `group` | 可选；输入中已有的一个或多个 `group` 标签 |
| `count_mode` | `fixed` 或 `random` |
| `count` | 固定数量写 `[n,n]`；随机范围写 `[min,max]` |

固定数量至少为 1。随机范围的最小值可以为 0；抽到 0 时，该规则不删除原子。如果所有规则都抽到 0，原结构会作为一个唯一输出保留，且不会追加 `Vac` 标签。

### 最大结构数（max_structures）

`int`，默认 1。每个输入最多保留的唯一空位结构数。候选组合不足、规则重叠或随机尝试重复时，实际输出会更少。

### 使用随机种子（use_seed）

`bool`，默认 `false`。开启后，相同输入结构和参数产生相同删除结果。

### 随机种子（seed）

`int`，默认 0，仅在 `use_seed=true` 时使用。种子会结合结构内容派生，因此不同输入帧不会机械删除相同的原子序号。

## 推荐组合

- `Layer Groups → Targeted Vacancy`：只在交替原子层中的某一组删位。
- `Super Cell → Targeted Vacancy`：先增大晶胞，降低周期空位镜像间的相互作用。
- `Targeted Vacancy → FPS Filter`：大量生成后筛选代表性构型。

## 常见问题

**填写 group 后提示输入没有 group 数组。** group 必须由输入结构或上游卡片提前写入；不需要区域限制时清空该字段。

**预览显示“组合数上限”。** 多条规则共享候选原子时，不同抽取顺序可能得到相同的最终删除集合，因此实际唯一输出通常更少。

**随机范围从 0 开始时为什么出现原结构？** 0 表示该规则本次不删除原子。若不希望保留原结构，把范围最小值改为 1。

**为什么运行失败而不是自动减少删除数？** 请求数量超过候选数或会删空整个结构时，程序明确失败，避免生成与参数不一致的数据。

## 输出标签

实际删除原子时，`Config_type` 追加：

```text
Vac(n={删除原子总数})
```
