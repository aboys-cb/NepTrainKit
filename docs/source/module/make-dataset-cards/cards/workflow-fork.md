# 永久分叉（Branch Fork）

**分类：** 容器

## 功能说明

把同一份输入送入多条独立分支。每条分支可以继续串联多张卡，最后选择保留各自输出，或显式合并为一个数据集。

它与 [分支合并](card-group.md) 的区别是：`Branch Merge` 的同层子卡运行后立即合并；`Branch Fork` 的每条分支可以先经过自己的多步卡片链。

## 工作原理

设输入为 $D$，第 $i$ 条分支中的卡片链为 $F_i$：

$$
O_i = F_i(D),\qquad
O_{\mathrm{merge}} = O_1 \mathbin{\Vert} O_2 \mathbin{\Vert} \cdots \mathbin{\Vert} O_n.
$$

其中 $O_i$ 是分支输出，$\Vert$ 表示按界面顺序拼接。独立输出模式保留各 $O_i$；合并模式生成 $O_{\mathrm{merge}}$。

## 操作示例

输入 1 个结构，建立两条分支：

```text
Branch Fork
  ├─ A: Random Slab → Atomic Perturb       → 6 个
  └─ B: Lattice Strain → Geometry Filter   → 4 个
```

选择“保留独立输出”时，得到 A、B 两份结果；选择“合并为一个输出”时：

$$
|O_{\mathrm{merge}}|=|O_A|+|O_B|=6+4=10.
$$

卡片会直接显示 `A 6 + B 4 → 合并 10`。

## 界面操作

1. 点击分支空白区选中目标分支，再从卡片库添加卡片。
2. 在分支名称输入框中直接改名；名称会随工作流配置保存。
3. 使用“添加分支”增加分支；一个永久分叉最多三条。
4. 选择“保留独立输出”或“合并为一个输出”，再运行工作流。

## 参数说明

### 分支（branches）

分支列表。每条分支保存稳定 `id`、显示名称、启用状态和内部卡片顺序。不同分支始终从同一份 Fork 输入开始。

### 显式合并（merge）

布尔值，默认 `false`。

- `false`：每条分支保留自己的最终输出；Fork 后不能连接共同下游卡片。
- `true`：所有启用分支成功后，按分支顺序拼接输出；拼接结果成为后续卡片输入。

`Merge` 只拼接，不去重或筛选。

## 失败与停止语义

- 启用的分支必须至少包含一张启用卡片，否则会在运行前提示具体分支。
- 独立输出模式下，一条分支失败不会删除其他成功分支的输出；卡片显示“部分完成”。
- 合并模式下，任一启用分支失败都会阻止 Merge 和共同下游。
- 停止工作流会停止所有仍在运行的分支卡片；部分结果不会冒充成功输出。

## 常见问题

**为什么不能连接共同下游？** “保留独立输出”没有唯一输出；先切换到“合并输出”。

**为什么运行前提示空分支？** 启用的分支必须包含至少一张启用卡片；添加卡片或关闭该分支即可。

## 保存字段

- `branches`：各分支的 `id`、名称、启用状态和卡片列表。
- `merge`：是否显式合并输出。
