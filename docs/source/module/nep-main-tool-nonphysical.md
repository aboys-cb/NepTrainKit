# 查找疑似非物理结构

界面按钮：`查找疑似非物理结构`。

## 作用与适用场景

按近邻距离扫描当前活动结构，选中疑似存在原子重叠或异常短接触的构型。适合检查强扰动、
随机缺陷、表面吸附和随机堆积产生的候选池。

## 判定原理

对每一对元素 $A,B$，程序用共价半径之和给出元素相关的距离下限：

$$
r_{\mathrm{limit}}(A,B)=c_r\left[r_{\mathrm{cov}}(A)+r_{\mathrm{cov}}(B)\right],
$$

其中 $r_{\mathrm{cov}}$ 是共价半径，$c_r$ 是界面设置中的半径系数，默认 0.7。
程序在周期边界条件下扫描原子对；只要存在

$$
r_{ij}<r_{\mathrm{limit}}(A_i,A_j),
$$

该结构就会被选中。与统一的绝对距离阈值相比，这种判据会随元素尺寸变化，但它仍不知道
键级、压力或特殊化学环境，因此只能称为“疑似非物理”。

## 操作后检查

扫描结果只是复核集合，不会自动删除。逐个查看最短键长和局部几何；高压结构或特殊成键体系
可能具有真实的短距离，不能只因被选中就判为坏结构。
