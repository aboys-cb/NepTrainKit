# 代表性采样（最远点采样）

界面按钮：`代表性采样`（`Sparse samples`）。

## 这个工具解决什么问题

候选池里经常有大量相似结构。最远点采样（Farthest Point Sampling，FPS）把每个结构表示成一个
描述符向量，并优先选择离已有样本最远的结构，从而用较少样本覆盖较大的描述符空间。

它解决的是**冗余**，不是**数据质量**。短键、错误标签和不合理结构应先清洗，再做 FPS。

## 最远点采样原理

设第 $i$ 个候选结构的描述符为 $\mathbf{x}_i$，当前已经选出的描述符集合为 $S$。
每一轮计算候选点到集合 $S$ 的最近距离：

$$
d(i,S)=\min_{\mathbf{x}_j\in S}\left\|\mathbf{x}_i-\mathbf{x}_j\right\|_2
$$

然后选择最近距离最大的候选：

$$
i^\*=\arg\max_{i\notin S}d(i,S),\qquad
S\leftarrow S\cup\{\mathbf{x}_{i^\*}\}
$$

- $\mathbf{x}_i$ 是结构级 NEP 描述符或其 PCA 坐标，没有 Å、eV 之类的物理单位。
- $\|\cdot\|_2$ 是欧氏距离。
- `最小距离`（`Min distance`）记为 $\delta$。当所有剩余候选都满足
  $d(i,S)<\delta$ 时，采样会提前停止，所以实际数量可以小于“样本上限”。
- 提供“训练数据集”后，训练集描述符会作为初始集合 $S_0$。此时优先选择训练集尚未覆盖的候选，
  而不是重新挑一批与训练集重复的结构。

:::{important}
`最小距离`的数值依赖当前 NEP 模型以及“原始描述符/降维后描述符”的选择，不能跨模型直接复用。
更换 `nep.txt` 或描述符来源后，应重新观察距离尺度。
:::

## 三种选择策略

| 中文界面选项 | 算法 | 适用场景 | 主要限制 |
| --- | --- | --- | --- |
| `全局 FPS（兼容模式）` | 所有候选共享一个 FPS 集合和总预算 | 数据属于同一化学体系，或希望完全复现旧流程 | 大数据组可能占满预算，小元素集合可能一个都选不到 |
| `元素集合平衡 FPS` | 先按结构所含元素集合分组，再在每组内独立 FPS | 一个候选池混有 Fe、Fe-O、Fe-Ni-O 等不同体系 | 强制使用原始描述符和固定数量模式；样本上限不得小于元素集合组数 |
| `元素集合 / 晶相 / 磁序 FPS` | 按元素集合、晶相和磁序建立物理分层，再根据局域环境描述符在层内 FPS | FeNi 等体系同时存在浓度偏斜、BCC/FCC 和多种 spin 排列 | 强制使用原始描述符；可选择用户总上限或自动描述符覆盖数量 |

平衡策略先给每个非空元素集合一个名额。剩余预算按组大小的平方根分配。若第 $g$ 组有
$n_g$ 个候选，其额外名额近似满足：

$$
q_g-1\propto\sqrt{n_g}
$$

程序还会把名额限制在该组实际结构数以内，并按小数余量补齐整数预算。没有训练集时，每组从最靠近
该组描述符中心的结构开始；有训练集时，只使用**元素集合完全相同**的训练结构作为该组初始集合。

平方根配额比按结构数线性分配更照顾小组，但它不表示各体系同等重要。训练目标本身有明确权重时，
仍应先拆分候选池或分别设定预算。

物理平衡策略复用 `Training Set Audit` 的保守晶相和磁序识别。它先给每个已观察到的
“元素集合—晶相—磁序”分层一个名额，再按各层的描述符覆盖缺口和下一采样点的边际收益分配剩余预算。
`mixed` 和 `unresolved` 会作为独立分层保留，不会被强行猜成 BCC 或 FCC。

层内 FPS 并不只看一个结构平均描述符。物理平衡策略把以下连续证据分别归一化并按特征块平衡后，
拼成同一个代表性采样空间：

- NEP 原子描述符的结构均值、标准差和最大局域偏离，用于同时保留整体环境、环境分布和少数极端局域环境；
- 每原子体积、晶胞形状、夹角和周期性，用于显式保留体积、应变和晶格形状变化；
- spin 模型的磁矩大小与离散度、净磁矩比例、共线度、共面度、近邻关联以及经过晶胞换算和正负号等价处理的 `q_peak/q-vector` 证据。

这些连续证据只用于同一硬分层内部的距离；元素集合、晶相和磁序仍是不能被 FPS 距离冲掉的硬分层。全局浓度不单独建立硬层，它通过不同局域化学环境在 NEP 描述符分布中体现。
若旧结果只有结构平均描述符、又没有可调用的 NEP calculator，软件会保留功能并退回“描述符均值 + 晶格 + 磁性证据”，
但不会伪称已经比较了原子描述符的分布和尾部。

检测到 spin 模型后，候选集和已有训练集都必须提供规范的逐原子 `spin:R:3`。
`mforce` 与 `force_mag` 是监督标签，不能代替 spin 输入。普通 NEP 模型仍按元素集合和晶相分层，磁序轴不启用。

启用“缓存输出文件”后，第一次物理平衡采样会在描述符输出目录保存压缩的
`*.phase-sampling.jsonl.gz` 分层缓存；再次加载同一数据、同一活动范围和同一识别版本时直接复用。
旧版本已经生成的晶相与磁序证据缓存也会自动转换成这一轻量分层缓存；旧的精确浓度分层缓存会在读取时折叠为元素集合分层并写回新格式，不要求重新分析。
数据内容、活动范围或识别方法版本变化时，缓存指纹不匹配，程序会安全地重新计算。

## 两种采样模式

### 固定数量（FPS）

“用户定义总上限”模式最多选择“样本上限”个结构，并在全部物理层之间分配这一个总预算。以下任一条件满足时提前结束：

- 已达到样本上限；
- 候选已用完；
- 最大最近距离小于“最小距离”。

因此“样本上限”是全局上限，不是每层数量，也不是保证数量。

“自动描述符覆盖”模式不读取样本上限和最小距离。程序在每个元素集合—晶相—磁序层内按描述符覆盖目标独立确定数量，再把各层数量汇总并直接使用同一次分析得到的结构集合，不会先推荐数量后换一套分配算法重采样。

### 覆盖 $R^2$ 停止（FPS）

只在“全局 FPS”中可选。程序每轮仍按 FPS 选点，并把所有候选到最近已选中心的平方距离作为剩余未覆盖量：

$$
R^2_{\mathrm{cover}}
=
1-
\frac{\sum_{i=1}^{N}\min_{\mathbf{s}\in S}
\left\|\mathbf{x}_i-\mathbf{s}\right\|_2^2}
{\sum_{i=1}^{N}\left\|\mathbf{x}_i-\bar{\mathbf{x}}\right\|_2^2},
\qquad
\bar{\mathbf{x}}=\frac{1}{N}\sum_{i=1}^{N}\mathbf{x}_i
$$

结果限制在 `[0, 1]`。提供已有训练集时，它也属于初始中心集合 $S_0$，所以已有覆盖会直接提高初始分数。
当 $R^2_{\mathrm{cover}}$ 达到“覆盖 $R^2$ 阈值”时停止；“样本上限”和“最小距离”仍然同时生效。

:::{warning}
这里的 $R^2_{\mathrm{cover}}$ 是**最近中心残差定义的描述符覆盖指标**，不是回归模型的决定系数。
它只能说明当前描述符空间被代表点覆盖到什么程度，不能单独证明能量、力、磁力或 TC 已经收敛。
:::

## 描述符来源

| 中文界面选项 | 实际距离空间 | 效果 |
| --- | --- | --- |
| `降维后（PCA）` | 当前数据的 PCA 坐标；合并训练集时会在候选与训练描述符上联合降到二维 | 速度快、便于和叠加图对应，但降维可能丢失低方差方向 |
| `原始描述符` | 缓存的结构级原始描述符 | 保留完整描述符信息，但距离尺度随维度和模型变化 |

如果请求原始描述符但当前没有缓存，程序会提示并回退到降维空间。元素集合平衡和物理平衡 FPS
都不允许这种回退；缺少原始描述符时会停止并报错。

## “将当前选择作为区域”到底做什么

这个选项不是“把当前选择当作已经保留的训练集”，而是把当前选中的结构限制为**本次 FPS 的候选区域**：

1. 先在主图上选中想清理的局部点群。
2. 勾选“将当前选择作为区域”并运行 FPS。
3. FPS 只在这批已选结构中找代表点。
4. 运行结束后，程序会把代表点从当前选择中**取消选择**。
5. 仍保持选中的，是该区域内未被 FPS 保留的冗余结构，可直接点击“删除选中结构”。

也就是说，它实现的是“在选定区域内保留代表点、留下冗余点供删除”。如果当前没有选择，或者当前子图
上找不到这些选择，程序会提示并退回到全数据采样；此时结果会按普通方式加入选择集。

## 其他参数

| 中文界面字段 | 怎么选 | 改变什么 |
| --- | --- | --- |
| `物理采样数量` | 物理分层策略可选“用户定义总上限”或“自动描述符覆盖” | 前者分配一个全局上限；后者由各物理层覆盖需求汇总数量 |
| `样本上限` | 固定数量模式填目标上限；覆盖 $R^2$ 模式填安全上限 | 限制最多选择多少结构；自动物理覆盖模式下不使用此项 |
| `最小距离` | 从较小值开始，根据实际选择数量和覆盖图调整 | 调大通常减少结果并提高样本间隔；调小允许保留更相似的结构 |
| `覆盖 R^2 阈值` | 只在覆盖 $R^2$ 模式生效，范围 `[0, 1]` | 调高通常选择更多结构；仍可能先被样本上限或最小距离截断 |
| `训练数据集` | 选择已有训练集的 `.xyz` 或目录 | 用已有训练描述符预热距离；全局模式读取失败时忽略预热，平衡模式读取或维度不匹配会报错 |
| `显示训练集叠加图` | 只有填写训练数据集路径时才有结果 | 采样后把训练集、当前数据和入选结构联合投影到 PCA 图中；只用于观察，不改变采样结果 |

## 跑完检查什么

- 看实际选择数量是否因“最小距离”或覆盖 $R^2$ 阈值提前停止，并核对界面报告的最终覆盖分数。
- 看元素集合平衡模式是否覆盖了预期的每个元素集合。
- 对 spin 模型，核对物理平衡模式是否覆盖了预期的元素集合、BCC/FCC 和磁序分层；不同浓度由层内局域环境覆盖体现。BCC 的 TC 通过不能替代 FCC 独立验证。
- 有训练集时，看叠加图中新样本是否落在训练集空白区域，而不是大量堆在已有训练点附近。
- 回到结构视图抽查代表点；描述符距离大可能来自真实新环境，也可能来自坏结构。
- 使用“当前选择作为区域”时，删除前确认：**仍被选中的才是准备删除的冗余点**。
