# 训练集评估

「训练集评估」用于检查当前训练数据：先找会阻止训练的技术问题，再查看组分、标签、局域环境、结构相和磁类型在数据内部如何分布。每一项结果都能回到 `NEP Dataset Display` 中的原始结构，便于继续查看、选择或导出。

这个页面给出的是**当前数据快照的证据**。它不会仅凭一份训练集宣称物理空间已经完整覆盖，也不会在缺少独立测试数据时判断势函数是否可靠。

## 从 `NEP Dataset Display` 进入

先在 `NEP Dataset Display` 中打开训练数据，再使用以下任一入口：

| 入口 | 打开位置 | 适合做什么 |
|---|---|---|
| 顶部 `Save` 分裂菜单 → `评估当前数据集` | 训练集评估的「概览」 | 完整检查当前活动结构 |
| 左侧图表工具栏 → `查看数据分布` | 「数据地图」→「数据分布」 | 直接查看能量、力、virial、预测值或误差的分布 |

没有加载数据时，入口会提示先打开数据集。评估默认只读取当前活动结构；已删除结构不在本次范围内。

```{admonition} 数据变化后要重新检查
:class: warning
页面顶部会显示结构范围、数据指纹和生成时间。删除结构、切换数据、修改标签或切换 `nep.txt` 后，请点击「重新检查」。旧结果不能继续代表已经变化的数据。
```

## 推荐操作顺序

### 1. 先看「概览」

<!-- assessment-overview-start -->
「概览」先回答 3 个问题：

- 有没有空结构、非法数值、标签形状错误等训练阻塞项；
- 当前数据包含哪些精确组分、元素和标签；
- 哪些高力、高能量、重复或低频集合值得先复核。

点击复核项后，下方会显示观察事实、解释和能力边界。再点击显示结构按钮，即可返回原页面，并选中该项对应的真实结构。


图中的编号就是推荐阅读顺序：先读当前结论，再确认本次检查了多少结构和标签，随后按「建议下一步」进入复核队列。只有需要留档或发给合作者时，才使用右上角的 HTML 导出。

### 2. 在「数据地图」查看组分、相和磁类型

<!-- assessment-data-map-start -->
「组分地图」按精确原子比例合并结构。例如，`Fe2Ni2`、`Fe4Ni4` 和 `Fe32Ni32` 都归入同一个 `Fe:Ni = 1:1` 组分点。右侧表格仍保留结构数量、原子数和 `Config_type`，不会把不同尺寸的结构当成同一个结构。

第一次进入时，柱高表示该浓度下的结构数。基础诊断显示后，页面默认自动在后台遍历当前评估范围内的所有结构；不需要另找按钮启动。大体系如果不希望自动分析，可在「设置 → 个性化」中关闭「自动分析结构证据」。分析完成后会增加两种视图，但不会擅自切换当前组分图：

- **结构相：** FCC、HCP、BCC，以及通过保守模板确认的 A4、L1₀、L1₂、B1、B2、B3、B4、C1、B8₁、D0₃、L2₁、C1ᵦ、D0₁₉、C14、C15；其余显示为混合局域结构或未解析；
- **磁类型：** FM、AFM（未细分）、逐层 AFM（`↑↓`）、双层 AFM（`↑↑↓↓`）、FiM、PM-like（自旋无序）、其他非共线、未识别、低／零磁矩和无有效 `spin` 字段。

分析结束后，可以先选组分，再用结构相和磁类型下拉框继续筛选。点击「查看选中的结构」即可回到 `NEP Dataset Display`。

相和磁是两条独立证据。同一个 FCC 或 BCC 骨架可以承载不同磁结构，所以页面不会把它们合成一个不可拆分的标签。`Config_type` 只是来源元数据，不参与结构相或磁类型判断。

在「进阶证据 → 磁序」中还可以切换三张按结构帧数归一化的 100% 堆叠图：每个结构相中的磁类型占比、每个磁类型中的结构相占比，以及整个评估范围的磁类型占比。颜色段中的百分比和右侧帧数分别回答“占多少”和“有多少帧”；点击任一颜色段可回选对应结构。

### 3. 用「进阶证据」追到局域环境

<!-- assessment-advanced-start -->
有活动的 `nep.txt` 时，页面会读取模型声明的元素及径向、角向 cutoff，并按模型实际可见的邻域统计：

- 中心元素周围的配位数和近邻元素组成；
- 元素对是否共同出现、是否在 cutoff 内真正接触；
- 标签分布、高力尾部和高能量尾部。

没有 `nep.txt` 时，数据质量、组分、标签、结构相和磁类型仍可使用；依赖模型 cutoff 的局域化学与元素对接触会显示为不可用。
<!-- assessment-advanced-end -->

### 4. 在「复核队列」记录判断

<!-- assessment-review-start -->
「复核队列」把相关的低频分箱合并为一个主题，避免同一问题产生大量重复提醒。状态选项会随问题类型变化：阻塞项可标为「未解决」或「已解决并重新检查」，重复几何可标记为「有意保留」「隔离候选」或「需要重算」，普通复核项可标记为「物理上合理」或「检查几何」。这些状态用于当前数据快照的页面复核，不会自动删除或修改结构。
<!-- assessment-review-end -->

### 5. 有明确研究范围时再用「目标与模型」

<!-- assessment-target-start -->
目标比较只在用户明确给出目标后才成立。可以指定：

- 一个元素的浓度范围；
- 必须出现的浓度点；
- 必须出现的 `Config_type`；
- 每个点的最少结构数。

页面比较的是**精确组分点和结构数量规则**。即使某个点显示为「支持」，也只表示数量规则通过，不代表局域环境、温压路径、缺陷类型或模型精度已经覆盖。

当前训练数据上的 Show NEP 预测可以用于浏览误差，但不会自动视为独立模型验证。要判断泛化误差，仍需结构映射和单位已经核对的独立参考值与预测值。
<!-- assessment-target-end -->

## 快速体检检查什么

### 训练阻塞项

以下结果违反明确的数据契约，应在训练前处理：

- 空结构；
- 位置、晶胞或标签中的 `NaN / Inf`；
- 位置、力、virial 等数组形状错误；
- 周期方向与晶胞不一致；
- 未知元素，或元素数量与原子数不一致；
- 最短原子距离小于 `0.5 Å` 的保守重叠信号；
- 相同几何对应互相冲突的能量、力或 virial 标签。

相同几何按元素、周期边界、晶胞和坐标共同判断；晶胞与坐标比较到小数点后 8 位。冲突标签的当前绝对容差为：能量 `1 × 10⁻⁵`、力 `1 × 10⁻⁵`、virial `1 × 10⁻⁴`，相对容差为 `0`。

软件不会自动删除阻塞结构，也不会替用户决定哪一次重复计算才正确。应先回到结构来源和 DFT 输出核对。

### 建议复核项

- 最大力最高的 10%；
- 单原子能量最高的 5%；
- 重复几何；
- 当前数据内部的低频组分、低频局域环境或不平衡集合。

固定分位集合按排名必然产生。高力、高能量或重复结构可能来自真实目标物理、显式加权或独立计算，因此这些结果是复核入口，不是删除建议。
<!-- assessment-health-end -->

## 结构相如何识别

### FCC、HCP 和 BCC：自适应公共近邻分析

页面先对每个原子做自适应公共近邻分析（Adaptive Common Neighbor Analysis，a-CNA）。算法使用周期性近邻搜索，最多取得 24 个近邻，并根据第一、第二近邻壳之间的距离间隔为每个原子单独确定 cutoff。

对于 FCC 和 HCP，设排好序的近邻距离为 $d_1 \le \cdots \le d_{13}$。只有在

$$
\frac{d_{13}}{d_{12}} \ge 1.08
$$

时，才用

$$
r_\mathrm{cut}=\frac{d_{12}+d_{13}}{2}
$$

分隔 12 配位的第一近邻壳。随后统计每条中心—近邻键的 3 个 CNA 数：公共近邻数、公共近邻之间的键数、最长键链长度。理想拓扑对应：

| 局域结构 | CNA 组合 |
|---|---|
| FCC | 12 条 `(4, 2, 1)` |
| HCP | 6 条 `(4, 2, 1)` + 6 条 `(4, 2, 2)` |
| BCC | 6 条 `(4, 4, 3)` + 8 条 `(6, 6, 5)` |

BCC 使用前 14 个近邻，并要求 $d_{15}/d_{14} \ge 1.08$。不满足壳层间隔或拓扑组合的原子记为「未解析」，不会强行分到最接近的晶相。

对一帧结构，某种局域相的原子占比为

$$
p_\alpha=\frac{N_\alpha}{N}
$$

若没有更具体的有序相通过确认，$p_\alpha \ge 0.80$ 时结构记为强证据；$0.50 \le p_\alpha < 0.80$ 时记为混合证据；低于 `0.50` 时记为未解析。这些比例描述当前快照中的局域拓扑，不等同于热力学相分数。

### 常见晶体原型：几何和化学同时过门槛

有序合金和化合物不能只靠 FCC/HCP/BCC 局域几何区分。页面会对三维周期结构做保守的原型确认，并同时检查组成、局域形状和物种占位。当前确认目录如下；这是一组经过反例测试的常见原型，不是完整晶体学数据库。

| 显示标签 | 常见名称 | Pearson / 空间群 | 说明 |
|---|---|---|---|
| A4 | 金刚石 | `cF8` / $Fd\bar 3m$ (227) | 单元素四面体网络 |
| L1₀ | CuAu 型 | `tP2` / $P4/mmm$ (123) | FCC 衍生的 `1:1` 有序结构 |
| L1₂ | Cu₃Au 型 | `cP4` / $Pm\bar 3m$ (221) | FCC 衍生的 `3:1` 有序结构 |
| B1 | 岩盐 | `cF8` / $Fm\bar 3m$ (225) | `1:1` 八面体配位 |
| B2 | CsCl | `cP2` / $Pm\bar 3m$ (221) | BCC 衍生的 `1:1` 有序结构 |
| B3 / B4 | 闪锌矿 / 纤锌矿 | `cF8` / $F\bar 43m$ (216)；`hP4` / $P6_3mc$ (186) | 立方／六方四面体化合物 |
| C1 | 萤石 | `cF12` / $Fm\bar 3m$ (225) | `1:2` 化合物 |
| B8₁ | NiAs | `hP4` / $P6_3/mmc$ (194) | 六方 `1:1` 化合物 |
| D0₃ | Fe₃Al 型 | `cF16` / $Fm\bar 3m$ (225) | BCC 衍生的 `3:1` 有序结构 |
| L2₁ / C1ᵦ | 全赫斯勒 / 半赫斯勒 | `cF16` / $Fm\bar 3m$ (225)；`cF12` / $F\bar 43m$ (216) | 三元 `2:1:1`／`1:1:1` 结构 |
| D0₁₉ | Ni₃Sn 型 | `hP8` / $P6_3/mmc$ (194) | HCP 衍生的 `3:1` 有序结构 |
| C14 / C15 | Laves | `hP12` / $P6_3/mmc$ (194)；`cF24` / $Fd\bar 3m$ (227) | `1:2` Frank–Kasper 结构 |

局域形状首先消除整体尺度。对选定的 $K$ 个近邻，以平均近邻距离 $\bar r$ 归一化，构造

$$
\mathbf d=\operatorname{sort}\left(\frac{r_i}{\bar r}\right)
\oplus
\operatorname{sort}\left(\frac{\lVert\mathbf r_i-\mathbf r_j\rVert}{\bar r}\right)_{i<j}
$$

这里 $\oplus$ 表示把两组数连接起来。程序计算该描述向量与内置参考晶体模板之间的最小均方根距离。物种检查使用同一组完整近邻壳，比较每一壳中的元素角色数。这样可以容忍整体平移、旋转、缩放、原子重排、元素编号变化和适度畸变，但不会仅凭化学计量、晶格常数或“看起来像立方”认相。

通用原型门槛为：组成比例相对理想值的偏差不超过 `3.5%`，几何匹配原子比例至少 `0.82`，化学匹配比例至少 `0.80`，两者同时匹配的比例至少 `0.80`。每个局域环境使用不少于 14 个、且不截断完整壳层的近邻；壳层边界附近最多容许 `max(1, floor(0.08 K))` 个近邻的排序交换。若两个已通过候选的局域形状距离和联合支持度都不足以明确拉开差距，结果直接返回「未解析」，不会按最接近模板猜一个标签。

- **L1₂：** 自动识别接近 `A:B = 1:3` 的二元组成。除了 FCC 形状外，还要求 A 位点的前 12 个近邻中没有 A、第二壳 6 个近邻全为 A；B 位点的前 12 个近邻中有 4 个 A、第二壳没有 A。几何匹配比例至少为 `0.80`，化学匹配比例至少为 `0.85`，几何与化学同时匹配的比例至少为 `0.80`。
- **Laves：** 自动识别接近 `A:B = 1:2` 的二元组成。A 位点按 Z16 模板检查，B 位点按 Z12 模板检查；A 位点应有 4 个 A 近邻，B 位点应有 6 个 A 近邻。几何匹配和联合匹配比例都至少为 `0.85`。通过后再用 B 子晶格的中心对称参数区分 C14 与 C15。

C15 的 Pearson 符号是 `cF24`，空间群是 $Fd\bar 3m$；这里的 `F` 表示面心立方布拉菲格子，但不表示它是 A1 型 FCC 固溶体，也不表示每个原子都具有 a-CNA 的 FCC 近邻拓扑。C15 的两类位点分别使用 Laves 的 Z12/Z16 Frank–Kasper 环境，因此界面可以同时显示「C15 Laves 已确认」和「a-CNA（仅 FCC/HCP/BCC）为其他 / 未解析」。参见 [AFLOW C15 原型](https://www.aflow.org/prototype-encyclopedia/A2B_cF24_227_d_a)。

自动推断 A/B 角色时，实际组成与理想少数元素比例的偏差必须不超过 `3.5%`。C36 局域堆垛与 C14/C15 混合在当前局域证据下可能不可区分，因此只显示为未确认线索，不会作为已确认 C36 输出。这里的「未确认」表示证据不足，不表示该相一定不存在。

### 为什么会同时显示“B1 已确认”和“局域未解析”

这两行回答的是不同问题。以轻微应变和原子扰动后的 `U₄N₄` 为例，物种分辨的完整近邻壳仍与 B1 岩盐模板一致，因此结构级标签可以显示：

```text
B1（岩盐）· 已确认原型
参考晶体学（理想原型）：cF8 · Fm-3m (No. 225) · 面心立方布拉菲格子
```

但 a-CNA 只识别每个原子的 A1-FCC、A2-BCC 或 A3-HCP 局域拓扑。B1 中每个原子的第一近邻是 6 配位八面体环境，不是 12 配位的 A1-FCC 环境，所以同一张卡片可以同时显示：

```text
a-CNA 局域环境（仅 FCC/HCP/BCC）：其他 / 未解析 100.0%
```

这不是相互矛盾，也不是把 B1 误判成 FCC：前者是**化合物原型确认**，后者是**单原子局域金属骨架统计**。软件会并列保留两层证据。A15、钙钛矿、L1₁、C36 等尚未进入确认目录的具体原型不会被猜成某个已支持原型；如果它们仍具有明显的 FCC/BCC/HCP 局域骨架，页面最多只报告该局域骨架。

## 磁类型如何识别

### 输入条件

磁类型分析只读取逐原子的 `spin:R:3`，即每个原子一个三分量自旋向量：

```text
Properties=species:S:1:pos:R:3:spin:R:3
```

`spin` 必须是数值型 `N × 3` 数组，并且所有分量有限。`mforce` 和 `force_mag` 是磁力标签，不能替代 `spin`。缺少有效 `spin` 的结构会单独显示为「无有效 spin 字段」，不会被猜成非磁结构。

### 4 组判据

设第 $i$ 个自旋为 $\mathbf s_i$，磁矩大小为 $m_i=\lVert\mathbf s_i\rVert$，单位方向为 $\hat{\mathbf s}_i=\mathbf s_i/m_i$。小于等于 `1 × 10⁻⁷` 的磁矩不参与方向统计。

1. **净磁矩比例**

   $$
   R_M=\frac{\left\lVert\sum_i\mathbf s_i\right\rVert}{\sum_i\lVert\mathbf s_i\rVert}
   $$

   $R_M$ 接近 `1` 表示自旋净对齐，接近 `0` 表示整体补偿。它是无量纲比例；平均磁矩仍沿用输入 `spin` 的单位。

2. **共线性与共面性**

   $$
   \mathbf Q=\frac{1}{N_s}\sum_i\hat{\mathbf s}_i\hat{\mathbf s}_i^{\mathsf T},
   \qquad \lambda_1\le\lambda_2\le\lambda_3
   $$

   共线性取 $C=\lambda_3$，共面性取 $P=1-3\lambda_1$。$C$ 接近 `1` 表示方向集中在同一条轴上；$P$ 接近 `1` 表示方向主要位于同一平面。

3. **近邻自旋相关**

   每个原子最多取 12 个最近邻，计算

   $$
   \bar c=\left\langle\hat{\mathbf s}_i\cdot\hat{\mathbf s}_j\right\rangle_{\langle i,j\rangle}
   $$

   点积不小于 `0.80` 记为平行近邻，不大于 `-0.80` 记为反平行近邻。程序还分别统计平行和反平行近邻比例。

4. **低阶磁结构因子**

   对分数坐标 $\mathbf f_i$，程序在周期方向上扫描 $|h|,|k|,|l|\le3$ 的非零整数波矢，计算

   $$
   S(\mathbf q)=\min\!\left[1,
   \frac{2\left\lVert\sum_i\mathbf s_i
   \exp\!\left(\mathrm i2\pi\mathbf q\cdot\mathbf f_i\right)\right\rVert^2}
   {\left(\sum_i m_i\right)^2}\right]
   $$

   页面记录最大值 $S_\mathrm{max}$ 及对应的整数波矢。它用于识别当前超胞内可分辨的低阶调制，不是连续 reciprocal-space 扫描。

### 结构级磁类型标签

判定按下表从上到下执行：

| 输出 | 当前判据 |
|---|---|
| 低／零磁矩 | 没有大于 `1 × 10⁻⁷` 的有效磁矩 |
| 未识别 | 只有 1 个有效磁矩；或后续证据不足以落入其他类型 |
| FM | $C\ge0.90$、$R_M\ge0.82$、$\bar c\ge0.20$ |
| AFM | $C\ge0.90$、$R_M\le0.20$，并且满足 $S_\mathrm{max}\ge0.45$、$\bar c\le-0.25$ 或反平行近邻比例至少 `0.20` 中的任一项 |
| FiM | $C\ge0.90$、$R_M<0.82$、反平行近邻比例至少 `0.20`，并且 $S_\mathrm{max}\ge0.35$ 或 $\bar c<-0.05$ |
| 其他非共线 | $C<0.90$，且满足 $S_\mathrm{max}\ge0.45$ 与 $P\ge0.72$；或满足 $S_\mathrm{max}\ge0.32$、$\lvert\bar c\rvert\ge0.30$ 中的任一项 |
| PM-like（自旋无序） | $R_M\le0.25$、$S_\mathrm{max}\le0.22$ 且 $\lvert\bar c\rvert\le0.15$ |

只有结构级结果已经属于 AFM，程序才继续检查层序。它沿周期晶格方向用分数坐标聚合磁层；同一方向上分数坐标间隔不超过 `0.025` 的原子归入同一层，层内极化绝对值必须至少为 `0.80`。层序细分至少需要 4 个有效磁矩原子。一个完整的周期 `↑↓` 标为「逐层 AFM」，`↑↑↓↓` 标为「双层 AFM」。周期边界会继续重复该层序，因此不要求同一晶胞内再出现第二遍。没有通过层序门槛的 AFM 显示为「AFM（未细分）」。

逐元素结果使用相同的净磁矩、方向张量、同元素近邻相关和结构因子，给出「对齐」「补偿」「调制」「非共线」「混合共线」「无序」等快照标签。异元素近邻耦合按平均点积判断：不小于 `0.50` 为平行，不大于 `-0.50` 为反平行，其余为混合。

```{admonition} 磁类型标签的边界
:class: important
这些标签描述单帧自旋快照，不是有限温度磁相判定。`PM-like` 只表示这一帧在当前判据下呈现低净磁矩、低 q 峰和弱近邻相关，不能据此声明热力学顺磁相。波矢扫描只覆盖当前超胞可表示的低阶整数点；非公度螺旋、更长周期调制、强缺陷结构或尺寸很小的结构可能落入「其他非共线」或「未识别」。判断相变温度、磁畴稳定性或自由能仍需要独立模拟和物理验证。
```

## 当前不能单独回答什么

训练集评估不能单独回答：

- 数据是否覆盖某个温度、压力、缺陷、界面或相变目标；
- 哪种目标结构一定缺失；
- 势函数在独立测试集上的误差；
- 长时间分子动力学是否稳定；
- 某项物性的误差是否可接受；
- 单帧结构和自旋标签对应的热力学相是否稳定。

这些问题分别需要明确的目标空间、目标结构或轨迹、模型预测、独立参考数据和物性验证协议。「当前数据中少」只表示相对稀少，不等于研究目标中缺失。
