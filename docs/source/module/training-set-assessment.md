# 训练集评估

“训练集评估”用于回答一个比“画分布图”更直接的问题：当前数据中有没有阻止训练的数据问题，哪些结构值得复核，现有证据还能说明什么、不能说明什么。

它不会仅凭当前训练集宣称“物理空间已经覆盖完整”，也不会在没有模型预测和独立参考数据时判断势函数可靠。

## 从哪里进入

在 `NEP Dataset Display` 中加载数据后，可以通过两种方式进入：

- 菜单中的 `评估当前数据集`：打开评估首页。
- 工具栏中的 `查看数据分布`：打开同一页面的“数据分布”工作区。

原来的独立 `Distribution Inspector` 窗口已不再作为主入口。分布统计和点击分箱回选结构的能力仍然保留。

## 首先确认评估范围

从 Dataset Display 进入时，默认检查当前活动结构，而不是被删除的结构或磁盘文件中的所有历史内容。

页面标题下方会显示：

- 当前范围和原始结构数，例如 `active · 1000/19313`。
- 规则版本。
- 数据指纹。
- 使用 `nep.txt` 时的模型指纹。

结构范围、数据内容或模型变化后，应重新运行检查。不要把旧报告继续用于已经变化的数据。

## 快速体检会检查什么

### 数据阻塞

以下结果表示违反了明确的数据契约，应在训练前处理：

- 空结构。
- 位置、晶胞或标签中的 `NaN / Inf`。
- 位置、力、virial/stress 等数组形状错误。
- 周期方向与晶胞不一致。
- 未知元素或元素数量与原子数不一致。
- 小于 `0.5 Å` 的保守原子重叠信号。
- 相同几何对应明显冲突的能量、力或 virial 标签。

点击 Finding 可以查看受影响结构，并把它们送回 Dataset Display。软件不会自动删除这些结构，也不会替用户决定哪一次重复计算才正确。

### 建议复核

以下内容只是复核集合，不是错误判定：

- 最高 10% 的最大力。
- 最高 5% 的单原子能量。
- 重复几何。

固定分位集合按排名必然产生。高力、高能量或重复结构可能来自真实目标物理、显式加权或独立计算，必须结合来源判断。

### 数据内部证据

组成、`Config_type`、局域化学和元素对接触用于描述当前数据内部的分布。低频区域只表示“相对当前数据较少”，不等于训练集缺失，也不直接构成补数据建议。

## 数据分布工作区

默认只需要设置四项：

- `字段`：选择可发现的结构级或原子级数值字段。
- `数值类型`：参考值、预测值或误差。
- `分组方式`：按化学式或元素分组。
- `数据范围`：当前活动结构或当前选中结构。

点击“高级选项”后，可以调整选择方式、分箱数、辅助曲线和向量模长。

点击图中的分箱会把对应结构回选到 Dataset Display。`替换选择 / 追加选择 / 与当前选择求交集` 的行为与旧 Distribution Inspector 一致。

## 当前不能回答什么

当前快速体检不能单独回答：

- 数据是否覆盖某个温度、压力、缺陷或相变目标。
- 哪种目标结构“缺失”。
- 势函数在独立测试集上的误差。
- 长时间 MD 是否稳定。
- 某项物性的误差是否可接受。

这些结论分别需要目标定义、目标结构或轨迹、模型预测、独立参考数据和明确的物性验证协议。页面中的“模型误差：未评估”就是对这一能力边界的明确提示。

## HTML 报告

导出的报告与 GUI 使用同一组 canonical Findings，包含评估范围、输入、指纹、检查项目、事实、结论、判定规则和限制。

报告描述的是本次数据快照，不是全局覆盖证明，也不是自动采样指令。
