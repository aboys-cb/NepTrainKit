# 术语表

本页解释 NepTrainKit 界面和文档中反复出现的术语。要查按钮和参数，请回到
[功能指南](../module/index.rst)；要查文件字段契约，请看[支持格式](../formats.md)。

## 数据、标签和模型

### 参考值（reference / DFT）

结构文件中已有的能量、力或 virial 标签，通常来自 DFT。NepTrainKit 把它们作为比较基准，
但不会仅凭字段存在就判断其计算设置是否一致。

在 NEP 散点图中，当前约定是 **x 轴为 NEP 预测值，y 轴为参考值**。不要根据其他软件
输出列的先后顺序猜坐标含义；以 NepTrainKit 图上的轴标题为准。

### 预测值（prediction / NEP）

由当前加载的 `nep.txt` 计算，或从 GPUMD 输出文件读取的模型结果。预测值不是新的 DFT 标签，
也不会在没有模型或结果文件时自动出现。

### `nep.txt`

NEP 模型文件。它可用于计算能量、力、virial 和描述符。模型必须支持数据中出现的元素；
换模型后，预测误差和描述符距离都可能改变。

### `Config_type`

结构级标签，存放在 `atoms.info["Config_type"]`。NepTrainKit 用它记录数据来源、生成步骤或
用户分组，并可据此搜索、筛选和分目录导出。它不是化学式，也不保证代表唯一物理相。

### `energy_original`

第一次执行能量基线平移前保存的结构总能量。后续再次平移不会覆盖已经存在的
`energy_original`。导出 EXTXYZ 后可同时检查 `energy` 和 `energy_original`。

### EXTXYZ

扩展 XYZ。除元素和坐标外，还能在帧头声明晶胞、周期边界、能量、virial 和字段布局，
并通过 `Properties` 描述逐原子列。NepTrainKit 的训练数据交换优先使用这种明确的数据契约。

## 采样和结构生成

### 卡片（card）

“生成数据集”页面中的一个操作单元。卡片可以生成结构、变换输入结构、过滤数据或组织分支。
勾选状态决定本次是否运行；卡片在工作区中的位置不一定代表所有子卡都会顺序串联。

### 配方（recipe）

为一个完整目标组合多张卡片的示例，例如高熵合金、富缺陷表面或磁性数据。配方给出可复用
起点，不代表参数可以不经检查直接用于所有材料。

### FPS（Farthest Point Sampling，最远点采样）

在描述符空间中反复选择离已有集合最远的候选点，用于从干净候选池中减少冗余。
“代表性”只相对于当前模型的描述符空间成立；FPS 不检查短键，也不会补出输入池中不存在的构型。

### 描述符（descriptor）

NEP 对局域原子环境的数值表示。NepTrainKit 的 FPS 默认把逐原子描述符取结构级均值后计算距离。
描述符坐标通常没有 Å 或 eV 这样的直接物理单位，数值尺度也依赖模型。

### warm start / 已有训练集

在代表性采样开始前，把已有训练集当作已经覆盖的集合。新候选会优先补充离现有覆盖较远的区域；
已有训练集不计入本轮输出数量。

### GSFE（Generalized Stacking Fault Energy，广义层错能）

沿指定晶面和面内滑移方向逐步移动晶体的一部分，用能量差除以层错面面积得到的路径。
“层错路径”卡只生成结构路径，不替用户计算 DFT 能量，也不会自动判断周期晶胞中的界面数。

## 力、应力和磁性

### virial

结构级张量，NepTrainKit 内部按 eV 保存。只有 stress 时，结构层会结合晶胞体积换算 virial；
两者不能脱离体积和符号约定直接当成同一个数比较。导入、导出契约见[支持格式](../formats.md)。

### 净力（net force）

一个结构中所有参考原子力的矢量和再取模。它用于发现可能不满足平衡或标签契约异常的结构，
不是逐原子最大力，也不能单独决定结构是否应该删除。

### `spin:R:3`

EXTXYZ 中每个原子的三分量自旋／磁矩向量字段。`R` 表示实数，`3` 表示每个原子有三个分量。
磁性卡片和训练集评估以该字段作为磁结构证据；`mforce` 或 `force_mag` 不是自旋状态。

### FM / AFM / FiM / PM-like

- FM：铁磁，磁矩主要同向；
- AFM：反铁磁，存在补偿的反平行有序；
- FiM：亚铁磁，反平行子晶格未完全补偿；
- PM-like：当前有限结构快照表现为自旋无序。

训练集评估给出的分类是当前结构和阈值下的模式识别，不等同于有限温度热力学相判定。

## 页面状态

### 活动结构、选中结构和删除结构

活动结构仍参与当前查看和导出；选中结构只是当前操作目标；删除结构已从活动集合排除。
三者不是同一状态。导出前应核对状态栏中的 `Orig / Now / Rm / Sel / Unsel / Rej`。

### 训练集评估（Training Set Audit）

对当前活动数据快照做标签、组成、局域环境、结构相和磁类型检查。它提供复核证据，
不会在没有独立测试集时宣称模型已经可靠，也不会自动替用户决定哪些结构必须删除。
