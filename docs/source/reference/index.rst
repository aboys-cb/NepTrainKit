参考资料
========

这里放需要准确查找的契约，不承担新手教学：

* :doc:`glossary`：集中解释 ``Config_type``、FPS、GSFE、virial、``spin:R:3`` 等术语。
* :doc:`troubleshooting`：按“导入失败、没有输出、CUDA 不可用”等症状定位问题。
* :doc:`../formats`：可导入、导出和自动识别的文件格式。
* :doc:`../module/make-dataset-cards/index`：先按目的选择卡片，再进入完整参数参考。
* :doc:`../module/make-dataset-cards/cards/stacking-fault-card`：载入旧工作流时迁移已经隐藏的旧版层错卡片。

各桌面功能的按钮、参数和操作说明不再单独放在这里，而是直接归入对应的
:doc:`../module/index`。用户从软件页面名称进入后，就能按界面顺序继续展开。

如果你是在完成一个具体任务，而不是核对字段或按钮，请先从 :doc:`../example/index`
或 :doc:`../workflows/index` 开始。
