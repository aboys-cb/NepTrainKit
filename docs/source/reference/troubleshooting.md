# 常见问题与故障排查

先按你看到的现象定位。每一项只给最短检查路径；需要完整参数时进入链接页面。

## 安装和启动

### `nepkit` 启动后立即报错

1. 确认当前终端已激活安装 NepTrainKit 的环境。
2. 运行 `python -c "import NepTrainKit; print(NepTrainKit.__file__)"`，确认导入来自预期环境。
3. 如果 traceback 指向某个缺失模块，重新核对安装是否完整，不要在多个环境间单独复制包文件。
4. 如果是 macOS Dock 图标提示但主窗口仍能打开，应保留完整 traceback 判断是否只是图标初始化失败。

安装和运行时检查见[快速开始](../quickstart.md)。

### CUDA 不可用或自动回退到 CPU

先运行：

```bash
python -c "import nep_adapters as n; print(n.backend_status('cpu')); print(n.backend_status('cuda'))"
```

`Auto` 会使用可用后端并说明 CUDA 不可用原因。只有必须使用 GPU 时才在设置中强制选
`CUDA`；强制选择但运行时不可用会明确失败。详细入口见[设置](../module/settings.md)。

## 导入和显示

### `.xyz` / `.extxyz` 导入失败

依次检查首帧：

1. 声明的原子数是否等于实际原子行数；
2. `Properties` 声明的列数是否与每行一致；
3. 元素符号是否合法；
4. 周期结构的 `Lattice` 是否有效；
5. `pbc` 是否符合全周期、全非周期或部分周期的真实设置。

不要通过补零、伪元素或只改扩展名绕过错误。各格式的完整契约见[支持格式](../formats.md)。

### LAMMPS dump 提示缺少元素映射

只有数值 `type` 的 dump 不能自动知道真实元素。导入时提供完整的“类型编号 → 元素”映射，
或者在 dump 中直接写出 `element` 列。坐标还必须完整使用 `xs/ys/zs`、`x/y/z`
或 `xu/yu/zu` 中的一组。

### 打开结构后没有能量、力或 virial 图

结构坐标可以正常显示，不代表文件中一定有标签。检查是否同时提供了：

- EXTXYZ 中的参考能量、力或 virial；
- 对应的 GPUMD 输出文件；或
- 可用于现场预测的 `nep.txt`。

数据入口和组合方式见[打开数据与切换模型](../module/nep-display-open-data.md)。

### 图上的 x、y 哪个是 DFT

NepTrainKit 当前 NEP 对比图中，**x 轴是 NEP 预测值，y 轴是参考值（通常为 DFT）**。
NEP 与其他工具的输出列顺序不同，不影响本页面坐标约定。仍不确定时直接看坐标轴标题，
不要靠点云方向或文件列顺序猜测。

## 生成数据集

### 点击运行后没有输出

按顺序检查：

1. 卡片是否已勾选；
2. 需要输入的卡片是否已经导入结构；
3. 参数范围是否真的产生采样点，例如起点、终点和步长是否一致；
4. 过滤卡是否把全部结构排除；
5. 状态提示是否说明输入前提、路径、元素或几何条件不满足。

进入[卡片选择页](../module/make-dataset-cards/index.md)后打开具体卡片，查看“操作示例”和
“常见问题”。不要只反复点击运行。

### 输出数量比预计少

常见原因包括：重复结果被去重、几何检查拒绝候选、距离阈值提前停止、随机尝试达到上限，
或输入结构本身没有足够可操作位点。具体数量契约以卡片页的功能说明和参数说明为准。

### 输出数量突然非常大

多轴扫描、多元素组合、多个输入结构和多张卡片都可能相乘。先用单个输入和小范围预览，
再逐步增加轴、配比或随机样本数。需要多分支时查看[配方示例](../module/make-dataset-cards/recipes.md)，
不要一次把所有组合都送入 DFT。

### 界面是中文，文档里为什么还出现英文

文档采用“中文用途（英文界面名／序列化名）”的方式：中文用于阅读，英文用于和旧 JSON、
代码字段或未翻译界面精确对应。参数标题先写中文标签，括号中保留稳定字段名。

## 筛选、采样和数据修改

### FPS 选择数远少于目标

最小距离或 $R^2$ 阈值可能提前停止；也可能是候选池本身高度重复。降低阈值或关闭距离停止，
并检查实际停止原因。FPS 只能从已有候选中选择，不会补出缺失的结构类型。详见
[代表性采样](../module/nep-main-tool-sparse-samples.md)。

### FPS 选出的结构仍然不合理

FPS 只看描述符空间距离，短键或坏晶胞反而可能因为“很不一样”而被选中。先执行几何和人工清洗，
再做代表性采样。完整顺序见[候选结构清洗](../workflows/clean-candidate-structures.md)。

### 能量平移后找不到原始能量

第一次平移前的结构总能量写入 `energy_original`，新值写在 `energy`。导出 EXTXYZ 后检查这两个
帧级字段。再次平移不会覆盖已经保存的 `energy_original`。详见
[能量基线平移](../module/nep-main-tool-energy-shift.md)。

### 最大误差选中的结构数和点数不一致

能量图通常一行对应一个结构；力图中一个结构有多个原子和分量。最大误差工具会把行映射回
结构编号并去重，所以最终结构数可以少于图上的候选点数。

## 训练集评估

### 页面显示“没有磁性数据”

磁性评估只读取有效的逐原子 `spin:R:3`。`mforce`、`force_mag` 或标量说明文字不能代替
三分量自旋字段。先在 EXTXYZ 的 `Properties` 和原子列中确认字段真实存在。

### 结构相或磁类型和预期不同

评估结果是当前阈值和有限结构快照下的证据分类。先检查晶胞、周期边界、元素、邻居环境和
自旋字段，再进入[结构相判据](../module/training-audit-phase.md)或
[磁类型判据](../module/training-audit-magnetism.md)。不要把分类名称直接当成热力学相结论。

## 仍然无法定位

保留以下信息再反馈问题：

- NepTrainKit 版本和操作系统；
- 完整 traceback 或界面原始错误文本；
- 能复现问题的最小输入；
- 使用的页面、卡片和参数；
- 预期结果与实际结果。

不要只截最后一行错误；根因通常在 traceback 前面的文件、字段或参数信息中。
