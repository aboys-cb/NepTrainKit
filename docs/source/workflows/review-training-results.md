# 从训练误差定位下一轮数据缺口

这条流程适合已经完成一次 NEP 训练、准备决定下一轮补什么数据的人。它不以“删掉所有大误差点”
为目标，而是把误差点还原到真实结构和来源，区分标签问题、坏构型和训练集缺口。

## 1. 打开训练结果

在 `NEP Dataset Display` 中打开训练输出目录，确认能量、力和 virial 的参考值与预测值已经载入。
如果某类输出文件缺失，只分析当前真实可用的数据，不把缺失量当成零误差。

先确认两件事：

- 图中的参考值和预测值分别来自哪里；
- 当前显示的是训练集、测试集，还是另一个独立结构集合。

## 2. 先看误差集中在哪里

不要只记录一个总 RMSE。依次检查：

1. energy、force 和 virial 是否只有一种量明显偏差；
2. 大误差是否集中在少数 `Config_type`；
3. 是否集中在某种组分、表面、缺陷、应变或磁构型；
4. 同一结构附近是否已经有足够相似的训练样本。

使用 `Find Max Error Point` 选择最大误差结构，再查看右侧结构、元素组成和来源标签。
需要批量查看某个误差范围时，使用 `Select by Range`。

## 3. 进入训练集评估

从顶部 `Save` 分裂菜单打开“评估当前数据集”。先看概览中的训练阻塞项，再查看：

- 精确组分与低频集合；
- 高力和高能量尾部；
- 局域环境与元素对接触；
- 结构相和磁类型；
- 重复几何或标签冲突。

训练集评估给出的是当前数据内部证据。某个组分数量较多，不代表该组分的温压、缺陷或局域环境
已经覆盖；没有独立测试集时，也不能仅凭训练集预测判断模型已经泛化。

## 4. 给每类问题选择处理方向

| 看到的现象 | 先做什么 | 不要直接做什么 |
| --- | --- | --- |
| 同一几何对应冲突标签 | 回查 DFT 输出、单位和结构映射 | 把其中一条随机删掉 |
| 明显原子重叠或异常表面 | 隔离并检查生成参数 | 送入 FPS 强行保留 |
| 某类真实结构持续高误差 | 导出该类结构并补充邻近构型 | 只增加完全无关的随机扰动 |
| 某组分或磁类型样本很少 | 按研究目标补对应结构 | 把“低频”自动等同于“错误” |
| 训练集误差小、独立测试误差大 | 检查数据划分和覆盖范围 | 继续只优化训练 RMSE |

## 5. 导出可追溯的下一轮输入

把不同原因的结构分开导出，例如：

```text
review_label_conflicts.xyz
review_bad_geometry.xyz
next_round_surface_gap.xyz
next_round_magnetic_gap.xyz
```

如果需要新生成结构，再回到 `生成数据集`，按缺口选择主卡片。生成后的候选结构仍然要经过
几何检查和代表性采样，不能因为它们来自“高误差结构附近”就默认合理。

跑完检查：

- 每个导出文件只对应一种明确处理意图；
- 结构保留原有 `Config_type`，新生成结构追加可追溯标签；
- 下一轮训练前，能说明每批新增数据解决的具体缺口。
