# 通用采样验收协议（v1）

目标是在固定帧数下保留有用的结构变化，而非使 PCA 图均匀、复制原始频率，或只保住最大最小值。此协议独立于采样器；选择阶段不读取参考能量、力、virial、磁性力及来源名。有磁输入是可选项，普通结构同样适用。

## 1. 比较前冻结什么

- 固定原始文件、模型、描述符、来源行号及哈希。所有方法使用同一候选池、已有训练集和预算。
- 在继续调算法前保存评估坐标、缩放、切片和排除规则。改变任何一项必须重新跑全部对照，不能只重算候选方法。
- 先比较当前实际预算（如 10,000），再检查至少三个预算点的曲线。只比较同预算的结果，不以自动模式多选样来赢。
- 对照包括已发布 FPS、均匀随机（固定种子 0–19）、简单混合方法。混合比例需预先约定，不能对目标数据挑最优比例后宣称通用。
- 分清算法开发数据与未用于调参的外部数据；至少覆盖磁性、非磁多元素、单元素缺陷/应变。小型功能测试不算跨材料效果验收。

## 2. 分项验收，不合成一个总分

| 维度 | 指标 | 能发现什么 |
|---|---|---|
| 局域环境 | 同元素逐原子原始描述符到入选环境的最近距离，P95/P99/最大值 | 稀有环境被结构平均或其他目标挤掉 |
| 输入范围 | 每条预定义物理坐标的入选范围/全量范围 | 端点缺失 |
| 路径连续性 | 每个原始状态到入选状态的距离，P95/最大值 | 只选两端、内部断档 |
| 联合状态 | 多坐标联合空间最近距离；按预定义条件切片 | 各自范围完整但变量组合缺失 |
| 冗余与稳定性 | 去重后的有效状态数；重排、重复帧、等价变换前后的覆盖 | 把大量名额用在同一状态或依赖排列 |
| 代价 | 解析、描述符、特征、选样分别计时；峰值内存 | 改善是否值得额外成本 |

最近距离必须在**共同、冻结的坐标系**中计算，不能用各方法自己的自适应加权距离互比。描述符、几何和可选磁输入各自报告；高维距离不与低维距离相加。

输入坐标包括体积/原子、局域近邻分布、组成等；有规范 spin 输入时再加幅值、相对排列和自旋相对晶格/键方向。必须注明各坐标的适用范围和不变性。NEP 描述符是模型相关的表征，也不是完备的物理真值。

同时报告全局、每个关键切片与最差切片，防止大样本群掩盖小扫描。来源名只用于事后诊断：某来源选中为零不自动判失败，若其他来源有等价状态可以代表它；但相等的少数标量不构成物理等价证明。

### 可解释的标量指标

对于全量有限值集合 X、入选集合 S：

- 范围留存率：`(max(S) - min(S)) / (max(X) - min(X))`。
- 内部缺口：对每个 `x` 计算 `min(|x-s|) / (max(X)-min(X))`，报告 P95 和最大值。
- 正负两端分别报告 1%、5% 分位区域的样本数量，以及 `实际入选 / 均匀随机期望`。分位数遇到相同值时按实际尾部数量计算期望。

常量坐标若有代表则距离为零。没有可用观测或没有入选有效值时报告缺失，不能填零。范围和缺口的分母会受极端值影响，必须连同实际范围、分位数和数据质量一起看。不要把归一化距离解释为训练误差百分比。

## 3. 怎样判“改善”

1. **功能门槛**：恰好满足预算、索引合法、结果可复现；移除/改变参考标签与来源名不改变选择；磁性输入不存在时仍可工作。
2. **覆盖结论**：在预先冻结的关键指标上都不退步，并至少改善一项，才称为覆盖上的全面改善。若有退步，标为取舍方案并列出退步幅度；不能用加权总分把它藏起来，也不事后调容忍阈值。
3. **对照结论**：报告相对旧版和随机种子的完整范围/中位数。落在随机波动内的结果不作为算法优势。随机尾部数量多也不代表更会学习。
4. **默认算法验收**：有明显覆盖取舍时，须有跨数据、同验证集的训练证据支持，才有依据替换默认方案。仅一个材料上的覆盖改善不足以确认通用性。

不预设一个放之四海皆准的“0.25 合格线”。物理误差容忍度来自应用；没有这些信息时，交付覆盖证据和取舍，不承诺“必要结构已全部保留”。预算不足也必须显式呈现。

## 4. 标签审计与学习验收

参考标签只在**采样完成后**进入独立审计。分别检查能量、正/负力、virial、可选磁性力的尾部数量与范围，以及条件分布。已知占位标签先显式标记缺失；零能量不是通用的无效值规则。

训练比较须先冻结一份所有训练方法都不可见的验证集，再仅在训练候选池中重新采样。验证集不能由每个方法自己的未选样本代替，也不能把已用于算法调试的数据称为盲测。

匹配模型、超参数、种子，并分别说明固定训练步数和固定计算预算的比较口径。除整体 RMSE，检查正负尾部、稀有环境及条件响应曲线；有磁任务再检查磁响应。各自在训练集上画出的拟合图不能支持泛化优劣结论。

## 5. 离线工具

`tools/evaluate_sampling.py` 不导入采样算法，不修改选择，仅比较已导出的索引。

输入 NPZ（同一来源行顺序）：

- `scalar__NAME`: `(N,)`，物理标量；允许 NaN 表示显式缺失。审计标签建议命名 `scalar__label_NAME`。
- `view__NAME`: `(N,D)`，共同缩放且有限的联合坐标；不同元素/组成应先明确比较池，勿将不可比能量直接混合。
- `group`: 可选 `(N,)`，来源或已冻结的条件切片。

选择 JSON：`{"baseline": [0, 2, ...], "candidate": [1, 3, ...]}`，零基、不重复、预算一致。脚本自动加入 20 个均匀随机对照。

```sh
python tools/evaluate_sampling.py observations.npz selections.json audit.json
python -m pytest tests/test_evaluate_sampling.py -q
```

输出包含输入及脚本 SHA256、各方法的标量指标、联合距离和分组诊断。联合距离可由其他来源的代表覆盖；`within_source_scalars` 则只描述该来源直接入选部分，不能作为强制来源配额。该工具不计算原子描述符、不做训练、不自动给出科学通过结论；逐原子覆盖另用独立的公共参考距离核查，不能仅靠结构平均描述符替代。

## 6. 固定数量的默认算法

主界面和卡片的物理采样在“固定数量、无已有训练集、距离阈值为 0”时使用 `sampling_states.select_state_coverage`，这是唯一的固定数量算法。选择只读几何、可选自旋输入和模型描述符，不读 DFT 标签、来源名或 toy 真值。

1. 在可比较的元素集合内识别输入区域：精确/弯曲路径、完整或缺格的联合网格、同一联合状态的热扰动观测，以及有限独立状态。识别是基于输入的保守启发式，不能识别的部分交给覆盖处理。
2. 用每个区域只取一个代表时的缺口作为该区域的固定尺度，按剩余相对缺口分配区域名额，由此得到范围、连续性、联合单元和有限状态的**见证要求**。每个已观察的物理分层（元素集合、晶相、可选磁序）也是一个见证。见证可由任意满足它的帧实现，不锁定规划时的参考帧。
3. 对这些见证求最少帧数的精确集合覆盖（SciPy 整数求解；先消去必选项和被支配列，再拆分独立子问题）。列按内容顺序排列，结果与输入顺序无关。覆盖不可行时，FPS 只在能满足未完成见证的帧中挑选，并在证据中报告未覆盖结构。
4. 剩余名额由不加权多视图 FPS 补足：结构特征块之间取最大距离，原子只与相同中心元素比较。不使用局部间距权重，因此名额不随帧密度或重复帧变化。
5. 预算小于物理分层数时明确报错。没有输入视图时直接使用共享 FPS 轨迹。

按半径自动停止、有已有训练集或距离阈值大于 0 时，使用共享 FPS 轨迹。该轨迹的距离只含描述符、结构特征和原子环境，不含逐帧输入指纹；无已有训练集时，输入视图只提供每个元素集合在各输入坐标上的范围端点见证。FeRh 上若让输入几何参与半径判断，默认阈值 0.25 需要约 3.1 万帧，去掉后约 1.5 万帧。

原生覆盖更新按帧和原子树叶节点多线程执行，结果与单线程逐位一致。线程数依次读取 `NEPKIT_SAMPLING_THREADS`、`OMP_NUM_THREADS`，否则使用全部硬件线程。因此固定数量结果不再保证是自动模式选择序列的前缀。

## 7. 可复现的 toy 任务与预算证明

运行以下命令生成无标签 XYZ、独立真值、实际采样结果及报告，输出目录必须为空：

```sh
python -m tools.benchmark_sampling_toys \
  --output /tmp/neptrainkit-toy-benchmark \
  --model src/NepTrainKit/Config/nep89.txt \
  --spin-model /path/to/spin-nep.txt
python -m pytest tests/test_sampling_toys.py tests/test_evaluate_sampling.py -q
```

不提供 `--spin-model` 时显式跳过磁性案例。五类任务包括连续路径、路径中间重复帧、稀有晶相/缺陷分支、双轴应变及可选磁矩幅值—相对夹角；另有预先改变网格、预算、范围和非磁元素的五个迁移案例。迁移案例不是经过隔离的盲测集。输入 XYZ 不含能量、力、磁性力、virial、来源名或真值坐标，模型只用于计算描述符。真值位于单独 JSON，采样后才读取它评分。每个任务给出同预算的可行参考集合，并与实际默认算法、描述符 FPS 及 20 个随机种子比较。

必须分清三类问题：

- **搜索不足**：预算和约束允许更好的集合，但采样没有找到。
- **约束冲突**：独立标准在当前预算下可行，算法额外锁定的帧却使它不可行；增加交换搜索不能解决这个问题。
- **目标不一致**：最近距离变小不保证预定义格子全部被占据；格子占据更多也不代表模型误差更小。

`sampling_toy_data.minimum_budget` 在小型有限 toy 上独立求解整数覆盖问题，报告独立标准的最少帧数。超时报告 unknown，不当作不可行证明。这个求解器是评估工具，不能接入生产采样或用它读取真实数据的标签。

早期版本强制保留固定边界帧，曾使稀有分支和磁性任务在给定预算下与独立标准冲突。默认算法不再锁定边界帧；范围、连续性和联合单元见证可由任意满足的帧实现，由精确覆盖统一求解；toy 真值和独立标准不进入采样。

原始标准保持不变，报告所有失败；不通过放宽阈值、增大候选方法预算或调整分箱来制造改进。单元测试验证无标签输入、参考集合、独立评分、负对照及可行性证明，不要求现有采样器通过尚未解决的科学覆盖任务。实际质量验收看 benchmark 报告，不能用 pytest 通过代替。

## 8. 设计取舍与已否决方案

以下结论来自 FeRh（40,854 帧，预算 10,000）与 24 个 toy，均为覆盖指标和事后标签分布，未经统一测试集重训验证：

- **局部间距权重已删除。** 权重近似为 $(\rho/\rho_{\mathrm{median}})^{1/d}$，使高于中位密度区域的名额与帧数成正比；合成反例中路径名额随帧密度从 7 增至 40，而在其他区域加入近重复帧后又降至 17。FeRh 上权重最大达 1.16×10⁵；去掉权重后联合结构与原子环境覆盖在不加权度量下均改善。
- **基线 + 稀疏证书 + 整体最坏半径的共同求解已删除。** 以基线自身 FPS 半径作为覆盖阈值时几乎没有松弛（93.5% 的基线帧在该半径内没有其他基线帧），结果主要是基线修补；单一全局上限掩盖了 12 列中 9 列的分项退步，耗时约为基线两倍。
- **单帧/联合交换、受约束细化、均衡分配的回退修补已删除**，理由同上：收益有限、耗时高，且以单一上限掩盖分项变化。
- **分视图校准未采用。** 按各视图单独 FPS 半径归一化后，磁性统计视图最大缺口从 0.765 降到 0.269，但原子环境最大缺口从 0.760 增至 1.311、输入几何从 0.79 增至 1.18。它只是把名额从原子环境转给磁性视图，属于价值取舍而非改进，且结果受下限常数影响。

当前算法在 24 个 toy 上全部通过；FeRh 上联合结构最大/P95 为 0.794/0.765，原子环境为 0.760/0.359，单次调用约 140 秒（Apple M5，单线程，缓存特征）。已知残留：结构磁性统计视图最大缺口 0.765 被联合最大值掩盖；所有覆盖类方法都明显少选近平衡低能帧（最低 1% 能量帧约为随机期望的 0.06 倍）。这两点对训练精度的影响须用统一测试集重训判断。
